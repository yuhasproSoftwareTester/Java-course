    Java Installation Guide

    Notes

    What You Will Learn

    In this chapter, you will learn:

    • What is JDK
    • How to install Java
    • How to set environment variables
    • How to verify installation

    What is JDK?

    JDK (Java Development Kit) is required to:

    • Write Java programs
    • Compile code
    • Run applications

    It includes: - JRE (Java Runtime Environment) - JVM (Java Virtual Machine)

    Step 1: Download Java (JDK)

    1. Go to the official website: https://www.oracle.com/java/technologies/downloads/

    2. Choose:

    3. Latest LTS version (Recommended)

    4. Windows / Mac / Linux (based on your system)

    5. Download the installer

    Step 2: Install Java

    For Windows:

    1. Double-click the downloaded .exe file
    2. Click Next
    3. Choose install location (default is fine)
    4. Click Install
    5. Finish installation

    For Mac:

    1. Open .dmg file
    2. Follow installation steps
    3. Complete setup

    Step 3: Set Environment Variables (Windows)

    Why Needed?

    To run Java from anywhere in command prompt

    Steps:

    1. Open Start Menu
    2. Search: Environment Variables
    3. Click: Edit the system environment variables
    4. Click: Environment Variables

    Add JAVA_HOME

    1. Click New under System Variables
    2. Add:
    Variable Name: JAVA_HOME
Variable Value: C:\Program Files\Java\jdk-XX

    Replace XX with your version

    Update Path

    1. Select Path → Click Edit
    2. Click New

    3. Add: text %JAVA_HOME%\bin

    4. Click OK

    Step 4: Verify Installation

    Open Command Prompt and type:

    java -version
