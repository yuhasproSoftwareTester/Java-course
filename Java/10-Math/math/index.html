    Section 14: Math Methods

    1. Math Class Overview

    Key Facts

    • Static methods: Call directly via Math.method()
    • No instantiation: Cannot create new Math()
    • Primitive operations: Works with int, long, float, double
    • Returns: double for most operations (except min, max, abs variants)

    Import

    // No import needed! java.lang.Math is auto-imported
double result = Math.sqrt(25);  // Direct use

    2. Essential Math Methods by Category

    2.1 Basic Operations

    Method Returns Description Example
    Math.abs(x) Same type Absolute value Math.abs(-5) → 5
    Math.max(a, b) Same type Larger of two Math.max(10, 20) → 20
    Math.min(a, b) Same type Smaller of two Math.min(10, 20) → 10
    Math.pow(a, b) double Power (a^b) Math.pow(2, 3) → 8.0
    Math.sqrt(x) double Square root Math.sqrt(16) → 4.0
    Math.cbrt(x) double Cube root Math.cbrt(27) → 3.0

    2.2 Rounding Methods

    Method Returns Description Example
    Math.round(x) long/int Round to nearest Math.round(4.6) → 5
    Math.floor(x) double Round down Math.floor(4.9) → 4.0
    Math.ceil(x) double Round up Math.ceil(4.1) → 5.0
    Math.rint(x) double Round to nearest integer Math.rint(4.5) → 4.0

    2.3 Trigonometric Methods

    Method Returns Description Example
    Math.sin(x) double Sine (radians) Math.sin(Math.PI/2) → 1.0
    Math.cos(x) double Cosine (radians) Math.cos(0) → 1.0
    Math.tan(x) double Tangent (radians) Math.tan(Math.PI/4) → 1.0
    Math.toRadians(deg) double Degrees to radians Math.toRadians(180) → π
    Math.toDegrees(rad) double Radians to degrees Math.toDegrees(Math.PI) → 180.0

    2.4 Exponential & Logarithmic

    Method Returns Description Example
    Math.exp(x) double e^x Math.exp(1) → 2.718...
    Math.log(x) double Natural log (ln) Math.log(Math.E) → 1.0
    Math.log10(x) double Base-10 log Math.log10(100) → 2.0

    2.5 Random Generation

    Method Returns Description Example
    Math.random() double 0.0 to <1.0 Math.random() → 0.753...

    2.6 Constants

    Constant Value Description
    Math.PI 3.14159... Circle ratio
    Math.E 2.71828... Euler's number

    3. Random Number Generation Patterns

    Basic Random

    // 0.0 to 0.999...
double random = Math.random();

// 0 to 99
int zeroTo99 = (int)(Math.random() * 100);

// 1 to 100
int oneTo100 = (int)(Math.random() * 100) + 1;

// Min to Max formula: (int)(Math.random() * (max - min + 1)) + min
int dice = (int)(Math.random() * 6) + 1;  // 1-6

    Random Ranges

    Range Formula Example
    0 to n-1 (int)(Math.random() * n) 0-9: (int)(Math.random() * 10)
    1 to n (int)(Math.random() * n) + 1 1-10: (int)(Math.random() * 10) + 1
    min to max (int)(Math.random() * (max-min+1)) + min 5-15: (int)(Math.random() * 11) + 5

    Program 2: Geometry Calculator

    import java.util.Scanner;

public class GeometryCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Geometry Calculator ===");
        System.out.println("1. Circle");
        System.out.println("2. Rectangle");
        System.out.println("3. Triangle");
        System.out.println("4. Sphere");
        System.out.print("Choose shape: ");
        int choice = scanner.nextInt();

        switch (choice) {
            case 1: // Circle
                System.out.print("Enter radius: ");
                double r = scanner.nextDouble();

                double circleArea = Math.PI * Math.pow(r, 2);
                double circumference = 2 * Math.PI * r;

                System.out.println("Area: " + Math.round(circleArea * 100) / 100.0);
                System.out.println("Circumference: " + Math.round(circumference * 100) / 100.0);
                break;

            case 2: // Rectangle
                System.out.print("Enter width: ");
                double w = scanner.nextDouble();
                System.out.print("Enter height: ");
                double h = scanner.nextDouble();

                double rectArea = w * h;
                double diagonal = Math.sqrt(Math.pow(w, 2) + Math.pow(h, 2));

                System.out.println("Area: " + rectArea);
                System.out.println("Diagonal: " + Math.round(diagonal * 100) / 100.0);
                break;

            case 3: // Triangle
                System.out.print("Enter side a: ");
                double a = scanner.nextDouble();
                System.out.print("Enter side b: ");
                double b = scanner.nextDouble();
                System.out.print("Enter side c: ");
                double c = scanner.nextDouble();

                // Heron's formula
                double s = (a + b + c) / 2;  // semi-perimeter
                double triangleArea = Math.sqrt(s * (s - a) * (s - b) * (s - c));

                System.out.println("Area: " + Math.round(triangleArea * 100) / 100.0);
                break;

            case 4: // Sphere
                System.out.print("Enter radius: ");
                double radius = scanner.nextDouble();

                double sphereVolume = (4.0 / 3.0) * Math.PI * Math.pow(radius, 3);
                double surfaceArea = 4 * Math.PI * Math.pow(radius, 2);

                System.out.println("Volume: " + Math.round(sphereVolume * 100) / 100.0);
                System.out.println("Surface Area: " + Math.round(surfaceArea * 100) / 100.0);
                break;

            default:
                System.out.println("Invalid choice");
        }

        scanner.close();
    }
}

    Program 3: Financial Calculator

    import java.util.Scanner;

public class FinancialCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Financial Calculator ===");

        System.out.print("Principal amount: $");
        double principal = scanner.nextDouble();

        System.out.print("Annual interest rate (%): ");
        double rate = scanner.nextDouble() / 100;

        System.out.print("Time in years: ");
        int years = scanner.nextInt();

        System.out.print("Compounding periods per year: ");
        int n = scanner.nextInt();

        // Compound Interest: A = P(1 + r/n)^(nt)
        double amount = principal * Math.pow(1 + rate / n, n * years);
        double interest = amount - principal;

        System.out.println("\n=== Results ===");
        System.out.println("Final Amount: $" + Math.round(amount * 100) / 100.0);
        System.out.println("Interest Earned: $" + Math.round(interest * 100) / 100.0);

        // Monthly Payment for Loan (Amortization)
        System.out.print("\nCalculate loan payment? (y/n): ");
        if (scanner.next().equalsIgnoreCase("y")) {
            System.out.print("Loan amount: $");
            double loan = scanner.nextDouble();
            System.out.print("Annual rate (%): ");
            double loanRate = scanner.nextDouble() / 100 / 12;  // monthly rate
            System.out.print("Years: ");
            int loanYears = scanner.nextInt();
            int payments = loanYears * 12;

            // M = P[r(1+r)^n]/[(1+r)^n-1]
            double monthlyPayment = loan * (loanRate * Math.pow(1 + loanRate, payments)) 
                                   / (Math.pow(1 + loanRate, payments) - 1);

            System.out.println("Monthly Payment: $" + Math.round(monthlyPayment * 100) / 100.0);
            System.out.println("Total Paid: $" + Math.round(monthlyPayment * payments * 100) / 100.0);
        }

        scanner.close();
    }
}

    Program 4: Statistical Analyzer

    import java.util.Scanner;

public class StatisticalAnalyzer {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Statistical Analyzer ===");
        System.out.print("How many numbers? ");
        int n = scanner.nextInt();

        double[] numbers = new double[n];
        double sum = 0;
        double min = Double.MAX_VALUE;
        double max = Double.MIN_VALUE;

        System.out.println("Enter " + n + " numbers:");
        for (int i = 0; i < n; i++) {
            numbers[i] = scanner.nextDouble();
            sum += numbers[i];
            min = Math.min(min, numbers[i]);
            max = Math.max(max, numbers[i]);
        }

        double mean = sum / n;

        // Calculate standard deviation
        double sumSquaredDiff = 0;
        for (double num : numbers) {
            sumSquaredDiff += Math.pow(num - mean, 2);
        }
        double stdDev = Math.sqrt(sumSquaredDiff / n);

        // Median (requires sorting - simplified here assuming sorted or use Arrays.sort)
        java.util.Arrays.sort(numbers);
        double median;
        if (n % 2 == 0) {
            median = (numbers[n/2 - 1] + numbers[n/2]) / 2;
        } else {
            median = numbers[n/2];
        }

        // Range and variance
        double range = max - min;
        double variance = Math.pow(stdDev, 2);

        System.out.println("\n=== Statistics ===");
        System.out.println("Count: " + n);
        System.out.println("Sum: " + Math.round(sum * 100) / 100.0);
        System.out.println("Mean: " + Math.round(mean * 100) / 100.0);
        System.out.println("Median: " + Math.round(median * 100) / 100.0);
        System.out.println("Min: " + min);
        System.out.println("Max: " + max);
        System.out.println("Range: " + Math.round(range * 100) / 100.0);
        System.out.println("Variance: " + Math.round(variance * 100) / 100.0);
        System.out.println("Std Dev: " + Math.round(stdDev * 100) / 100.0);

        // Outlier detection (mean ± 2*stdDev)
        System.out.println("\nOutliers (beyond 2 std dev):");
        int outlierCount = 0;
        for (double num : numbers) {
            if (Math.abs(num - mean) > 2 * stdDev) {
                System.out.println("  " + num);
                outlierCount++;
            }
        }
        if (outlierCount == 0) System.out.println("  None detected");

        scanner.close();
    }
}

    import java.util.Scanner;

public class SeleniumMathHelper {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Selenium Math Helper ===");

        // 1. Random wait time generator (exponential backoff)
        System.out.println("\n1. RANDOM WAIT TIMES");
        System.out.print("Base wait (ms): ");
        int baseWait = scanner.nextInt();
        System.out.print("Max retries: ");
        int maxRetries = scanner.nextInt();

        System.out.println("Exponential backoff schedule:");
        for (int i = 0; i < maxRetries; i++) {
            // Exponential: base * 2^i, capped at reasonable max
            long waitTime = Math.min(baseWait * (long)Math.pow(2, i), 30000);
            System.out.println("  Retry " + (i + 1) + ": " + waitTime + "ms");
        }

        // 2. Scroll position calculator
        System.out.println("\n2. SCROLL POSITIONS");
        System.out.print("Page height (px): ");
        int pageHeight = scanner.nextInt();
        System.out.print("Viewport height (px): ");
        int viewportHeight = scanner.nextInt();
        System.out.print("Target element Y position: ");
        int elementY = scanner.nextInt();

        // Calculate optimal scroll position (center element in viewport)
        int optimalScroll = Math.max(0, elementY - (viewportHeight / 2));
        int maxScroll = Math.max(0, pageHeight - viewportHeight);
        int finalScroll = Math.min(optimalScroll, maxScroll);

        System.out.println("Optimal scroll Y: " + finalScroll);
        System.out.println("Scroll percentage: " + Math.round((double)finalScroll / maxScroll * 100) + "%");

        // 3. Random click position within element (to avoid bot detection)
        System.out.println("\n3. RANDOM CLICK POSITION");
        System.out.print("Element X: ");
        int elemX = scanner.nextInt();
        System.out.print("Element Y: ");
        int elemY = scanner.nextInt();
        System.out.print("Element width: ");
        int elemWidth = scanner.nextInt();
        System.out.print("Element height: ");
        int elemHeight = scanner.nextInt();

        // Random position with padding (avoid edges)
        int padding = 5;
        int clickX = elemX + padding + (int)(Math.random() * (elemWidth - 2 * padding));
        int clickY = elemY + padding + (int)(Math.random() * (elemHeight - 2 * padding));

        System.out.println("Random click at: (" + clickX + ", " + clickY + ")");

        // 4. Pagination calculator
        System.out.println("\n4. PAGINATION MATH");
        System.out.print("Total items: ");
        int totalItems = scanner.nextInt();
        System.out.print("Items per page: ");
        int perPage = scanner.nextInt();
        System.out.print("Current page: ");
        int currentPage = scanner.nextInt();

        int totalPages = (int)Math.ceil((double)totalItems / perPage);
        int startItem = (currentPage - 1) * perPage + 1;
        int endItem = Math.min(currentPage * perPage, totalItems);

        System.out.println("Total pages: " + totalPages);
        System.out.println("Showing items " + startItem + "-" + endItem);
        System.out.println("Progress: " + Math.round((double)currentPage / totalPages * 100) + "%");

        // 5. Screenshot grid calculator
        System.out.println("\n5. SCREENSHOT GRID");
        System.out.print("Page width: ");
        int pageWidth = scanner.nextInt();
        System.out.print("Page height: ");
        int pageHeight2 = scanner.nextInt();

        int maxSize = scanner.nextInt();

        int cols = (int)Math.ceil((double)pageWidth / maxSize);
        int rows = (int)Math.ceil((double)pageHeight2 / maxSize);

        System.out.println("Grid needed: " + cols + "x" + rows + " = " + (cols * rows) + " screenshots");

        int overlap = 50; // pixels

        int effectiveHeight = (pageHeight2 + (rows - 1) * overlap) / rows;

        System.out.println("Effective capture size: " + effectiveWidth + "x" + effectiveHeight);

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Integer division (int)(Math.random() * 100) gives 0-99 Need +1 for 1-100 (int)(Math.random() * 100) + 1
    Floating point comparison if (Math.sqrt(2) == 1.414) Precision loss if (Math.abs(Math.sqrt(2) - 1.414) < 0.001)
    Negative square root Math.sqrt(-4) Returns NaN Check if (x >= 0) first
    Overflow in pow Math.pow(2, 10000) Returns Infinity Use BigInteger for large numbers
    Wrong rounding Math.round(4.5) gives 4 Banker's rounding (to even) Use Math.floor(x + 0.5) for always up
    Casting truncation (int) Math.pow(2, 31) Overflow Use long for large powers

    7. Quick Rules Checklist

    ✅ Math Rules

    • [ ] Math.random() returns 0.0 to <1.0 (never 1.0)
    • [ ] Cast to int after multiplication for random integers
    • [ ] Range formula: (int)(Math.random() * (max - min + 1)) + min
    • [ ] Math.pow() returns double, may need casting
    • [ ] Math.round() returns long (cast to int if needed)
    • [ ] Check for negative inputs before sqrt()

    ✅ Best Practices

    • [ ] Use Math.abs() for distance/difference calculations
    • [ ] Use Math.max()/Math.min() for boundary checks
    • [ ] Round only for display, keep precision for calculations
    • [ ] Use BigDecimal for financial precision (not double)
    • [ ] Cache random results if used multiple times

    // Calculate optimal scroll position to center element
WebElement element = driver.findElement(By.id("target"));

    Another Example: Dynamic Wait Strategy

    public void smartClick(By locator, int maxRetries) {
    int baseWait = 500;  // ms

    for (int i = 0; i < maxRetries; i++) {
        try {
            WebElement element = driver.findElement(locator);
            if (element.isDisplayed() && element.isEnabled()) {
                // Random offset click (avoid detection)
                int offsetX = (int)(Math.random() * 10);
                int offsetY = (int)(Math.random() * 10);

                Actions actions = new Actions(driver);
                actions.moveToElement(element, offsetX, offsetY).click().perform();
                return;
            }
        } catch (Exception e) {
            // Exponential backoff
            long waitTime = (long)(baseWait * Math.pow(2, i));
            waitTime = Math.min(waitTime, 10000);  // Cap at 10s

            try {
                Thread.sleep(waitTime);
            } catch (InterruptedException ie) {
                Thread.currentThread().interrupt();
            }
        }
    }
    throw new RuntimeException("Failed to click after " + maxRetries + " retries");
}
