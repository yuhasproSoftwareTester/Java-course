    Assignment

    1. Assignment Operators Overview

    Simple Assignment

    Operator Name Description Example Equivalent
    = Simple Assignment Assigns right value to left variable a = 5 Direct assignment

    Compound Assignment (Shorthand)

    Operator Name Description Example Equivalent To
    += Add and assign Add right, store in left a += 5 a = a + 5
    -= Subtract and assign Subtract right, store in left a -= 5 a = a - 5
    *= Multiply and assign Multiply by right, store in left a *= 5 a = a * 5
    /= Divide and assign Divide by right, store in left a /= 5 a = a / 5
    %= Modulo and assign Modulo by right, store in left a %= 5 a = a % 5

    2. How Assignment Works

    Right-to-Left Evaluation

    int a, b, c;
a = b = c = 10;  // All become 10 (evaluated right to left)

    Step-by-Step Breakdown:

    a = b = c = 10;

Step 1: c = 10  →  c is now 10
Step 2: b = c   →  b is now 10  
Step 3: a = b   →  a is now 10

    3. Complete Working Examples

    Example 1: Simple vs Compound

    public class AssignmentDemo {
    public static void main(String[] args) {
        int score = 100;        // Simple assignment

        // Without compound operator
        score = score + 50;     // score is now 150

        // With compound operator (cleaner!)
        score += 25;            // score is now 175

        // All compound types
        int value = 1000;
        value -= 100;           // 900 (deduction)
        value *= 2;             // 1800 (bonus multiplier)
        value /= 10;            // 180 (average)
        value %= 7;             // 5 (remainder)

        System.out.println("Final value: " + value);
    }
}

    Example 2: Multiple Assignment

    public class MultipleAssignment {
    public static void main(String[] args) {
        // Assign same value to multiple variables
        int x, y, z;
        x = y = z = 50;

        System.out.println("x=" + x + ", y=" + y + ", z=" + z);

        // Update all at once (not possible with compound)
        x = y = z = x + 10;  // All become 60

        // Or individually with compound
        x += 5;  // 65
        y += 5;  // 65  
        z += 5;  // 65
    }
}

    Program 1: Shopping Cart Total (Compound Operators)

    import java.util.Scanner;

public class ShoppingCartCompound {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        double total = 0.0;

        System.out.println("=== Shopping Cart Calculator ===");
        System.out.println("Enter item prices (0 to checkout):");

        while (true) {
            System.out.print("Item price: $");
            double price = scanner.nextDouble();

            if (price == 0) break;

            total += price;  // Add to running total
            System.out.println("Added: $" + price + " | Running total: $" + total);
        }

        // Apply discount
        System.out.print("\nEnter discount percentage: ");
        double discount = scanner.nextDouble();

        total -= (total * discount / 100);  // Subtract discount

        // Add tax
        total += (total * 0.08);  // Add 8% tax

        System.out.println("\n=== FINAL TOTAL ===");
        System.out.println("Amount to pay: $" + total);

        scanner.close();
    }
}

    Program 2: Bank Account Manager

    import java.util.Scanner;

public class BankAccountManager {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        double balance = 1000.00;  // Starting balance
        int transactionCount = 0;

        System.out.println("=== Bank Account Manager ===");
        System.out.println("Starting Balance: $" + balance);

        System.out.println("\n1. Deposit");
        System.out.println("2. Withdraw");
        System.out.println("3. Check Balance");
        System.out.println("4. Exit");

        while (true) {
            System.out.print("\nChoose option: ");
            int choice = scanner.nextInt();

            if (choice == 4) break;

            switch (choice) {
                case 1:
                    System.out.print("Enter deposit amount: $");
                    double deposit = scanner.nextDouble();
                    balance += deposit;           // Add deposit
                    transactionCount += 1;        // Count transaction
                    System.out.println("Deposited: $" + deposit);
                    break;

                case 2:
                    System.out.print("Enter withdrawal amount: $");
                    double withdrawal = scanner.nextDouble();
                    if (withdrawal <= balance) {
                        balance -= withdrawal;    // Subtract withdrawal
                        transactionCount += 1;
                        System.out.println("Withdrawn: $" + withdrawal);
                    } else {
                        System.out.println("Insufficient funds!");
                    }
                    break;

                case 3:
                    System.out.println("Current Balance: $" + balance);
                    System.out.println("Transactions today: " + transactionCount);
                    break;

                default:
                    System.out.println("Invalid option!");
            }
        }

        System.out.println("\n=== FINAL SUMMARY ===");
        System.out.println("Final Balance: $" + balance);
        System.out.println("Total Transactions: " + transactionCount);

        scanner.close();
    }
}

    Program 3: Score Multiplier Game

    import java.util.Scanner;

public class ScoreMultiplier {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int baseScore = 100;
        int multiplier = 1;

        System.out.println("=== Score Multiplier Game ===");
        System.out.println("Base Score: " + baseScore);

        // Level 1: Double the score
        baseScore *= 2;  // 200
        multiplier += 1;   // 2
        System.out.println("Level 1 complete! Score: " + baseScore + " (x" + multiplier + ")");

        // Level 2: Add bonus
        System.out.print("Enter bonus points: ");
        int bonus = scanner.nextInt();
        baseScore += bonus;  // Add bonus
        System.out.println("Bonus added! Score: " + baseScore);

        // Level 3: Penalty for wrong answer
        System.out.print("Wrong answer! Enter penalty: ");
        int penalty = scanner.nextInt();
        baseScore -= penalty;  // Subtract penalty
        System.out.println("After penalty: " + baseScore);

        // Final: Divide by attempts used
        System.out.print("Enter attempts used: ");
        int attempts = scanner.nextInt();
        baseScore /= attempts;  // Average per attempt
        System.out.println("Final averaged score: " + baseScore);

        // Modulo for bonus check
        baseScore %= 10;  // Get last digit
        System.out.println("Bonus digit (remainder): " + baseScore);

        scanner.close();
    }
}

    Program 4: Inventory Stock Manager

    import java.util.Scanner;

public class InventoryManager {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int stock = 100;  // Initial stock

        System.out.println("=== Inventory Stock Manager ===");
        System.out.println("Initial Stock: " + stock + " units");

        while (true) {
            System.out.println("\n1. Receive Stock (+)");
            System.out.println("2. Sell Stock (-)");
            System.out.println("3. Double Order (*)");
            System.out.println("4. Clearance Sale (/2)");
            System.out.println("5. Check Stock");
            System.out.println("6. Exit");

            System.out.print("Choice: ");
            int choice = scanner.nextInt();

            int amount;

            switch (choice) {
                case 1:
                    System.out.print("Enter quantity received: ");
                    amount = scanner.nextInt();
                    stock += amount;  // Receive stock
                    System.out.println("Added " + amount + " units. New stock: " + stock);
                    break;

                case 2:
                    System.out.print("Enter quantity sold: ");
                    amount = scanner.nextInt();
                    if (amount <= stock) {
                        stock -= amount;  // Sell stock
                        System.out.println("Sold " + amount + " units. Remaining: " + stock);
                    } else {
                        System.out.println("Not enough stock!");
                    }
                    break;

                case 3:
                    stock *= 2;  // Double inventory
                    System.out.println("Stock doubled! New amount: " + stock);
                    break;

                case 4:
                    stock /= 2;  // Half price sale - reduce tracking
                    System.out.println("Clearance mode: Stock now " + stock);
                    break;

                case 5:
                    System.out.println("Current Stock: " + stock + " units");
                    break;

                case 6:
                    System.out.println("Final Stock Count: " + stock);
                    scanner.close();
                    return;

                default:
                    System.out.println("Invalid choice!");
            }
        }
    }
}

    Program 5: Selenium Wait Calculator (Automation Prep)

    import java.util.Scanner;

public class WaitCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int baseWait = 2;      // Base wait in seconds
        int maxWait = 30;      // Maximum wait cap
        int retryCount = 0;    // Track retries

        System.out.println("=== Selenium Wait Calculator ===");
        System.out.println("Base wait: " + baseWait + "s, Max: " + maxWait + "s");

        while (true) {
            System.out.print("\nElement found? (1=Yes, 0=No, -1=Exit): ");
            int found = scanner.nextInt();

            if (found == -1) break;
            if (found == 1) {
                System.out.println("Element found! Using wait: " + baseWait + "s");
                // Reset for next element
                baseWait = 2;
                retryCount = 0;
                continue;
            }

            // Element not found - increase wait
            retryCount += 1;
            System.out.println("Retry #" + retryCount);

            // Exponential backoff: double the wait
            baseWait *= 2;

            // Cap at maximum
            if (baseWait > maxWait) {
                baseWait = maxWait;
                System.out.println("Reached max wait: " + baseWait + "s");
            } else {
                System.out.println("Increased wait to: " + baseWait + "s");
            }

            // Check if max retries reached
            if (retryCount >= 5) {
                System.out.println("Max retries reached. Failing test.");
                break;
            }
        }

        System.out.println("\n=== SUMMARY ===");
        System.out.println("Total retries this session: " + retryCount);

        scanner.close();
    }
}

    5. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Assignment vs Comparison if (a = 5) Assigns 5 to a, always true if (a == 5) for comparison
    Chained Assignment Type int x = y = 5.5; y would be double Ensure types match: double x, y; x = y = 5.5;
    Lost Precision int a = 5; a /= 2; Result is 2 (int division) Use double: double a = 5; a /= 2; // 2.5
    Uninitialized Variable int x; x += 5; x has no initial value Initialize first: int x = 0;
    Operator Precedence a *= b + c Equivalent to a = a * (b + c) Use parentheses: (a *= b) + c if needed

    6. Quick Rules Checklist

    Assignment Rules

    • [ ] Right-to-left: a = b = c = 5 assigns 5 to all
    • [ ] Compound operators are cleaner and slightly faster
    • [ ] Type compatibility: Can't assign double to int without cast
    • [ ] Initialization required before using += etc.

    Best Practices

    • [ ] Use += for running totals and counters
    • [ ] Use -= for decrements and deductions
    • [ ] Use *= and /= for scaling operations
    • [ ] Reset values (= 0) rather than creating new variables
    • [ ] Chain assignments only when all variables need same value
