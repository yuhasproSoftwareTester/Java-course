    Logical Operators

    1. Logical Operators Overview

    Operator Name Description Example Result
    && AND Both conditions must be true true && false false
    \|\| OR At least one condition must be true true \|\| false true
    ! NOT Reverses the boolean value !true false

    2. Truth Tables

    AND (&&) - Both must be true

    Condition 1 Condition 2 Result
    true true true
    true false false
    false true false
    false false false

    Real-world: "Login if username AND password are correct"

    OR (||) - At least one must be true

    Condition 1 Condition 2 Result
    true true true
    true false true
    false true true
    false false false

    Real-world: "Free shipping if member OR order > $50"

    NOT (!) - Reverse the result

    Condition Result
    !true false
    !false true

    Real-world: "Continue if NOT logged out"

    3. Short-Circuit Evaluation

    Java evaluates logical operators left-to-right and stops early when the result is known:

    && (AND) Short-Circuit

    // If first condition is false, second is NOT checked
if (isValidUser() && hasPermission()) {
    // If isValidUser() returns false, hasPermission() never runs
}

    || (OR) Short-Circuit

    // If first condition is true, second is NOT checked
if (isAdmin() || isModerator()) {
    // If isAdmin() returns true, isModerator() never runs
}

    Why This Matters

    • Performance: Skip unnecessary checks
    • Safety: Prevent null pointer exceptions
    • Efficiency: Put cheaper checks first

    Example 1: Login System with Combined Conditions

    import java.util.Scanner;

public class SecureLogin {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Simulated database
        String validUser = "admin";
        String validPass = "secret123";
        boolean accountActive = true;
        int failedAttempts = 0;

        System.out.print("Username: ");
        String username = scanner.nextLine();

        System.out.print("Password: ");
        String password = scanner.nextLine();

        // Check credentials AND account status
        boolean credentialsValid = username.equals(validUser) && 
                                   password.equals(validPass);
        boolean canLogin = credentialsValid && accountActive && 
                          failedAttempts < 3;

        System.out.println("Credentials valid: " + credentialsValid);
        System.out.println("Can login: " + canLogin);

        if (canLogin) {
            System.out.println("✅ Access granted!");
        } else {
            System.out.println("❌ Access denied!");

            // Determine why using OR conditions
            if (!credentialsValid) {
                System.out.println("   - Invalid username or password");
            }
            if (!accountActive) {
                System.out.println("   - Account is disabled");
            }
            if (failedAttempts >= 3) {
                System.out.println("   - Account locked due to failed attempts");
            }
        }

        scanner.close();
    }
}

    Example 2: Eligibility Checker

    import java.util.Scanner;

public class EligibilityChecker {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Age: ");
        int age = scanner.nextInt();

        System.out.print("Has degree (true/false): ");
        boolean hasDegree = scanner.nextBoolean();

        System.out.print("Years of experience: ");
        int experience = scanner.nextInt();

        System.out.print("Has certification (true/false): ");
        boolean hasCert = scanner.nextBoolean();

        // Complex condition: Job eligibility
        // Must be 18+ AND (hasDegree OR (experience >= 3 AND hasCert))
        boolean ageOk = age >= 18;
        boolean qualified = hasDegree || (experience >= 3 && hasCert);
        boolean eligible = ageOk && qualified;

        System.out.println("\n=== Eligibility Check ===");
        System.out.println("Age requirement met: " + ageOk);
        System.out.println("Qualifications met: " + qualified);
        System.out.println("ELIGIBLE FOR JOB: " + eligible);

        // Alternative: Senior position (stricter)
        boolean seniorEligible = age >= 25 && hasDegree && experience >= 5;
        System.out.println("Eligible for senior role: " + seniorEligible);

        scanner.close();
    }
}

    Program 1: E-commerce Checkout Validator

    import java.util.Scanner;

public class CheckoutValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Checkout Validator ===");

        System.out.print("Cart total: $");
        double total = scanner.nextDouble();

        System.out.print("Items in cart: ");
        int itemCount = scanner.nextInt();
        scanner.nextLine();  // Clear buffer

        System.out.print("Is logged in (true/false): ");
        boolean isLoggedIn = scanner.nextBoolean();

        System.out.print("Has valid payment method (true/false): ");
        boolean hasPayment = scanner.nextBoolean();

        System.out.print("Shipping address confirmed (true/false): ");
        boolean addressOk = scanner.nextBoolean();

        // Validation rules
        boolean minOrder = total >= 10.0 && itemCount > 0;
        boolean canCheckout = isLoggedIn && hasPayment && addressOk && minOrder;

        boolean freeShipping = total >= 50.0 || isLoggedIn && total >= 25.0;
        boolean expressAvailable = total >= 100.0 && addressOk;

        System.out.println("\n=== Validation Results ===");
        System.out.println("Minimum order met: " + minOrder);
        System.out.println("Can proceed to checkout: " + canCheckout);
        System.out.println("Qualifies for free shipping: " + freeShipping);
        System.out.println("Express shipping available: " + expressAvailable);

        // Detailed error messages
        if (!canCheckout) {
            System.out.println("\n❌ Cannot checkout because:");
            if (!isLoggedIn) System.out.println("   - Not logged in");
            if (!hasPayment) System.out.println("   - No payment method");
            if (!addressOk) System.out.println("   - Address not confirmed");
            if (!minOrder) System.out.println("   - Minimum order not met");
        }

        scanner.close();
    }
}

    Program 2: Game Access Control

    import java.util.Scanner;

public class GameAccessControl {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Game Server Access ===");

        System.out.print("Player age: ");
        int age = scanner.nextInt();

        System.out.print("Has valid subscription (true/false): ");
        boolean hasSub = scanner.nextBoolean();

        System.out.print("Is banned (true/false): ");
        boolean isBanned = scanner.nextBoolean();

        System.out.print("Server maintenance mode (true/false): ");
        boolean maintenance = scanner.nextBoolean();

        System.out.print("Current players online: ");
        int onlinePlayers = scanner.nextInt();

        // Access rules
        boolean ageAppropriate = age >= 13;
        boolean accountGood = !isBanned && hasSub;  // NOT banned AND has subscription
        boolean serverAvailable = !maintenance && onlinePlayers < 1000;

        boolean canPlay = ageAppropriate && accountGood && serverAvailable;

        System.out.println("\n=== Access Check ===");
        System.out.println("Age appropriate (13+): " + ageAppropriate);
        System.out.println("Account in good standing: " + accountGood);
        System.out.println("Server available: " + serverAvailable);
        System.out.println("🎮 CAN PLAY: " + canPlay);

        // Priority queue check
        boolean vipAccess = age >= 18 && hasSub && !isBanned;
        boolean canSkipQueue = vipAccess && onlinePlayers >= 900;

        if (canPlay) {
            if (canSkipQueue) {
                System.out.println("⭐ VIP Status: Skip the queue!");
            } else {
                System.out.println("⏳ Standard queue");
            }
        }

        scanner.close();
    }
}

    Program 3: Form Validation System

    import java.util.Scanner;

public class FormValidation {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Registration Form Validation ===");

        System.out.print("Username (min 4 chars): ");
        String username = scanner.nextLine();

        System.out.print("Password (min 8 chars): ");
        String password = scanner.nextLine();

        System.out.print("Email contains '@': ");
        String email = scanner.nextLine();

        System.out.print("Age: ");
        int age = scanner.nextInt();
        scanner.nextLine();

        System.out.print("Agreed to terms (true/false): ");
        boolean agreedToTerms = scanner.nextBoolean();

        // Individual validations
        boolean userValid = username.length() >= 4;
        boolean passValid = password.length() >= 8;
        boolean emailValid = email.contains("@") && email.contains(".");
        boolean ageValid = age >= 18 && age <= 120;

        // Combined validation
        boolean formValid = userValid && passValid && emailValid && 
                           ageValid && agreedToTerms;

        System.out.println("\n=== Validation Results ===");
        System.out.println("Username valid: " + userValid);
        System.out.println("Password valid: " + passValid);
        System.out.println("Email valid: " + emailValid);
        System.out.println("Age valid: " + ageValid);
        System.out.println("Terms accepted: " + agreedToTerms);
        System.out.println("✅ FORM VALID: " + formValid);

        // Specific feedback using OR for grouping
        boolean contactInfoOk = emailValid;  // Could add phone later with ||
        boolean identityOk = userValid && ageValid;

        if (!formValid) {
            System.out.println("\nIssues found:");
            if (!identityOk) System.out.println("   - Identity information incomplete");
            if (!contactInfoOk) System.out.println("   - Contact information invalid");
            if (!passValid) System.out.println("   - Password does not meet requirements");
            if (!agreedToTerms) System.out.println("   - Terms not accepted");
        }

        scanner.close();
    }
}

    Program 4: Smart Home Security System

    import java.util.Scanner;

public class SmartHomeSecurity {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Smart Home Security ===");

        System.out.print("Motion detected (true/false): ");
        boolean motion = scanner.nextBoolean();

        System.out.print("Door/window open (true/false): ");
        boolean entryPointOpen = scanner.nextBoolean();

        System.out.print("After hours (10PM - 6AM) (true/false): ");
        boolean afterHours = scanner.nextBoolean();

        System.out.print("Owner away (true/false): ");
        boolean ownerAway = scanner.nextBoolean();

        System.out.print("Security system armed (true/false): ");
        boolean systemArmed = scanner.nextBoolean();

        // Alarm triggers if:
        // (Motion OR Entry open) AND (After hours OR Owner away) AND System armed
        boolean intrusionDetected = (motion || entryPointOpen);
        boolean highRiskTime = afterHours || ownerAway;

        boolean alarmShouldTrigger = intrusionDetected && highRiskTime && systemArmed;

        // Alert levels
        boolean criticalAlert = motion && entryPointOpen && afterHours && ownerAway;
        boolean standardAlert = alarmShouldTrigger && !criticalAlert;
        boolean notificationOnly = intrusionDetected && !systemArmed;

        System.out.println("\n=== Security Status ===");
        System.out.println("Intrusion detected: " + intrusionDetected);
        System.out.println("High risk time: " + highRiskTime);
        System.out.println("🔔 ALARM TRIGGERED: " + alarmShouldTrigger);
        System.out.println("🚨 CRITICAL ALERT: " + criticalAlert);
        System.out.println("⚠️  STANDARD ALERT: " + standardAlert);
        System.out.println("📱 NOTIFICATION: " + notificationOnly);

        // Auto-actions
        if (criticalAlert) {
            System.out.println("Actions: Police notified + Sirens activated");
        } else if (standardAlert) {
            System.out.println("Actions: Owner notified + Lights activated");
        } else if (notificationOnly) {
            System.out.println("Actions: Logged for review");
        } else {
            System.out.println("Status: All clear");
        }

        scanner.close();
    }
}

    Program 5: Selenium Wait Condition Builder (Automation Prep)

    import java.util.Scanner;

public class SeleniumWaitBuilder {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Selenium Smart Wait Builder ===");

        // Simulating element states
        System.out.print("Element exists (true/false): ");
        boolean exists = scanner.nextBoolean();

        System.out.print("Element is visible (true/false): ");
        boolean visible = scanner.nextBoolean();

        System.out.print("Element is enabled (true/false): ");
        boolean enabled = scanner.nextBoolean();

        System.out.print("Element text is not empty (true/false): ");
        boolean hasText = scanner.nextBoolean();

        System.out.print("Loading spinner present (true/false): ");
        boolean loading = scanner.nextBoolean();

        System.out.print("Error message displayed (true/false): ");
        boolean errorDisplayed = scanner.nextBoolean();

        // Standard clickable condition
        boolean isClickable = exists && visible && enabled && !loading;

        // Safe to interact (no errors, ready state)
        boolean safeToInteract = isClickable && !errorDisplayed;

        // Ready for assertion (text loaded, stable)
        boolean readyForCheck = exists && visible && hasText && !loading;

        // Wait should continue (not ready yet)
        boolean shouldKeepWaiting = !safeToInteract && !errorDisplayed;

        // Fail fast condition (error state)
        boolean shouldFail = errorDisplayed || (exists && !visible && !loading);

        System.out.println("\n=== Wait Logic ===");
        System.out.println("Element clickable: " + isClickable);
        System.out.println("Safe to interact: " + safeToInteract);
        System.out.println("Ready for assertion: " + readyForCheck);
        System.out.println("⏳ Continue waiting: " + shouldKeepWaiting);
        System.out.println("❌ Fail test: " + shouldFail);

        // Complex wait strategy
        System.out.println("\n=== Recommended Action ===");
        if (safeToInteract) {
            System.out.println("✅ PROCEED: Click/interact with element");
        } else if (shouldFail) {
            System.out.println("❌ ABORT: Error state detected");
        } else if (!exists) {
            System.out.println("⏳ WAIT: Element not in DOM yet");
        } else if (loading) {
            System.out.println("⏳ WAIT: Page still loading");
        } else if (!visible) {
            System.out.println("⏳ WAIT: Element not visible (scrolling/animation?)");
        } else if (!enabled) {
            System.out.println("⏳ WAIT: Element disabled");
        }

        // Timeout calculation
        int baseTimeout = 10;
        int extendedTimeout = (loading || !exists) ? baseTimeout * 2 : baseTimeout;
        System.out.println("Suggested timeout: " + extendedTimeout + " seconds");

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Single & or | if (a & b) Bitwise AND, not logical if (a && b) for logical
    Assignment in condition if (ready = true) Assigns true, always passes if (ready == true) or if (ready)
    Missing parentheses if (a && b \|\| c) Unclear precedence if ((a && b) \|\| c) be explicit
    NOT with comparison if (!x == 5) Parses as (!x) == 5 if (!(x == 5)) or if (x != 5)
    Null check order if (str.equals("test")) NPE if str is null if ("test".equals(str)) or if (str != null && str.equals("test"))
    Over-complicating if (x == true) Redundant if (x) is cleaner

    🔑 7. Quick Rules Checklist

    ✅ Logical Rules

    • [ ] && (AND): Both must be true
    • [ ] \|\| (OR): At least one must be true
    • [ ] ! (NOT): Reverses boolean
    • [ ] Short-circuit: Evaluation stops when result is known
    • [ ] Precedence: ! > && > \|\| (use parentheses!)

    ✅ Best Practices

    • [ ] Put cheaper/lighter checks first for short-circuit benefit
    • [ ] Use parentheses to make complex logic readable
    • [ ] Decompose complex conditions into named booleans
    • [ ] Use ! sparingly - positive conditions are easier to read
    • [ ] For null checks, put null check BEFORE method call: if (obj != null && obj.isValid())

    Summary

    Operator Name Use Case
    && AND Both conditions required
    \|\| OR At least one condition acceptable
    ! NOT Negate a condition

    Pro Tips: - Use short-circuit to your advantage (cheap checks first) - Decompose complex logic: boolean canProceed = isValid && isReady && !isBlocked; - Always use && and \|\| (not single & or |) for boolean logic
