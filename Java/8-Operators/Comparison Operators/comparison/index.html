    Section 11: Comparison (Relational) Operators

    1. Comparison Operators Overview

    Operator Name Description Example Result
    == Equal to Checks if values are equal 5 == 5 true
    != Not equal to Checks if values are different 5 != 3 true
    > Greater than Left is larger than right 5 > 3 true
    < Less than Left is smaller than right 5 < 3 false
    >= Greater than or equal Left is larger or equal 5 >= 5 true
    <= Less than or equal Left is smaller or equal 5 <= 3 false

    2. How Comparisons Work

    Boolean Results

    All comparison operators return a boolean (true or false):

    int a = 10;
int b = 20;

boolean result1 = a == b;  // false
boolean result2 = a < b;     // true
boolean result3 = a != b;   // true

    Comparison with Different Types

    // Numbers
int x = 5;
double y = 5.0;
System.out.println(x == y);  // true (5 equals 5.0)

// Characters (compared by ASCII/Unicode value)
char c = 'A';  // ASCII 65
int i = 65;
System.out.println(c == i);  // true

// BUT: Strings are different!
String s1 = "hello";
String s2 = "hello";
System.out.println(s1 == s2);   // Sometimes true (same object)
System.out.println(s1.equals(s2));  // Always true (same content)

    3. The Critical Difference: == vs .equals()

    Aspect == (Operator) .equals() (Method)
    Primitives Compares values N/A (doesn't work)
    Objects Compares memory addresses Compares content
    Strings May give wrong results Always correct for content
    Selenium Checks if same WebElement Checks if same text/attribute

    String Comparison Examples

    // WRONG way for strings
String password = scanner.nextLine();
if (password == "secret123") {  // DON'T DO THIS!
    // May fail even if text matches
}

// RIGHT way for strings
if (password.equals("secret123")) {  // CORRECT!
    // Compares actual text content
}

// Case-insensitive comparison
if (username.equalsIgnoreCase("Admin")) {
    // "admin", "ADMIN", "Admin" all match
}

    4. Complete Working Examples

    Example 1: Number Comparison

    import java.util.Scanner;

public class NumberComparison {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter first number: ");
        int num1 = scanner.nextInt();

        System.out.print("Enter second number: ");
        int num2 = scanner.nextInt();

        // All comparisons
        System.out.println(num1 + " == " + num2 + " : " + (num1 == num2));
        System.out.println(num1 + " != " + num2 + " : " + (num1 != num2));
        System.out.println(num1 + " > " + num2 + " : " + (num1 > num2));
        System.out.println(num1 + " < " + num2 + " : " + (num1 < num2));
        System.out.println(num1 + " >= " + num2 + " : " + (num1 >= num2));
        System.out.println(num1 + " <= " + num2 + " : " + (num1 <= num2));

        scanner.close();
    }
}

    import java.util.Scanner;

public class LoginValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Stored credentials (simulated database)
        String correctUsername = "tester";
        String correctPassword = "pass123";

        System.out.println("=== Login System ===");

        System.out.print("Username: ");

        System.out.print("Password: ");
        String password = scanner.nextLine();

        // CORRECT string comparison
        boolean userMatch = username.equals(correctUsername);
        boolean passMatch = password.equals(correctPassword);

        // Case-insensitive username check
        boolean userMatchIgnoreCase = username.equalsIgnoreCase(correctUsername);

        System.out.println("\n=== Results ===");
        System.out.println("Username exact match: " + userMatch);
        System.out.println("Username case-insensitive match: " + userMatchIgnoreCase);
        System.out.println("Password match: " + passMatch);

        if (userMatch && passMatch) {
            System.out.println("✅ Login successful!");
        } else {
            System.out.println("❌ Login failed!");
            if (!userMatch) System.out.println("   - Username incorrect");
            if (!passMatch) System.out.println("   - Password incorrect");
        }

        scanner.close();
    }
}

    Program 2: Grade Calculator

    import java.util.Scanner;

public class GradeCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter score (0-100): ");
        int score = scanner.nextInt();

        // Validate range first
        if (score < 0 || score > 100) {
            System.out.println("Invalid score! Must be 0-100.");
            scanner.close();
            return;
        }

        // Determine grade using comparisons
        char grade;
        if (score >= 90) {
            grade = 'A';
        } else if (score >= 80) {
            grade = 'B';
        } else if (score >= 70) {
            grade = 'C';
        } else if (score >= 60) {
            grade = 'D';
        } else {
            grade = 'F';
        }

        // Additional checks
        boolean isPassing = score >= 60;
        boolean isExcellent = score >= 95;
        boolean needsImprovement = score < 70 && score >= 60;

        System.out.println("\n=== Grade Report ===");
        System.out.println("Score: " + score);
        System.out.println("Grade: " + grade);
        System.out.println("Passing: " + isPassing);
        System.out.println("Excellent: " + isExcellent);
        System.out.println("Needs improvement: " + needsImprovement);

        scanner.close();
    }
}

    Program 3: Number Guessing Game

    import java.util.Scanner;
import java.util.Random;

public class NumberGuessingGame {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();

        int secretNumber = random.nextInt(100) + 1;  // 1 to 100
        int attempts = 0;
        int guess = 0;

        System.out.println("=== Number Guessing Game (1-100) ===");

        while (guess != secretNumber) {
            System.out.print("Enter your guess: ");
            guess = scanner.nextInt();
            attempts++;

            // Comparisons guide the player
            if (guess < 1 || guess > 100) {
                System.out.println("Out of range! Guess between 1-100.");
            } else if (guess < secretNumber) {
                System.out.println("Too low! Try higher.");
            } else if (guess > secretNumber) {
                System.out.println("Too high! Try lower.");
            } else {
                System.out.println("🎉 Correct! You got it in " + attempts + " attempts!");
            }

            // Hint after 5 attempts
            if (attempts == 5 && guess != secretNumber) {
                if (secretNumber % 2 == 0) {
                    System.out.println("Hint: The number is even.");
                } else {
                    System.out.println("Hint: The number is odd.");
                }
            }
        }

        scanner.close();
    }
}

    Program 4: E-commerce Discount Engine

    import java.util.Scanner;

public class DiscountEngine {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter purchase amount: $");
        double amount = scanner.nextDouble();

        System.out.print("Is customer a member? (true/false): ");
        boolean isMember = scanner.nextBoolean();

        System.out.print("Enter coupon code (or 'none'): ");
        String coupon = scanner.next();

        double discount = 0;

        // Amount-based discounts
        if (amount >= 500) {
            discount += 20;  // $500+ gets 20% off
        } else if (amount >= 200) {
            discount += 10;  // $200+ gets 10% off
        } else if (amount >= 100) {
            discount += 5;   // $100+ gets 5% off
        }

        // Member bonus
        if (isMember) {
            discount += 5;   // Extra 5% for members
        }

        // Coupon check (string comparison)
        if (coupon.equals("SAVE20")) {
            discount += 20;
        } else if (coupon.equals("SAVE10")) {
            discount += 10;
        }

        // Cap discount at 50%
        if (discount > 50) {
            discount = 50;
        }

        // Calculate final
        double discountAmount = amount * (discount / 100);
        double finalAmount = amount - discountAmount;

        System.out.println("\n=== Discount Summary ===");
        System.out.println("Original: $" + amount);
        System.out.println("Discount: " + discount + "% (-$" + discountAmount + ")");
        System.out.println("Final: $" + finalAmount);

        // Free shipping check
        boolean freeShipping = finalAmount > 50 || isMember;
        System.out.println("Free shipping: " + freeShipping);

        scanner.close();
    }
}

    Program 5: Selenium Element Validator (Automation Prep)

    import java.util.Scanner;

public class ElementValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Simulated element properties (from Selenium WebDriver)
        System.out.println("=== Selenium Element Validator ===");

        System.out.print("Element text content: ");
        String elementText = scanner.nextLine();

        System.out.print("Expected text: ");
        String expectedText = scanner.nextLine();

        System.out.print("Element count found: ");
        int elementCount = scanner.nextInt();

        System.out.print("Expected minimum count: ");
        int minExpected = scanner.nextInt();

        scanner.nextLine();  // Clear buffer

        System.out.print("Page title: ");
        String pageTitle = scanner.nextLine();

        // Validation checks using comparisons
        boolean textMatch = elementText.equals(expectedText);
        boolean textContains = elementText.contains(expectedText);
        boolean countValid = elementCount >= minExpected;
        boolean exactlyOne = elementCount == 1;
        boolean titleCorrect = pageTitle.equals("Dashboard") || 
                              pageTitle.equals("Home");

        System.out.println("\n=== Validation Results ===");
        System.out.println("Text exact match: " + textMatch);
        System.out.println("Text contains expected: " + textContains);
        System.out.println("Count meets minimum: " + countValid);
        System.out.println("Exactly one element: " + exactlyOne);
        System.out.println("Title valid: " + titleCorrect);

        // Overall test pass/fail
        boolean testPassed = (textMatch || textContains) && countValid;
        System.out.println("\nTest Result: " + (testPassed ? "✅ PASSED" : "❌ FAILED"));

        // Additional checks
        if (!elementText.isEmpty()) {
            System.out.println("Element has content: true");
        }

        if (elementCount > 0) {
            System.out.println("Elements present: true");
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Assignment instead of comparison if (x = 5) Assigns 5 to x, always true if (x == 5) for comparison
    String comparison with == if (input == "yes") Compares object references if (input.equals("yes"))
    Null pointer on equals if (str.equals("test")) Throws exception if str is null if ("test".equals(str)) or if (str != null && str.equals("test"))
    Floating point equality if (price == 10.99) Precision issues if (Math.abs(price - 10.99) < 0.001)
    Chained comparisons if (5 < x < 10) Syntax error if (x > 5 && x < 10)
    Char vs String if (grade == "A") Char vs String mismatch if (grade == 'A') for char

    7. Quick Rules Checklist

    ✅ Comparison Rules

    • [ ] == compares values for primitives, references for objects
    • [ ] .equals() compares content for objects (especially Strings)
    • [ ] >= and <= include the boundary value
    • [ ] Comparisons return boolean (true/false)
    • [ ] Never use == for String content comparison

    ✅ Best Practices

    • [ ] Use .equalsIgnoreCase() for case-insensitive string checks
    • [ ] Check for null before calling .equals() on variables
    • [ ] Use Objects.equals(a, b) for null-safe comparison (Java 7+)
    • [ ] For floating points, use epsilon comparison (difference < small value)
    • [ ] Chain ranges with &&: if (x >= min && x <= max)

    8. Selenium Connection

    Real Automation Use Cases

    Scenario Comparison Use Code Example
    Verify page title .equals() driver.getTitle().equals("Expected Title")
    Check element count ==, >, < driver.findElements(By.xpath("...")).size() >= 1
    Validate URL .contains() driver.getCurrentUrl().contains("/dashboard")

    Check visibility == element.isDisplayed() == true

String expectedText = "Welcome";

boolean textMatches = actualText.equalsIgnoreCase(expectedText);
boolean textContains = actualText.contains(expectedText);

// Even better: Check multiple conditions
if (actualText != null && !actualText.isEmpty()) {

        System.out.println("Partial match acceptable");
    }
}
