    Arithmetic Operators

    1. Arithmetic Operators Overview

    Operator Name Description Example Result
    + Addition Adds two values 5 + 3 8
    - Subtraction Subtracts right from left 5 - 3 2
    * Multiplication Multiplies two values 5 * 3 15
    / Division Divides left by right 5 / 3 1 (int) or 1.67 (double)
    % Modulo (Remainder) Returns division remainder 5 % 3 2
    ++ Increment Adds 1 to value ++a or a++ a + 1
    -- Decrement Subtracts 1 from value --a or a-- a - 1

    2. Increment & Decrement Deep Dive

    Pre vs Post - The Critical Difference

    Type Syntax When Value Changes Use Case
    Pre-increment ++a Before expression is evaluated When you need the new value immediately
    Post-increment a++ After expression is evaluated When you need the old value first

    Visual Comparison

    int a = 5;
int b = ++a;  // a becomes 6, THEN b gets 6
// Result: a = 6, b = 6

int c = 5;
int d = c++;  // d gets 5, THEN c becomes 6  
// Result: c = 6, d = 5

    Memory Step-by-Step

    POST-INCREMENT (a++):
┌─────────┐     ┌─────────┐     ┌─────────┐
│ a = 5   │ ──→ │ d = a   │ ──→ │ a = a+1 │
│         │     │ (d=5)   │     │ (a=6)   │
└─────────┘     └─────────┘     └─────────┘

PRE-INCREMENT (++a):
┌─────────┐     ┌─────────┐     ┌─────────┐
│ a = 5   │ ──→ │ a = a+1 │ ──→ │ b = a   │
│         │     │ (a=6)   │     │ (b=6)   │
└─────────┘     └─────────┘     └─────────┘

    3. Complete Working Examples

    Example 1: Basic Calculator

    import java.util.Scanner;

public class BasicCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter first number: ");
        double num1 = scanner.nextDouble();

        System.out.print("Enter second number: ");
        double num2 = scanner.nextDouble();

        // All arithmetic operations
        System.out.println("Addition: " + (num1 + num2));
        System.out.println("Subtraction: " + (num1 - num2));
        System.out.println("Multiplication: " + (num1 * num2));
        System.out.println("Division: " + (num1 / num2));
        System.out.println("Modulo: " + (num1 % num2));

        scanner.close();
    }
}

    Example 2: Shopping Cart Calculator

    public class ShoppingCart {
    public static void main(String[] args) {
        double item1 = 29.99;
        double item2 = 15.50;
        double item3 = 8.99;
        int quantity = 3;

        // Calculate subtotal
        double subtotal = item1 + item2 + item3;

        // Apply quantity multiplier
        subtotal = subtotal * quantity;  // Can also write: subtotal *= quantity

        // Calculate tax (8%)
        double tax = subtotal * 0.08;

        // Final total
        double total = subtotal + tax;

        System.out.println("Subtotal: $" + subtotal);
        System.out.println("Tax (8%): $" + tax);
        System.out.println("Total: $" + total);
    }
}

    4. Five Practical Programs (Copy-Paste Ready)

    Program 1: Score Calculator (Post-Increment)

    import java.util.Scanner;

public class ScoreCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int currentScore = 100;
        int bonusPoints = 10;

        System.out.println("=== Score Calculator ===");
        System.out.println("Current Score: " + currentScore);

        // Post-increment: use value, THEN add
        int newScore = currentScore++ + bonusPoints;

        System.out.println("New Score (with post-increment): " + newScore);
        System.out.println("Current Score after increment: " + currentScore);

        scanner.close();
    }
}

    Expected Output:

    Current Score: 100
New Score (with post-increment): 110
Current Score after increment: 101

    Program 2: Level Up System (Pre-Increment)

    import java.util.Scanner;

public class LevelUpSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int playerLevel = 5;
        int experienceNeeded = 100;

        System.out.println("=== RPG Level System ===");
        System.out.println("Current Level: " + playerLevel);

        // Pre-increment: add first, THEN use value
        int nextLevelCost = ++playerLevel * experienceNeeded;

        System.out.println("Next Level: " + playerLevel);
        System.out.println("XP needed for next level: " + nextLevelCost);

        // Reset for comparison
        playerLevel = 5;
        int wrongCost = playerLevel++ * experienceNeeded;
        System.out.println("WRONG calculation (post-increment): " + wrongCost);
        System.out.println("Level after wrong calc: " + playerLevel);

        scanner.close();
    }
}

    Expected Output:

    Current Level: 5
Next Level: 6
XP needed for next level: 600
WRONG calculation (post-increment): 500
Level after wrong calc: 6

    Program 3: Order Counter (Loop Simulation)

    import java.util.Scanner;

public class OrderCounter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int orderNumber = 1000;
        int processedToday = 0;

        System.out.println("=== Order Processing System ===");

        // Simulate processing 5 orders
        System.out.println("Processing order: " + orderNumber++);  // 1000, then becomes 1001

        System.out.println("Processing order: " + orderNumber++);  // 1001, then becomes 1002

    Program 4: Bank Interest Calculator

    import java.util.Scanner;

public class BankInterest {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter principal amount: $");
        double principal = scanner.nextDouble();

        System.out.print("Enter annual interest rate (as decimal, e.g., 0.05 for 5%): ");
        double rate = scanner.nextDouble();

        System.out.print("Enter time in years: ");
        int years = scanner.nextInt();

        // Simple interest formula: A = P(1 + rt)
        double amount = principal * (1 + rate * years);
        double interest = amount - principal;

        System.out.println("\n=== Interest Calculation ===");
        System.out.println("Principal: $" + principal);
        System.out.println("Interest earned: $" + interest);
        System.out.println("Total amount: $" + amount);

        // Compound interest (year by year using increment)
        double compoundPrincipal = principal;
        int yearCounter = 1;

        System.out.println("\n=== Year-by-Year Compound Growth ===");
        while (yearCounter <= years) {
            compoundPrincipal = compoundPrincipal * (1 + rate);
            System.out.println("Year " + yearCounter + ": $" + compoundPrincipal);
            yearCounter++;  // Post-increment
        }

        scanner.close();
    }
}

    Program 5: Pagination Calculator (Selenium Prep)

    import java.util.Scanner;

public class PaginationCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter total number of items: ");
        int totalItems = scanner.nextInt();

        System.out.print("Enter items per page: ");
        int itemsPerPage = scanner.nextInt();

        // Calculate total pages using division and modulo
        int fullPages = totalItems / itemsPerPage;
        int remainingItems = totalItems % itemsPerPage;

        // If there are remaining items, we need one more page
        int totalPages = fullPages + (remainingItems > 0 ? 1 : 0);

        System.out.println("\n=== Pagination Results ===");
        System.out.println("Total items: " + totalItems);
        System.out.println("Items per page: " + itemsPerPage);
        System.out.println("Full pages: " + fullPages);
        System.out.println("Items on last page: " + (remainingItems > 0 ? remainingItems : itemsPerPage));
        System.out.println("Total pages to navigate: " + totalPages);

        // Simulate page navigation using increment
        System.out.println("\n=== Page Navigation Simulation ===");
        int currentPage = 1;

        while (currentPage <= totalPages) {
            System.out.println("Navigating to page " + currentPage++);
        }

        scanner.close();
    }
}

    Expected Output:

    Enter total number of items: 25
Enter items per page: 10

=== Pagination Results ===
Total items: 25
Items per page: 10
Full pages: 2
Items on last page: 5
Total pages to navigate: 3

=== Page Navigation Simulation ===
Navigating to page 1
Navigating to page 2
Navigating to page 3

    5. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Integer Division int result = 5 / 2; // Result: 2 Loses decimal part double result = 5.0 / 2; // Result: 2.5
    Modulo with Negative -5 % 3 // Result: -2 Sign follows dividend Use Math.abs() if needed
    Pre vs Post Confusion int x = a++ + ++a; // Unpredictable Multiple increments in one line Split into separate statements
    Dividing by Zero int x = 5 / 0; Runtime exception Check divisor: if (b != 0) result = a / b;
    Lost Increment a++; alone on line Value not used Assign or use in expression: b = a++;

    6. Quick Rules Checklist

    Arithmetic Rules

    • [ ] Integer division truncates - always cast to double for decimals
    • [ ] Modulo sign follows dividend: -5 % 3 = -2, 5 % -3 = 2
    • [ ] Division by zero throws ArithmeticException for integers
    • [ ] Use compound operators (+=, -=) for cleaner code

    Increment/Decrement Rules

    • [ ] Pre (++a): Change first, then use (for immediate updates)
    • [ ] Post (a++): Use first, then change (for current value preservation)
    • [ ] Never chain multiple increments in one expression
    • [ ] In loops, post-increment (i++) is standard convention
