    Input (Scanner Class)

    What is Scanner?

    Scanner = Class to read user input from keyboard

    import java.util.Scanner;  // Required import!

Scanner sc = new Scanner(System.in);
String input = sc.next();  // Read input

    Scanner Methods (5 Types)

    Method Input Type Example Use Case
    next() Word name = sc.next(); Single word
    nextLine() Full line address = sc.nextLine(); Sentence
    nextInt() Integer age = sc.nextInt(); Numbers
    nextDouble() Decimal salary = sc.nextDouble(); Money
    nextBoolean() true/false isValid = sc.nextBoolean(); Yes/No

    Complete Scanner Example

    import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter your name: ");
        String name = sc.next();

        System.out.print("Enter your age: ");
        int age = sc.nextInt();

        System.out.print("Enter salary: ");
        double salary = sc.nextDouble();

        System.out.println("Hello " + name);
        System.out.println("Age: " + age);
        System.out.println("Salary: Rs." + salary);

        sc.close();  // Good practice
    }
}

    Sample Run:

    Enter your name: John
Enter your age: 25
Enter salary: 50000.50
Hello John
Age: 25
Salary: Rs.50000.5

    Practice 1: Simple Calculator

    import java.util.Scanner;

public class Practice1 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter first number: ");
        int num1 = sc.nextInt();
        System.out.print("Enter second number: ");
        int num2 = sc.nextInt();

        System.out.println("Sum: " + (num1 + num2));
        System.out.println("Product: " + (num1 * num2));

        sc.close();
    }
}

    Practice 2: Student Grade System

    import java.util.Scanner;

public class Practice2 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter student name: ");
        String name = sc.next();
        System.out.print("Enter marks (0-100): ");
        int marks = sc.nextInt();

        String grade = (marks >= 90) ? "A" : (marks >= 75) ? "B" : "C";

        System.out.println(name + " got grade: " + grade);
        sc.close();
    }
}

    Practice 3: BMI Calculator

    import java.util.Scanner;

public class Practice3 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Enter weight (kg): ");
        double weight = sc.nextDouble();
        System.out.print("Enter height (m): ");
        double height = sc.nextDouble();

        double bmi = weight / (height * height);
        System.out.printf("Your BMI: %.2f\n", bmi);

        if(bmi < 18.5) {
            System.out.println("Underweight");
        } else if(bmi < 25) {
            System.out.println("Normal");
        } else {
            System.out.println("Overweight");
        }
        sc.close();
    }
}

    Practice 5: Complete Registration Form

    import java.util.Scanner;

public class Practice5 {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("Full Name: ");
        String name = sc.nextLine();

        System.out.print("Age: ");
        int age = sc.nextInt();
        sc.nextLine();  // Clear buffer

        System.out.print("Email: ");
        String email = sc.nextLine();

        System.out.print("Phone: ");
        long phone = sc.nextLong();

        System.out.println("\n=== Registration Summary ===");
        System.out.println("Name: " + name);
        System.out.println("Age: " + age);
        System.out.println("Email: " + email);
        System.out.println("Phone: " + phone);

        sc.close();
    }
}

    Scanner Common Errors & Fixes

    Error 1: nextInt() after nextLine()

    // ❌ Wrong - Buffer issue
String name = sc.nextLine();
int age = sc.nextInt();  // May skip!

// ✅ Fix - Clear buffer
String name = sc.nextLine();
sc.nextLine();  // Clear leftover
int age = sc.nextInt();

    Error 2: Wrong Input Type

    Input Mismatch Exception!
Enter number: ABC  // Error!

    Fix: Use try-catch (advanced) or validate input.

    Error 3: Forget import

    // ❌ Error!
Scanner sc = new Scanner(System.in);  // Class not found

// ✅ Correct
import java.util.Scanner;

    Scanner Golden Rules

    1. ALWAYS import java.util.Scanner
2. Create Scanner ONCE: Scanner sc = new Scanner(System.in);
3. Use nextLine() for sentences
4. Clear buffer after nextInt(): sc.nextLine();
5. ALWAYS close: sc.close();
6. Match method with data type
