    Output & Input (Print Types)

    3 Types of Print Statements

    Type Syntax What it does Example Output
    print() System.out.print("text"); Prints without new line HelloWorld
    println() System.out.println("text"); Prints with new line Hello
    World
    printf() System.out.printf("format", value); Formatted output Age: 25

    All 3 Types - Complete Examples

    1. print() vs println() Difference

    public class PrintDemo {
    public static void main(String[] args) {
        System.out.print("Hello");
        System.out.print("World");      // No newline
        System.out.println("!");        // Newline here

        System.out.println("Line 1");
        System.out.println("Line 2");
    }
}

    Output:

    HelloWorld!
Line 1
Line 2

    2. printf() - Formatted Output

    public class PrintfDemo {
    public static void main(String[] args) {
        int age = 25;
        String name = "John";
        double salary = 50000.50;

        // %s = String, %d = int, %f = float
        System.out.printf("Name: %s\n", name);
        System.out.printf("Age: %d\n", age);
        System.out.printf("Salary: $%.2f\n", salary);
    }
}

    Output:

    Name: John
Age: 25
Salary: $50000.50

    3. Mixed Usage (Real-World)

    public class MixedPrint {
    public static void main(String[] args) {
        System.out.println("=== Student Report ===");
        System.out.print("Name: ");
        System.out.println("Alice");
        System.out.printf("Marks: %d%%\n", 85);
        System.out.print("Status: ");
        System.out.println("PASS");
    }
}

    Format Specifiers for printf()

    Specifier Data Type Example
    %s String printf("Name: %s", "John");
    %d int printf("Age: %d", 25);
    %f double/float printf("Price: %.2f", 19.99);
    %c char printf("Grade: %c", 'A');
    %% % symbol printf("Marks: %d%%", 95);

    Common Mistakes

    // ❌ Wrong
System.out.printlnf("Age: %d", 25);  // No such method

// ❌ Wrong  
System.out.printf("Age: %s", 25);    // Type mismatch

// ✅ Correct
System.out.printf("Age: %d\n", 25);

    Quick Reference

    print()     → No newline
println()   → Newline
printf()    → Formatted (use %s, %d, %f)
