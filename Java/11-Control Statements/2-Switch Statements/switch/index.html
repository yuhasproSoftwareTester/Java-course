    Switch Statement

    1. Traditional Switch Statement

    Syntax

    switch (expression) {
    case value1:
        // statements
        break;
    case value2:
        // statements
        break;
    default:
        // statements
}

    How It Works

    Expression value?
    │
    ├── matches case1 ──► Execute case1 block ──► break ──► Exit
    │
    ├── matches case2 ──► Execute case2 block ──► break ──► Exit
    │
    ├── matches case3 ──► Execute case3 block ──► (no break)
    │                      Fall through to case4 ──► Execute ──► break ──► Exit
    │
    └── no match ───────► Execute default ──► Exit

    Critical Rule: Fall-Through Behavior

    int day = 3;

switch (day) {
    case 1:
        System.out.println("Monday");
        // No break! Falls through
    case 2:
        System.out.println("Tuesday");
        // No break! Falls through
    case 3:
        System.out.println("Wednesday");
        // No break! Falls through
    case 4:
        System.out.println("Thursday");
        break;  // Finally stops
    case 5:
        System.out.println("Friday");
        break;
    default:
        System.out.println("Weekend");
}

// Output for day=3: Wednesday, Thursday

    2. Modern Switch Expression (Java 12+)

    Arrow Syntax (No break needed)

    String result = switch (day) {
    case 1, 2, 3, 4, 5 -> "Weekday";
    case 6, 7 -> "Weekend";
    default -> "Invalid";
};

    With Yield (Multi-statement)

    int result = switch (score) {
    case 90, 91, 92, 93, 94, 95, 96, 97, 98, 99, 100 -> {
        System.out.println("Excellent!");
        yield 4;  // Return value
    }
    case 80, 81, 82, 83, 84, 85, 86, 87, 88, 89 -> {
        yield 3;
    }
    default -> {
        yield 0;
    }
};

    3. What Switch Can Check

    Type Example Notes
    int, byte, short, char case 5: Primitive integers
    Integer, Character, etc. case Integer.valueOf(5): Wrapper types (auto-unboxed)
    String case "hello": Java 7+
    enum case MONDAY: Most common modern use

    Cannot Switch On

    • long, float, double, boolean
    • null (until Java 17, needs special handling)

    4. Complete Working Examples

    Example 1: Traditional Switch

    import java.util.Scanner;

public class TraditionalSwitch {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter day number (1-7): ");
        int day = scanner.nextInt();

        String dayName;
        String type;

        switch (day) {
            case 1:
                dayName = "Monday";
                type = "Weekday";
                break;
            case 2:
                dayName = "Tuesday";
                type = "Weekday";
                break;
            case 3:
                dayName = "Wednesday";
                type = "Weekday";
                break;
            case 4:
                dayName = "Thursday";
                type = "Weekday";
                break;
            case 5:
                dayName = "Friday";
                type = "Weekday";
                break;
            case 6:
                dayName = "Saturday";
                type = "Weekend";
                break;
            case 7:
                dayName = "Sunday";
                type = "Weekend";
                break;
            default:
                dayName = "Invalid";
                type = "Unknown";
        }

        System.out.println("Day: " + dayName);
        System.out.println("Type: " + type);

        scanner.close();
    }
}

    Example 2: Fall-Through Pattern

    import java.util.Scanner;

public class FallThroughExample {
    public static void main(String[] args) {

        String season;

            case 4:
            case 5:
                season = "Spring";
                break;
            case 6:
            case 7:
            case 8:
                season = "Summer";
                break;

            case 10:
            case 11:

                break;
            default:
                season = "Invalid month";
        }

        System.out.println("Month " + month + " is in " + season);

        scanner.close();
    }
}

    Example 3: Modern Switch Expression

    import java.util.Scanner;

public class ModernSwitch {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter grade (A/B/C/D/F): ");
        char grade = scanner.next().toUpperCase().charAt(0);

        // Modern switch expression with arrow syntax
        String message = switch (grade) {
            case 'A' -> "Excellent! 90-100%";
            case 'B' -> "Good job! 80-89%";
            case 'C' -> "Satisfactory 70-79%";
            case 'D' -> "Passing 60-69%";
            case 'F' -> "Failing below 60%";
            default -> "Invalid grade";
        };

        // With yield for complex logic
        int points = switch (grade) {
            case 'A' -> {
                System.out.println("Honor roll!");
                yield 4;
            }
            case 'B' -> 3;
            case 'C' -> 2;
            case 'D' -> 1;
            case 'F' -> 0;
            default -> -1;
        };

        System.out.println("Message: " + message);
        System.out.println("Grade points: " + points);

        scanner.close();
    }
}

    Program 1: Menu System (Traditional)

    import java.util.Scanner;

public class MenuSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Main Menu ===");
        System.out.println("1. View Profile");
        System.out.println("2. Edit Settings");
        System.out.println("3. View Reports");
        System.out.println("4. Export Data");
        System.out.println("5. Logout");
        System.out.print("Select option: ");

        int choice = scanner.nextInt();
        String action = "";
        boolean valid = true;

        switch (choice) {
            case 1:
                action = "Displaying user profile...";
                break;
            case 2:
                action = "Opening settings panel...";
                break;
            case 3:
                action = "Loading reports...";
                break;
            case 4:
                action = "Preparing export...";
                break;
            case 5:
                action = "Logging out...";
                break;
            default:
                action = "Invalid selection";
                valid = false;
        }

        System.out.println(action);

        if (valid) {
            System.out.println("Operation completed successfully.");
        } else {
            System.out.println("Please try again.");
        }

        scanner.close();
    }
}

    Program 2: HTTP Status Code Handler

    import java.util.Scanner;

public class HTTPStatusHandler {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter HTTP status code: ");
        int code = scanner.nextInt();

        String category;
        String description;
        String action;

        // First digit determines category
        switch (code / 100) {
            case 1:
                category = "Informational";
                description = "Request received, continuing process";
                action = "Wait for final response";
                break;
            case 2:
                category = "Success";
                description = "Request successfully processed";
                action = "Proceed with next step";
                break;
            case 3:
                category = "Redirection";
                description = "Further action needs to be taken";
                action = "Follow redirect location";
                break;
            case 4:
                category = "Client Error";
                description = "Request contains bad syntax or cannot be fulfilled";
                action = "Fix request and retry";
                break;
            case 5:
                category = "Server Error";
                description = "Server failed to fulfill valid request";
                action = "Retry later or contact support";
                break;
            default:
                category = "Unknown";
                description = "Invalid status code";
                action = "Check code validity";
        }

        // Specific codes (nested switch concept using if-else for precision)
        String specific = "";
        switch (code) {
            case 200:
                specific = "OK";
                break;
            case 201:
                specific = "Created";
                break;
            case 204:
                specific = "No Content";
                break;
            case 400:
                specific = "Bad Request";
                break;
            case 401:
                specific = "Unauthorized";
                break;
            case 403:
                specific = "Forbidden";
                break;
            case 404:
                specific = "Not Found";
                break;
            case 500:
                specific = "Internal Server Error";
                break;
            case 502:
                specific = "Bad Gateway";
                break;
            case 503:
                specific = "Service Unavailable";
                break;
        }

        System.out.println("\n=== Status Analysis ===");
        System.out.println("Code: " + code);
        System.out.println("Category: " + category);
        if (!specific.isEmpty()) {
            System.out.println("Specific: " + specific);
        }
        System.out.println("Description: " + description);
        System.out.println("Recommended Action: " + action);

        // Retry logic
        boolean shouldRetry = (code == 408 || code == 429 || code == 500 || 
                              code == 502 || code == 503 || code == 504);

        if (shouldRetry) {
            System.out.println("This error is retryable. Attempt again after delay.");
        }

        scanner.close();
    }
}

    Program 3: Currency Converter (Modern Switch)

    import java.util.Scanner;

public class CurrencyConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Available currencies: USD, EUR, GBP, JPY, CAD, AUD");
        System.out.print("Convert from: ");
        String from = scanner.next().toUpperCase();

        System.out.print("Convert to: ");
        String to = scanner.next().toUpperCase();

        System.out.print("Amount: ");
        double amount = scanner.nextDouble();

        // Exchange rates to USD (base)
        double toUSD = switch (from) {
            case "USD" -> 1.0;
            case "EUR" -> 1.09;
            case "GBP" -> 1.27;
            case "JPY" -> 0.0067;
            case "CAD" -> 0.74;
            case "AUD" -> 0.65;
            default -> -1;
        };

        if (toUSD == -1) {
            System.out.println("Invalid source currency");
            scanner.close();
            return;
        }

        // Convert to USD first, then to target
        double inUSD = amount * toUSD;

        double result = switch (to) {
            case "USD" -> inUSD;
            case "EUR" -> inUSD / 1.09;
            case "GBP" -> inUSD / 1.27;
            case "JPY" -> inUSD / 0.0067;
            case "CAD" -> inUSD / 0.74;
            case "AUD" -> inUSD / 0.65;
            default -> -1;
        };

        if (result == -1) {
            System.out.println("Invalid target currency");
            scanner.close();
            return;
        }

        // Currency symbols
        String symbol = switch (to) {
            case "USD" -> "$";
            case "EUR" -> "€";
            case "GBP" -> "£";
            case "JPY" -> "¥";
            case "CAD" -> "C$";
            case "AUD" -> "A$";
            default -> "";
        };

        System.out.printf("\n%.2f %s = %s%.2f %s%n", 
            amount, from, symbol, result, to);

        scanner.close();
    }
}

    Program 4: Roman Numeral Converter

    import java.util.Scanner;

public class RomanNumeralConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter digit (1-9): ");
        int digit = scanner.nextInt();

        System.out.print("Position (1=ones, 2=tens, 3=hundreds, 4=thousands): ");
        int position = scanner.nextInt();

        String roman = "";

        // Traditional switch with fall-through pattern
        switch (position) {
            case 1: // Ones place
                switch (digit) {
                    case 1: roman = "I"; break;
                    case 2: roman = "II"; break;
                    case 3: roman = "III"; break;
                    case 4: roman = "IV"; break;
                    case 5: roman = "V"; break;
                    case 6: roman = "VI"; break;
                    case 7: roman = "VII"; break;
                    case 8: roman = "VIII"; break;
                    case 9: roman = "IX"; break;
                }
                break;
            case 2: // Tens place
                switch (digit) {
                    case 1: roman = "X"; break;
                    case 2: roman = "XX"; break;
                    case 3: roman = "XXX"; break;
                    case 4: roman = "XL"; break;
                    case 5: roman = "L"; break;
                    case 6: roman = "LX"; break;
                    case 7: roman = "LXX"; break;
                    case 8: roman = "LXXX"; break;
                    case 9: roman = "XC"; break;
                }
                break;
            case 3: // Hundreds place
                switch (digit) {
                    case 1: roman = "C"; break;
                    case 2: roman = "CC"; break;
                    case 3: roman = "CCC"; break;
                    case 4: roman = "CD"; break;
                    case 5: roman = "D"; break;
                    case 6: roman = "DC"; break;
                    case 7: roman = "DCC"; break;
                    case 8: roman = "DCCC"; break;
                    case 9: roman = "CM"; break;
                }
                break;
            case 4: // Thousands place
                switch (digit) {
                    case 1: roman = "M"; break;
                    case 2: roman = "MM"; break;
                    case 3: roman = "MMM"; break;
                    default: roman = "Number too large"; break;
                }
                break;
            default:
                roman = "Invalid position";
        }

        System.out.println("Roman numeral: " + roman);

        // Alternative: Modern switch for digit names
        String digitName = switch (digit) {
            case 1 -> "One";
            case 2 -> "Two";
            case 3 -> "Three";
            case 4 -> "Four";
            case 5 -> "Five";
            case 6 -> "Six";
            case 7 -> "Seven";
            case 8 -> "Eight";
            case 9 -> "Nine";
            default -> "Invalid";
        };

        String positionName = switch (position) {
            case 1 -> "Ones";
            case 2 -> "Tens";
            case 3 -> "Hundreds";
            case 4 -> "Thousands";
            default -> "Unknown";
        };

        System.out.println("You entered " + digitName + " in the " + positionName + " place");

        scanner.close();
    }
}

    Program 5: Calculator with Operations

    import java.util.Scanner;

public class SwitchCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter first number: ");
        double num1 = scanner.nextDouble();

        System.out.print("Enter operator (+, -, *, /, %, ^): ");
        char operator = scanner.next().charAt(0);

        System.out.print("Enter second number: ");
        double num2 = scanner.nextDouble();

        double result = 0;
        boolean valid = true;
        String operationName = "";

        switch (operator) {
            case '+':
                result = num1 + num2;
                operationName = "Addition";
                break;
            case '-':
                result = num1 - num2;
                operationName = "Subtraction";
                break;
            case '*':
            case 'x':
            case 'X':
                result = num1 * num2;
                operationName = "Multiplication";
                break;
            case '/':
                if (num2 != 0) {
                    result = num1 / num2;
                    operationName = "Division";
                } else {
                    System.out.println("Error: Cannot divide by zero");
                    valid = false;
                }
                break;
            case '%':
                if (num2 != 0) {
                    result = num1 % num2;
                    operationName = "Modulo";
                } else {
                    System.out.println("Error: Cannot modulo by zero");
                    valid = false;
                }
                break;
            case '^':
                result = Math.pow(num1, num2);
                operationName = "Power";
                break;
            default:
                System.out.println("Error: Invalid operator");
                valid = false;
        }

        if (valid) {
            System.out.println("\n=== Result ===");
            System.out.println("Operation: " + operationName);
            System.out.println(num1 + " " + operator + " " + num2 + " = " + result);

            // Additional info using modern switch
            String numberType = switch ((int)result % 2) {
                case 0 -> "Even";
                case 1, -1 -> "Odd";
                default -> "Unknown";
            };

            System.out.println("Result is " + numberType);

            if (result == Math.floor(result)) {
                System.out.println("Result is a whole number");
            } else {
                System.out.println("Result has decimal places");
            }
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Missing break case 1: x(); case 2: y(); Falls through unintentionally Add break; after each case
    Wrong types switch (3.14) Cannot switch on double Use int, String, enum
    Case expression case x > 0: Case needs constant value case 1: with if inside or use if-else
    Null string switch (str) when str is null Throws NullPointerException Check if (str != null) first
    Duplicate cases case 1: and case 1: Compile error Remove duplicate
    Boolean switch switch (flag) Cannot switch on boolean Use if (flag) instead

    7. Quick Rules Checklist

    ✅ Switch Rules

    • [ ] Expression type: int, String, enum, or wrapper
    • [ ] Case values: Must be compile-time constants
    • [ ] Break required: In traditional switch to prevent fall-through
    • [ ] Default case: Always include for unhandled values
    • [ ] No duplicates: Case values must be unique

    ✅ Traditional vs Modern

    Feature Traditional Modern (Java 12+)
    Syntax case 1: x; break; case 1 -> x
    Fall-through Yes (needs break) No (implicit break)
    Multiple cases case 1: case 2: case 1, 2 ->
    Return value No Yes (switch expression)
    Yield No yield value; for blocks

    ✅ When to Use

    Use Switch Use If-Else
    Single variable, many values Range checks (x > 5)
    int, String, enum Multiple variables
    Discrete values Complex boolean logic
    3+ branches Only 1-2 branches

    Summary

    Aspect Traditional Switch Modern Switch
    Break needed Yes No
    Fall-through Yes No
    Multiple cases case 1: case 2: case 1, 2 ->
    Return value No Yes
    Arrow syntax No ->

    Golden Rules: 1. Always use break in traditional switch (unless intentional fall-through) 2. Use modern switch (->) for cleaner code in Java 12+ 3. Include default case for unhandled values 4. Switch works with int, String, enum - not double or boolean 5. Use fall-through intentionally for grouped cases (months → seasons)
