    Nested If Statements

    1. Nested If Structure

    Basic Concept

    An inner if placed inside an outer if block. The inner if only checks if the outer if is true.

    if (outerCondition) {
    // This code runs if outer is true

    if (innerCondition) {
        // This code runs if BOTH outer AND inner are true
    } else {
        // This runs if outer true, inner false
    }

} else {
    // This runs if outer is false (inner if never checked)
}

    Visual Flow

    Outer condition?
    │
    ├── YES ──┬──► Inner condition?
    │         │       │
    │         │       ├── YES ──► Execute inner-if block
    │         │       │
    │         │       └── NO ───► Execute inner-else block
    │         │
    │         └──► (Continue after inner)
    │
    └── NO ───► Execute outer-else (skip inner completely)

    2. Levels of Nesting

    One Level Deep

    if (isLoggedIn) {
    if (isAdmin) {
        System.out.println("Admin panel");
    }
}

    Two Levels Deep

    if (isLoggedIn) {
    if (hasPermission) {
        if (resourceExists) {
            System.out.println("Access granted");
        }
    }
}

    Scope Visualization

    if (conditionA) {
    int x = 10;  // x exists here

    if (conditionB) {
        int y = 20;  // y exists here (and x too)
        System.out.println(x + y);  // Both visible
    }  // y dies here

    // System.out.println(y);  // ERROR! y not visible
}  // x dies here

    3. Common Nested Patterns

    Pattern 1: Validation Then Processing

    // First validate input, then process if valid
if (input != null) {
    if (!input.isEmpty()) {
        if (input.length() >= 3) {
            // Process valid input
        } else {
            System.out.println("Too short");
        }
    } else {
        System.out.println("Empty input");
    }
} else {
    System.out.println("Null input");
}

    Pattern 2: Category Then Subcategory

    if (category.equals("electronics")) {
    if (subcategory.equals("phones")) {
        // Phone logic
    } else if (subcategory.equals("laptops")) {
        // Laptop logic
    }
} else if (category.equals("clothing")) {
    if (subcategory.equals("shirts")) {
        // Shirt logic
    }
}

    Pattern 3: Permission Hierarchy

    if (userExists) {
    if (accountActive) {
        if (passwordCorrect) {
            if (twoFactorPassed) {
                // Login successful
            } else {
                // 2FA failed
            }
        } else {
            // Wrong password
        }
    } else {
        // Account disabled
    }
} else {
    // User not found
}

    4. Complete Working Examples

    Example 1: Number Analyzer (3 Levels)

    import java.util.Scanner;

public class NumberAnalyzer {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int num = scanner.nextInt();

        // Level 1: Check if zero
        if (num != 0) {

            // Level 2: Check positive/negative
            if (num > 0) {

                // Level 3: Check range
                if (num < 100) {
                    System.out.println("Small positive number (1-99)");
                } else {
                    System.out.println("Large positive number (100+)");
                }

            } else {
                // Level 3 for negative
                if (num > -100) {
                    System.out.println("Small negative number (-99 to -1)");
                } else {
                    System.out.println("Large negative number (-100 or less)");
                }
            }

        } else {
            System.out.println("Zero entered");
        }

        scanner.close();
    }
}

    Example 2: Authentication System (4 Levels)

    import java.util.Scanner;

public class AuthenticationSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        String validUser = "admin";
        String validPass = "secret123";
        boolean maintenanceMode = false;

        System.out.print("Username: ");
        String username = scanner.nextLine();

        System.out.print("Password: ");
        String password = scanner.nextLine();

        // Level 1: Check maintenance
        if (!maintenanceMode) {

            // Level 2: Check username
            if (username.equals(validUser)) {

                // Level 3: Check password
                if (password.equals(validPass)) {

                    // Level 4: Additional check
                    System.out.print("Enter 2FA code: ");
                    String code = scanner.nextLine();

                    if (code.equals("123456")) {
                        System.out.println("Login successful! Welcome, admin.");
                    } else {
                        System.out.println("Invalid 2FA code.");
                    }

                } else {
                    System.out.println("Incorrect password.");
                }

            } else {
                System.out.println("Username not found.");
            }

        } else {
            System.out.println("System under maintenance. Try later.");
        }

        scanner.close();
    }
}

    Program 1: University Admission System

    import java.util.Scanner;

public class UniversityAdmission {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter GPA (0.0-4.0): ");
        double gpa = scanner.nextDouble();

        System.out.print("Enter SAT score (400-1600): ");
        int sat = scanner.nextInt();
        scanner.nextLine();

        System.out.print("Any disciplinary record (true/false): ");
        boolean hasRecord = scanner.nextBoolean();

        System.out.print("In-state resident (true/false): ");
        boolean inState = scanner.nextBoolean();

        // Level 1: Check disciplinary record
        if (!hasRecord) {

            // Level 2: Check GPA minimum
            if (gpa >= 2.5) {

                // Level 3: Check SAT minimum
                if (sat >= 1000) {

                    // Level 4: Determine admission tier
                    if (gpa >= 3.5 && sat >= 1400) {
                        System.out.println("Congratulations! Accepted with full scholarship.");
                    } else if (gpa >= 3.0 && sat >= 1200) {
                        System.out.println("Accepted with partial scholarship.");
                    } else {
                        System.out.println("Accepted with standard admission.");
                    }

                    // Level 4: Residency check
                    if (inState) {
                        System.out.println("In-state tuition rate applied.");
                    } else {
                        System.out.println("Out-of-state tuition rate applied.");
                    }

                } else {
                    System.out.println("SAT score too low. Minimum 1000 required.");
                }

            } else {
                System.out.println("GPA too low. Minimum 2.5 required.");
            }

        } else {
            System.out.println("Application denied due to disciplinary record.");
        }

        scanner.close();
    }
}

    Program 2: Bank Loan Approval

    import java.util.Scanner;

public class BankLoanApproval {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Annual income: $");
        int income = scanner.nextInt();

        System.out.print("Credit score (300-850): ");
        int creditScore = scanner.nextInt();

        System.out.print("Existing debt: $");
        int existingDebt = scanner.nextInt();

        System.out.print("Requested loan amount: $");
        int loanAmount = scanner.nextInt();

        System.out.print("Employment status (employed/self-employed/unemployed): ");
        String employment = scanner.next().toLowerCase();

        // Level 1: Employment check
        if (!employment.equals("unemployed")) {

            // Level 2: Credit score check
            if (creditScore >= 600) {

                // Level 3: Debt-to-income ratio
                double debtRatio = (double) existingDebt / income;

                if (debtRatio < 0.4) {

                    // Level 4: Loan amount vs income
                    double loanRatio = (double) loanAmount / income;

                    if (loanRatio <= 3) {
                        System.out.println("Loan APPROVED!");

                        // Level 5: Interest rate tier
                        if (creditScore >= 750 && debtRatio < 0.2) {
                            System.out.println("Interest rate: 3.5% (Prime)");
                        } else if (creditScore >= 700) {
                            System.out.println("Interest rate: 5.0% (Good)");
                        } else {
                            System.out.println("Interest rate: 7.5% (Standard)");
                        }

                    } else {
                        System.out.println("Loan amount too high relative to income.");
                        System.out.println("Maximum allowed: $" + (income * 3));
                    }

                } else {
                    System.out.println("Debt-to-income ratio too high.");
                    System.out.println("Current ratio: " + String.format("%.1f%%", debtRatio * 100));
                    System.out.println("Maximum allowed: 40%");
                }

            } else {
                System.out.println("Credit score too low. Minimum 600 required.");
            }

        } else {
            System.out.println("Loan denied: Employment verification required.");
        }

        scanner.close();
    }
}

    Program 3: Restaurant Order System

    import java.util.Scanner;

public class RestaurantOrderSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Menu ===");
        System.out.println("1. Burger ($10)");
        System.out.println("2. Pizza ($15)");
        System.out.println("3. Salad ($8)");
        System.out.print("Choose item (1-3): ");
        int choice = scanner.nextInt();
        scanner.nextLine();

        int basePrice = 0;
        String itemName = "";

        // Level 1: Item selection
        if (choice == 1) {
            basePrice = 10;
            itemName = "Burger";

            // Level 2: Burger customization
            System.out.print("Add cheese? (true/false): ");
            if (scanner.nextBoolean()) {
                basePrice += 2;
                System.out.print("Extra cheese? (true/false): ");
                if (scanner.nextBoolean()) {
                    basePrice += 1;
                    itemName += " (Double Cheese)";
                } else {
                    itemName += " (Cheese)";
                }
            }

        } else if (choice == 2) {
            basePrice = 15;
            itemName = "Pizza";

            // Level 2: Pizza size
            System.out.print("Size (small/medium/large): ");
            String size = scanner.next().toLowerCase();

            if (size.equals("small")) {
                basePrice -= 3;
                itemName += " (Small)";
            } else if (size.equals("large")) {
                basePrice += 5;
                itemName += " (Large)";
            } else {
                itemName += " (Medium)";
            }

            // Level 3: Toppings
            System.out.print("Add toppings? (true/false): ");
            if (scanner.nextBoolean()) {
                System.out.print("How many toppings? ");
                int toppings = scanner.nextInt();
                basePrice += toppings * 1;
                itemName += " + " + toppings + " toppings";
            }

        } else if (choice == 3) {
            basePrice = 8;
            itemName = "Salad";

            // Level 2: Dressing
            System.out.print("Want dressing? (true/false): ");
            if (scanner.nextBoolean()) {
                scanner.nextLine();
                System.out.print("Dressing type (vinaigrette/ranch/caesar): ");
                String dressing = scanner.nextLine().toLowerCase();

                if (dressing.equals("vinaigrette")) {
                    itemName += " with Vinaigrette";
                } else if (dressing.equals("ranch")) {
                    itemName += " with Ranch";
                    basePrice += 0.5;
                } else if (dressing.equals("caesar")) {
                    itemName += " with Caesar";
                    basePrice += 0.5;
                } else {
                    itemName += " with House Dressing";
                }
            }

        } else {
            System.out.println("Invalid selection.");
            scanner.close();
            return;
        }

        // Level 1: Drink addition (applies to all)
        System.out.print("Add drink? (true/false): ");
        if (scanner.nextBoolean()) {
            System.out.print("Size (small/medium/large): ");
            String drinkSize = scanner.next().toLowerCase();

            if (drinkSize.equals("small")) {
                basePrice += 2;
            } else if (drinkSize.equals("medium")) {
                basePrice += 3;
            } else {
                basePrice += 4;
            }
            itemName += " + Drink";
        }

        System.out.println("\n=== Order Summary ===");
        System.out.println("Item: " + itemName);
        System.out.println("Total: $" + basePrice);

        scanner.close();
    }
}

    Program 4: Game Character Creator

    import java.util.Scanner;

public class GameCharacterCreator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Character Creator ===");

        System.out.print("Choose class (warrior/mage/archer): ");
        String charClass = scanner.next().toLowerCase();

        int health = 0;
        int mana = 0;
        int attack = 0;
        String specialAbility = "";

        // Level 1: Class selection
        if (charClass.equals("warrior")) {
            health = 150;
            mana = 20;
            attack = 15;

            // Level 2: Warrior specialization
            System.out.print("Specialization (berserker/paladin): ");
            String spec = scanner.next().toLowerCase();

            if (spec.equals("berserker")) {
                attack += 10;
                health -= 20;
                specialAbility = "Rage Mode";

                // Level 3: Berserker weapon
                System.out.print("Weapon (axe/sword): ");
                if (scanner.next().equalsIgnoreCase("axe")) {
                    attack += 5;
                }

            } else if (spec.equals("paladin")) {
                health += 30;
                mana += 20;
                specialAbility = "Holy Shield";
            }

        } else if (charClass.equals("mage")) {
            health = 80;
            mana = 100;
            attack = 5;

            // Level 2: Magic type
            System.out.print("Magic type (fire/ice/lightning): ");
            String magic = scanner.next().toLowerCase();

            if (magic.equals("fire")) {
                attack += 20;
                specialAbility = "Fireball";
            } else if (magic.equals("ice")) {
                attack += 15;
                health += 10;
                specialAbility = "Freeze";
            } else if (magic.equals("lightning")) {
                attack += 25;
                mana -= 20;
                specialAbility = "Thunder";
            }

            // Level 3: Staff bonus
            System.out.print("Has enchanted staff? (true/false): ");
            if (scanner.nextBoolean()) {
                mana += 30;
            }

        } else if (charClass.equals("archer")) {
            health = 100;
            mana = 40;
            attack = 12;

            // Level 2: Archer type
            System.out.print("Type (ranger/sniper): ");
            String type = scanner.next().toLowerCase();

            if (type.equals("ranger")) {
                health += 20;
                specialAbility = "Summon Pet";
            } else if (type.equals("sniper")) {
                attack += 15;
                health -= 10;
                specialAbility = "Headshot";
            }

        } else {
            System.out.println("Invalid class.");
            scanner.close();
            return;
        }

        // Level 1: Difficulty modifier
        System.out.print("Difficulty (easy/normal/hard): ");
        String difficulty = scanner.next().toLowerCase();

        if (difficulty.equals("easy")) {
            health += 50;
            mana += 30;
        } else if (difficulty.equals("hard")) {
            health -= 30;
            mana -= 20;
        }

        System.out.println("\n=== Character Stats ===");
        System.out.println("Class: " + charClass);
        System.out.println("Health: " + health);
        System.out.println("Mana: " + mana);
        System.out.println("Attack: " + attack);
        System.out.println("Special: " + specialAbility);

        scanner.close();
    }
}

    Program 5: Tax Calculator with Filing Status

    import java.util.Scanner;

public class TaxCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Annual income: $");
        double income = scanner.nextDouble();

        System.out.print("Filing status (single/married/head): ");
        String status = scanner.next().toLowerCase();

        System.out.print("Any dependents? (true/false): ");
        boolean hasDependents = scanner.nextBoolean();

        double tax = 0;
        double effectiveRate = 0;

        // Level 1: Filing status
        if (status.equals("single")) {

            // Level 2: Single brackets
            if (income <= 11000) {
                tax = income * 0.10;
            } else if (income <= 44725) {
                tax = 1100 + (income - 11000) * 0.12;
            } else if (income <= 95375) {
                tax = 5147 + (income - 44725) * 0.22;
            } else if (income <= 182100) {
                tax = 16290 + (income - 95375) * 0.24;
            } else {
                tax = 37104 + (income - 182100) * 0.32;
            }

            // Level 2: Dependent credit
            if (hasDependents) {
                tax -= 2000;
                if (tax < 0) tax = 0;
            }

        } else if (status.equals("married")) {

            // Level 2: Married brackets (different thresholds)
            if (income <= 22000) {
                tax = income * 0.10;
            } else if (income <= 89450) {
                tax = 2200 + (income - 22000) * 0.12;
            } else if (income <= 190750) {
                tax = 10294 + (income - 89450) * 0.22;
            } else {
                tax = 32580 + (income - 190750) * 0.24;
            }

            // Level 2: Dependent credit (higher for married)
            if (hasDependents) {
                tax -= 4000;
                if (tax < 0) tax = 0;
            }

        } else if (status.equals("head")) {

            // Level 2: Head of household brackets
            if (income <= 15700) {
                tax = income * 0.10;
            } else if (income <= 59850) {
                tax = 1570 + (income - 15700) * 0.12;
            } else if (income <= 95350) {
                tax = 6868 + (income - 59850) * 0.22;
            } else {
                tax = 14678 + (income - 95350) * 0.24;
            }

            // Level 2: Dependent credit
            if (hasDependents) {
                tax -= 3000;
                if (tax < 0) tax = 0;
            }

        } else {
            System.out.println("Invalid filing status.");
            scanner.close();
            return;
        }

        effectiveRate = (tax / income) * 100;

        System.out.println("\n=== Tax Summary ===");
        System.out.println("Income: $" + String.format("%.2f", income));
        System.out.println("Status: " + status);
        System.out.println("Tax owed: $" + String.format("%.2f", tax));
        System.out.println("Effective rate: " + String.format("%.1f", effectiveRate) + "%");

        // Level 1: Refund or payment due
        System.out.print("Tax already paid: $");
        double paid = scanner.nextDouble();

        if (paid > tax) {
            System.out.println("Refund due: $" + String.format("%.2f", paid - tax));
        } else if (paid < tax) {
            System.out.println("Payment due: $" + String.format("%.2f", tax - paid));
        } else {
            System.out.println("No payment or refund due.");
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Too deep nesting 5+ levels of if Hard to read, "arrow code" Flatten with else-if or extract methods
    Wrong variable scope int x = 5; inside if, used outside Variable not visible outside Declare before if or in outer scope
    Missing braces if (a) if (b) x(); else y(); Else matches wrong if Always use explicit braces
    Logic error Check if (valid) then if (invalid) inside Contradictory conditions Use else, not second if
    Null check missing if (str.length() > 0) NPE if str is null if (str != null && str.length() > 0)
    Semicolon after if if (x > 0); { ... } Empty if body Remove semicolon

    7. Quick Rules Checklist

    ✅ Nesting Rules

    • [ ] Limit depth: Maximum 3-4 levels deep
    • [ ] Flatten when possible: Use else-if instead of nested if-else
    • [ ] Extract methods: Complex nested logic → separate method
    • [ ] Brace everything: Even single statements
    • [ ] Comment levels: // Level 2: Validation for clarity

    ✅ Scope Rules

    • [ ] Inner sees outer: Variables declared outside visible inside
    • [ ] Outer doesn't see inner: Variables declared inside NOT visible outside
    • [ ] Same level, same scope: Variables in if-else blocks can't see each other

    ✅ Best Practices

    • [ ] Guard clauses: Check errors first, return/exit early
    • [ ] Positive conditions: if (isValid) better than if (!isInvalid)
    • [ ] Fail fast: Invalid input checks at outermost level
    • [ ] Balance tree: Don't let one branch grow much deeper than others

    Summary

    Concept Explanation
    Nested if If statement inside another if statement
    Execution Inner if only checks if outer if is true
    Scope Inner block sees outer variables, not vice versa
    Maximum depth Keep to 3-4 levels for readability
    Alternative Use else-if ladder when branches are mutually exclusive

    Golden Rules: 1. Nest only when inner check depends on outer check being true 2. Keep nesting shallow (3 levels max) 3. Use guard clauses to reduce nesting depth 4. Always use braces for clarity 5. Comment each nesting level
