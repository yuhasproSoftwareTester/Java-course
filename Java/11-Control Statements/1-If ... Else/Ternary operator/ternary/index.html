    Ternary Operator

    1. Basic Ternary Operator

    Syntax

    condition ? valueIfTrue : valueIfFalse

    How It Works

    condition ? 
    ├── true ──► return first value
    └── false ──► return second value

    Simple Examples

    // Basic usage
int age = 20;
String status = (age >= 18) ? "Adult" : "Minor";

// With numbers
int a = 10, b = 20;
int max = (a > b) ? a : b;  // max = 20

// With methods
String result = (score >= 60) ? getPassMessage() : getFailMessage();

    Ternary vs If-Else

    Ternary If-Else Equivalent
    String s = (x > 0) ? "positive" : "negative"; String s; if (x > 0) s = "positive"; else s = "negative";

    2. Nested Ternary Operator

    Syntax

    condition1 ? value1 :
condition2 ? value2 :
condition3 ? value3 :
             defaultValue

    Execution Flow

    condition1 ?
    ├── true ──► value1
    └── false ──► condition2 ?
                      ├── true ──► value2
                      └── false ──► condition3 ?
                                        ├── true ──► value3
                                        └── false ──► default

    Examples

    Two Levels (Simple)

    // Grade classification
char grade = (score >= 90) ? 'A' :
             (score >= 80) ? 'B' :
             (score >= 70) ? 'C' :
             (score >= 60) ? 'D' : 'F';

    Three Levels

    // Age group with gender
String category = (age < 13) ? "Child" :
                  (age < 20) ? "Teen" :
                  (age < 65) ? "Adult" : "Senior";

// With nested condition
String type = (age >= 18) ? 
                (gender.equals("M") ? "Man" : "Woman") :
                (gender.equals("M") ? "Boy" : "Girl");

    Example 1: Basic Ternary

    import java.util.Scanner;

public class BasicTernary {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter number: ");
        int num = scanner.nextInt();

        // Basic ternary
        String sign = (num > 0) ? "Positive" : (num < 0) ? "Negative" : "Zero";
        String parity = (num % 2 == 0) ? "Even" : "Odd";
        String magnitude = (Math.abs(num) > 100) ? "Large" : "Small";

        System.out.println("Number: " + num);
        System.out.println("Sign: " + sign);
        System.out.println("Parity: " + parity);
        System.out.println("Magnitude: " + magnitude);

        scanner.close();
    }
}

    Example 2: Nested Ternary

    import java.util.Scanner;

public class NestedTernary {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter temperature: ");
        int temp = scanner.nextInt();

        System.out.print("Is it raining? (true/false): ");
        boolean raining = scanner.nextBoolean();

        // Nested ternary for weather advice
        String clothing = (temp < 0) ? "Heavy winter coat" :
                        (temp < 10) ? "Jacket and sweater" :
                        (temp < 20) ? "Light jacket" :
                        (temp < 30) ? "T-shirt and shorts" : "Minimal clothing";

        String accessory = raining ? 
                            ((temp < 10) ? "Umbrella and boots" : "Umbrella") :
                            ((temp > 25) ? "Sunglasses and hat" : "None needed");

        String activity = (temp > 20 && !raining) ? "Perfect for outdoor activities" :
                         (raining) ? "Stay indoors or use umbrella" :
                         (temp < 0) ? "Avoid going outside" : "Light outdoor activities OK";

        System.out.println("\nClothing: " + clothing);
        System.out.println("Accessory: " + accessory);
        System.out.println("Activity: " + activity);

        scanner.close();
    }
}

    Program 1: Number Properties (Basic Ternary)

    import java.util.Scanner;

public class NumberProperties {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter first number: ");
        int a = scanner.nextInt();

        System.out.print("Enter second number: ");
        int b = scanner.nextInt();

        // Basic ternary operations
        int larger = (a > b) ? a : b;
        int smaller = (a < b) ? a : b;
        int absoluteDiff = (a > b) ? (a - b) : (b - a);

        String relation = (a == b) ? "Equal" : (a > b) ? "First is larger" : "Second is larger";
        String sameSign = ((a > 0 && b > 0) || (a < 0 && b < 0)) ? "Same sign" : "Different signs";

        System.out.println("\n=== Results ===");
        System.out.println("Larger: " + larger);
        System.out.println("Smaller: " + smaller);
        System.out.println("Absolute difference: " + absoluteDiff);
        System.out.println("Relation: " + relation);
        System.out.println("Sign comparison: " + sameSign);

        // Check divisibility
        String divisible = (b != 0) ? 
                          ((a % b == 0) ? a + " is divisible by " + b : a + " is not divisible by " + b) :
                          "Cannot divide by zero";
        System.out.println(divisible);

        scanner.close();
    }
}

    Program 2: Grade Calculator (Nested Ternary)

    import java.util.Scanner;

public class GradeCalculatorTernary {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter score (0-100): ");
        int score = scanner.nextInt();

        // Validate first
        String valid = (score >= 0 && score <= 100) ? "Valid" : "Invalid";

        if (valid.equals("Invalid")) {
            System.out.println("Error: Score must be 0-100");
            scanner.close();
            return;
        }

        // Nested ternary for grade
        char grade = (score >= 90) ? 'A' :
                     (score >= 80) ? 'B' :
                     (score >= 70) ? 'C' :
                     (score >= 60) ? 'D' : 'F';

        // Nested ternary for message
        String message = (grade == 'A') ? "Excellent!" :
                        (grade == 'B') ? "Good job!" :
                        (grade == 'C') ? "Satisfactory" :
                        (grade == 'D') ? "Needs improvement" : "Failed";

        // Nested ternary for pass/fail status
        String status = (grade == 'F') ? "Fail" : 
                       (grade == 'D') ? "Marginal Pass" : "Pass";

        // Nested ternary for honors
        String honors = (score >= 95) ? "Summa Cum Laude" :
                       (score >= 90) ? "Magna Cum Laude" :
                       (score >= 85) ? "Cum Laude" : "No honors";

        System.out.println("\nScore: " + score);
        System.out.println("Grade: " + grade);
        System.out.println("Message: " + message);
        System.out.println("Status: " + status);
        System.out.println("Honors: " + honors);

        // Complex nested: scholarship eligibility
        boolean hasAttendance = true; // Assume
        String scholarship = (score >= 90) ?
                            (hasAttendance ? "Full scholarship" : "Partial scholarship") :
                            (score >= 80) ?
                            (hasAttendance ? "Partial scholarship" : "No scholarship") :
                            "No scholarship";

        System.out.println("Scholarship: " + scholarship);

        scanner.close();
    }
}

    Program 3: Time Greeting (Multi-Level Nested)

    import java.util.Scanner;

public class TimeGreeting {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter hour (0-23): ");
        int hour = scanner.nextInt();

        System.out.print("Enter minute (0-59): ");
        int minute = scanner.nextInt();

        // Validate time
        boolean validTime = (hour >= 0 && hour <= 23) && (minute >= 0 && minute <= 59);

        if (!validTime) {
            System.out.println("Invalid time entered");
            scanner.close();
            return;
        }

        // Determine time of day (nested ternary)
        String timeOfDay = (hour >= 5 && hour < 12) ? "Morning" :
                          (hour >= 12 && hour < 17) ? "Afternoon" :
                          (hour >= 17 && hour < 21) ? "Evening" : "Night";

        // Greeting based on time and minute precision
        String greeting = (hour < 12) ?
                          ((hour < 6) ? "Early bird!" : "Good morning!") :
                          (hour < 18) ?
                          ((hour == 12 && minute == 0) ? "Midday!" : "Good afternoon!") :
                          (hour < 22) ? "Good evening!" : "Good night!";

        // Meal suggestion
        String meal = (hour >= 6 && hour <= 10) ? "Breakfast time" :
                     (hour >= 11 && hour <= 14) ? "Lunch time" :
                     (hour >= 17 && hour <= 21) ? "Dinner time" : "Not meal time";

        // Activity suggestion (deep nesting)
        String activity = (timeOfDay.equals("Morning")) ?
                          ((hour < 8) ? "Perfect for exercise" : "Time to start work") :
                          (timeOfDay.equals("Afternoon")) ?
                          ((hour < 14) ? "Post-lunch meeting" : "Focus on tasks") :
                          (timeOfDay.equals("Evening")) ?
                          ((hour < 19) ? "Wind down work" : "Family time") :
                          ((hour < 23) ? "Relaxation or sleep prep" : "Sleep time");

        // Format time string
        String period = (hour < 12) ? "AM" : "PM";
        int displayHour = (hour == 0) ? 12 : (hour > 12) ? hour - 12 : hour;
        String minuteStr = (minute < 10) ? "0" + minute : String.valueOf(minute);

        System.out.println("\nTime: " + displayHour + ":" + minuteStr + " " + period);
        System.out.println("Period: " + timeOfDay);
        System.out.println("Greeting: " + greeting);
        System.out.println("Meal: " + meal);
        System.out.println("Suggested activity: " + activity);

        scanner.close();
    }
}

    Program 4: Shipping Cost Calculator (Complex Nested)

    import java.util.Scanner;

public class ShippingCalculatorTernary {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Package weight (kg): ");
        double weight = scanner.nextDouble();

        System.out.print("Destination (local/national/international): ");
        String dest = scanner.next().toLowerCase();

        System.out.print("Customer type (regular/member/vip): ");
        String customer = scanner.next().toLowerCase();

        System.out.print("Express shipping? (true/false): ");
        boolean express = scanner.nextBoolean();

        // Base rate calculation (nested ternary)
        double baseRate = (dest.equals("local")) ?
                         ((weight <= 1) ? 5.0 : (weight <= 5) ? 10.0 : (weight <= 10) ? 18.0 : 30.0) :
                         (dest.equals("national")) ?
                         ((weight <= 1) ? 8.0 : (weight <= 5) ? 15.0 : (weight <= 10) ? 25.0 : 40.0) :
                         (dest.equals("international")) ?
                         ((weight <= 1) ? 15.0 : (weight <= 5) ? 30.0 : (weight <= 10) ? 50.0 : 80.0) :
                         0.0; // Invalid

        if (baseRate == 0.0) {
            System.out.println("Invalid destination");
            scanner.close();
            return;
        }

        // Express surcharge (nested)
        double expressFee = express ?
                           ((dest.equals("local")) ? 5.0 :
                            (dest.equals("national")) ? 10.0 : 20.0) :
                           0.0;

        // Discount calculation (deep nesting)
        double discount = (customer.equals("vip")) ?
                         ((baseRate > 50) ? 0.30 : (baseRate > 20) ? 0.20 : 0.10) :
                         (customer.equals("member")) ?
                         ((baseRate > 50) ? 0.20 : 0.10) :
                         0.0;

        // Calculate totals
        double subtotal = baseRate + expressFee;
        double discountAmount = subtotal * discount;
        double total = subtotal - discountAmount;

        // Free shipping check (nested)
        String shippingType = express ? "Express" : "Standard";
        boolean freeShipping = (customer.equals("vip") && total > 100) ||
                              (customer.equals("member") && !express && total > 50);

        if (freeShipping) {
            total = 0.0;
            shippingType += " (FREE)";
        }

        System.out.println("\n=== Shipping Quote ===");
        System.out.println("Base rate: $" + baseRate);
        System.out.println("Express fee: $" + expressFee);
        System.out.println("Subtotal: $" + subtotal);
        System.out.println("Discount: " + (int)(discount * 100) + "% (-$" + String.format("%.2f", discountAmount) + ")");
        System.out.println("Total: $" + String.format("%.2f", total));
        System.out.println("Shipping type: " + shippingType);

        scanner.close();
    }
}

    Program 5: User Access Level (Deep Nesting)

    import java.util.Scanner;

public class UserAccessLevel {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("User role (admin/moderator/user/guest): ");
        String role = scanner.next().toLowerCase();

        System.out.print("Account status (active/suspended/pending): ");
        String status = scanner.next().toLowerCase();

        System.out.print("Department (it/sales/support/management): ");
        String dept = scanner.next().toLowerCase();

        // Determine access level (complex nested ternary)
        String accessLevel = (status.equals("active")) ?
                              // Active users
                              (role.equals("admin")) ?
                                  "Full System Access" :
                              (role.equals("moderator")) ?
                                  ((dept.equals("it")) ? "IT Moderator Access" :
                                   (dept.equals("support")) ? "Support Moderator Access" :
                                   "General Moderator Access") :
                              (role.equals("user")) ?
                                  ((dept.equals("management")) ? "Management User Access" :
                                   (dept.equals("sales")) ? "Sales User Access" :
                                   "Standard User Access") :
                              (role.equals("guest")) ?
                                  "Read-Only Access" :
                              "Unknown Role" :
                              // Non-active users
                              (status.equals("suspended")) ?
                                  "Access Denied - Account Suspended" :
                              (status.equals("pending")) ?
                                  "Limited Preview Access Only" :
                              "Invalid Status";

        // Determine specific permissions (another nested ternary)
        String permissions = (accessLevel.contains("Full")) ?
                            "Create, Read, Update, Delete, Admin" :
                           (accessLevel.contains("Moderator")) ?
                            ((dept.equals("it")) ? "CRUD + System Settings" :
                             (dept.equals("support")) ? "CRUD + User Management" :
                             "CRUD + Content Moderation") :
                           (accessLevel.contains("User")) ?
                            ((dept.equals("management")) ? "Read + Reports + Analytics" :
                             (dept.equals("sales")) ? "Read + Customer Data + Orders" :
                             "Read + Personal Data Only") :
                           (accessLevel.contains("Read-Only")) ?
                            "View Public Content Only" :
                           (accessLevel.contains("Preview")) ?
                            "View Sample Content" :
                            "No Permissions";

        // Determine dashboard view
        String dashboard = (accessLevel.contains("Full")) ?
                          "Admin Dashboard with Analytics" :
                         (accessLevel.contains("Moderator")) ?
                          (dept + " Dashboard with Moderation Tools") :
                         (accessLevel.contains("Management")) ?
                          "Executive Dashboard with Reports" :
                         (accessLevel.contains("Sales")) ?
                          "Sales Dashboard with CRM" :
                         (accessLevel.contains("Standard")) ?
                          "User Dashboard" :
                         (accessLevel.contains("Preview")) ?
                          "Welcome Page with Samples" :
                          "Access Denied Page";

        System.out.println("\n=== Access Determination ===");
        System.out.println("Role: " + role);
        System.out.println("Status: " + status);
        System.out.println("Department: " + dept);
        System.out.println("Access Level: " + accessLevel);
        System.out.println("Permissions: " + permissions);
        System.out.println("Dashboard: " + dashboard);

        // Quick action availability (simple ternary)
        boolean canCreate = permissions.contains("Create");
        boolean canDelete = permissions.contains("Delete");
        boolean canAdmin = permissions.contains("Admin");

        System.out.println("\n=== Quick Actions ===");
        System.out.println("Can create content: " + (canCreate ? "Yes" : "No"));
        System.out.println("Can delete content: " + (canDelete ? "Yes" : "No"));
        System.out.println("Can access admin panel: " + (canAdmin ? "Yes" : "No"));

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Wrong syntax x > 0 ? "positive" Missing : falseValue x > 0 ? "positive" : "negative"
    Type mismatch (x > 0) ? 1 : "one" Different return types (x > 0) ? 1 : 0 or (x > 0) ? "1" : "one"
    Too deep nesting 4+ levels of ? : Unreadable code Use if-else or switch
    No side effects (x > 0) ? print("hi") : print("bye") Void methods don't return Use if-else for method calls
    Assignment confusion x = y > 0 ? 1 : 0 Ambiguous precedence x = (y > 0) ? 1 : 0
    Null without check str.isEmpty() ? "empty" : "not" NPE if str is null str == null ? "null" : str.isEmpty() ? "empty" : "not"

    7. Quick Rules Checklist

    ✅ Ternary Rules

    • [ ] Both sides must return same type (or compatible)
    • [ ] Cannot use for void methods (no return value)
    • [ ] Maximum 2-3 levels deep for readability
    • [ ] Parenthesize complex conditions for clarity
    • [ ] Use for simple assignments only

    ✅ When to Use Ternary

    Use Ternary Use If-Else
    Simple value assignment Complex logic
    Two clear outcomes Multiple statements
    Return statement Void methods
    Variable initialization Side effects needed

    ✅ Best Practices

    • [ ] Keep it simple: One ternary per line maximum
    • [ ] Break nested ternary into multiple lines: java result = condition1 ? value1 : condition2 ? value2 : condition3 ? value3 : defaultValue;
    • [ ] Add parentheses around condition: (x > 0) ? a : b
    • [ ] Comment if logic is complex

    Summary

    Aspect Ternary Nested Ternary
    Syntax cond ? a : b c1 ? a : c2 ? b : c3 ? c : d
    Levels 1 (true/false) 2+ (multi-way)
    Returns Value Value
    Best for Simple choice Compact classification
    Max depth 1 2-3 (more is unreadable)

    Golden Rules: 1. Use for simple value assignments only 2. Maximum 3 levels of nesting 3. Both sides must return compatible types 4. Cannot use with void methods 5. When in doubt, use if-else for readability
