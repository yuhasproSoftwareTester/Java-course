    Section 15: Basic If-Else

    1. If-Else Structure Overview

    Three Basic Forms

    Form Syntax Use Case
    Simple if if (condition) { ... } Execute only if true
    If-else if (condition) { ... } else { ... } Two-way decision
    If-else-if if (c1) { ... } else if (c2) { ... } else { ... } Multi-way decision

    Visual Flow

    SIMPLE IF:
condition? ──Yes──► execute block
    │
    No
    ▼
   [continue]

IF-ELSE:
condition? ──Yes──► if-block
    │
    No
    ▼
  else-block

##  2. Syntax Rules

### Rule 1: Condition Must Be Boolean
```java
// CORRECT
if (score >= 60) { }

// WRONG - must be boolean, not int
if (score) { }  // ERROR!

// CORRECT - comparison returns boolean
if (score == 100) { }

    Rule 2: Braces Required for Multiple Statements

    // Without braces - only ONE statement belongs to if
if (passed)
    System.out.println("Pass");  // Only this is conditional
    System.out.println("Award"); // This ALWAYS executes!

// With braces - ALL statements conditional
if (passed) {
    System.out.println("Pass");
    System.out.println("Award");
}

    3. Complete Working Examples

    Example 1: Simple If

    import java.util.Scanner;

public class SimpleIf {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter your score: ");
        int score = scanner.nextInt();

        // Simple if - only executes when condition is true
        if (score >= 60) {
            System.out.println("Congratulations! You passed.");
        }

        // This always executes
        System.out.println("Your score: " + score);

        scanner.close();
    }
}

    Example 2: If-Else

    import java.util.Scanner;

public class IfElse {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter password: ");
        String password = scanner.nextLine();

        // Two-way decision
        if (password.equals("secret123")) {
            System.out.println("Access granted.");
            System.out.println("Welcome to the system.");
        } else {
            System.out.println("Access denied.");
            System.out.println("Please try again.");
        }

        scanner.close();
    }
}

    Program 1: Number Classifier

    import java.util.Scanner;

public class NumberClassifier {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int num = scanner.nextInt();

        // Simple if - check positive
        if (num > 0) {
            System.out.println(num + " is positive");
        }

        // If-else - check even/odd (only for non-zero)
        if (num != 0) {
            if (num % 2 == 0) {
                System.out.println(num + " is even");
            } else {
                System.out.println(num + " is odd");
            }
        }

        // If-else-if - classify range
        if (num < 0) {
            System.out.println("Range: Negative");
        } else if (num >= 0 && num <= 10) {
            System.out.println("Range: Small (0-10)");
        } else if (num > 10 && num <= 100) {
            System.out.println("Range: Medium (11-100)");
        } else if (num > 100 && num <= 1000) {
            System.out.println("Range: Large (101-1000)");
        } else {
            System.out.println("Range: Extra Large (1000+)");
        }

        scanner.close();
    }
}

    Program 2: Login System with Attempts

    import java.util.Scanner;

public class LoginSystem {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        String correctUsername = "admin";
        String correctPassword = "pass123";
        int maxAttempts = 3;
        int attempts = 0;
        boolean loggedIn = false;

        System.out.println("=== Secure Login ===");

        while (attempts < maxAttempts && !loggedIn) {
            System.out.print("Username: ");
            String username = scanner.nextLine();

            System.out.print("Password: ");
            String password = scanner.nextLine();

            // Nested if-else for validation
            if (username.equals(correctUsername)) {
                if (password.equals(correctPassword)) {
                    System.out.println("Login successful!");
                    loggedIn = true;
                } else {
                    System.out.println("Incorrect password.");
                    attempts++;
                    if (attempts < maxAttempts) {
                        System.out.println("Attempts remaining: " + (maxAttempts - attempts));
                    }
                }
            } else {
                System.out.println("Username not found.");
                attempts++;
                if (attempts < maxAttempts) {
                    System.out.println("Attempts remaining: " + (maxAttempts - attempts));
                }
            }
        }

        // Final check after loop
        if (!loggedIn) {
            System.out.println("Account locked. Too many failed attempts.");
        } else {
            System.out.println("Welcome to the dashboard!");
        }

        scanner.close();
    }
}

    Program 3: Grade Calculator with Validation

    import java.util.Scanner;

public class GradeCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter score (0-100): ");
        int score = scanner.nextInt();

        // Input validation first
        if (score < 0 || score > 100) {
            System.out.println("Error: Score must be between 0 and 100");
        } else {
            // Valid score - determine grade
            char grade;
            String message;

            if (score >= 90) {
                grade = 'A';
                message = "Outstanding!";
            } else if (score >= 80) {
                grade = 'B';
                message = "Good job!";
            } else if (score >= 70) {
                grade = 'C';
                message = "Satisfactory";
            } else if (score >= 60) {
                grade = 'D';
                message = "Needs improvement";
            } else {
                grade = 'F';
                message = "Failed - please retake";
            }

            System.out.println("Score: " + score);
            System.out.println("Grade: " + grade);
            System.out.println("Feedback: " + message);

            // Additional feedback
            if (grade == 'A' || grade == 'B') {
                System.out.println("Status: Honors");
            } else if (grade == 'C') {
                System.out.println("Status: Pass");
            } else {
                System.out.println("Status: Fail");
            }
        }

        scanner.close();
    }
}

    Program 4: E-commerce Discount Engine

    import java.util.Scanner;

public class DiscountEngine {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter purchase amount: $");
        double amount = scanner.nextDouble();

        System.out.print("Is customer a member? (true/false): ");
        boolean isMember = scanner.nextBoolean();

        System.out.print("Has coupon code? (true/false): ");
        boolean hasCoupon = scanner.nextBoolean();

        double discount = 0;
        double finalAmount = amount;

        // Calculate discount with nested logic
        if (amount > 0) {
            if (amount >= 500) {
                discount = 20;  // 20% off
                System.out.println("Tier: Platinum (20% off)");
            } else if (amount >= 200) {
                discount = 10;  // 10% off
                System.out.println("Tier: Gold (10% off)");
            } else if (amount >= 100) {
                discount = 5;   // 5% off
                System.out.println("Tier: Silver (5% off)");
            } else {
                discount = 0;
                System.out.println("Tier: Standard (no discount)");
            }

            // Member bonus
            if (isMember) {
                discount = discount + 5;  // Extra 5%
                System.out.println("Member bonus: +5%");
            }

            // Coupon bonus
            if (hasCoupon) {
                discount = discount + 10;  // Extra 10%
                System.out.println("Coupon bonus: +10%");
            }

            // Cap discount at 50%
            if (discount > 50) {
                discount = 50;
                System.out.println("Discount capped at 50%");
            }

            // Calculate final
            finalAmount = amount - (amount * discount / 100);

            System.out.println("\n=== Summary ===");
            System.out.println("Original: $" + amount);
            System.out.println("Discount: " + discount + "%");
            System.out.println("You save: $" + (amount - finalAmount));
            System.out.println("Final: $" + finalAmount);

            // Free shipping check
            if (finalAmount > 50 || isMember) {
                System.out.println("Shipping: FREE");
            } else {
                System.out.println("Shipping: $5.99");
                finalAmount = finalAmount + 5.99;
                System.out.println("Total with shipping: $" + finalAmount);
            }

        } else {
            System.out.println("Error: Amount must be positive");
        }

        scanner.close();
    }
}

    Program 5: Selenium Element State Checker (Automation Prep)

    import java.util.Scanner;

public class ElementStateChecker {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Selenium Element State Checker ===");

        System.out.print("Element exists (true/false): ");
        boolean exists = scanner.nextBoolean();

        System.out.print("Element is displayed (true/false): ");
        boolean displayed = scanner.nextBoolean();

        System.out.print("Element is enabled (true/false): ");
        boolean enabled = scanner.nextBoolean();

        System.out.print("Element text is empty (true/false): ");
        boolean textEmpty = scanner.nextBoolean();

        String action = "";
        String warning = "";

        // Decision tree for element interaction
        if (exists) {
            if (displayed) {
                if (enabled) {
                    if (!textEmpty) {
                        action = "CLICK_AND_VERIFY";
                        warning = "Ready for interaction with text verification";
                    } else {
                        action = "CLICK_ONLY";
                        warning = "Element clickable but no text to verify";
                    }
                } else {
                    action = "WAIT_FOR_ENABLE";
                    warning = "Element visible but disabled - possible loading state";
                }
            } else {
                if (enabled) {
                    action = "SCROLL_AND_CLICK";
                    warning = "Element enabled but not visible - may need scroll";
                } else {
                    action = "SKIP_OR_FAIL";
                    warning = "Element hidden and disabled - check locator";
                }
            }
        } else {
            action = "FAIL_TEST";
            warning = "Element not found - verify locator or wait for presence";
        }

        System.out.println("\n=== Recommendation ===");
        System.out.println("Action: " + action);
        System.out.println("Warning: " + warning);

        // Additional specific checks
        System.out.println("\n=== Specific Checks ===");

        if (exists && displayed && enabled) {
            System.out.println("✓ Element is interactable");

            if (!textEmpty) {
                System.out.println("✓ Can verify text content");
            } else {
                System.out.println("⚠ Text verification not possible");
            }
        } else {
            System.out.println("✗ Element not ready for interaction");

            if (!exists) {
                System.out.println("  - Not in DOM");
            }
            if (exists && !displayed) {
                System.out.println("  - Not visible");
            }
            if (exists && displayed && !enabled) {
                System.out.println("  - Not enabled");
            }
        }

        // Retry logic suggestion
        if (exists && !displayed) {
            System.out.println("\nSuggested: Wait for visibility or scroll into view");
        } else if (exists && displayed && !enabled) {
            System.out.println("\nSuggested: Wait for element to be enabled");
        } else if (!exists) {
            System.out.println("\nSuggested: Add explicit wait for element presence");
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Semicolon after if if (x > 0); { ... } Empty if body, braces always execute Remove semicolon: if (x > 0) { ... }
    Assignment instead of comparison if (x = 5) Assigns 5, always true if (x == 5)
    Missing braces if (x > 0) System.out.print("A"); System.out.print("B"); Only A is conditional Add braces for both statements
    Wrong else matching if (a) if (b) x(); else y(); Else matches inner if Use braces to clarify intent
    Double comparison if (5 < x < 10) Syntax error if (x > 5 && x < 10)
    String comparison if (input == "yes") Compares references if (input.equals("yes"))

    7. Quick Rules Checklist

    ✅ If-Else Rules

    • [ ] Condition must evaluate to boolean
    • [ ] Use braces {} even for single statements (prevents bugs)
    • [ ] Indent consistently for readability
    • [ ] Match else to correct if using braces
    • [ ] Handle all cases (include final else as catch-all)

    ✅ Best Practices

    • [ ] Put simplest/most likely case first
    • [ ] Avoid deep nesting (more than 3 levels is code smell)
    • [ ] Extract complex conditions to boolean variables
    • [ ] Keep if-else-if ladder under 5-6 branches (use switch or polymorphism if more)
    • [ ] Validate input first (guard clauses)

    📝 Summary

    Structure Syntax When to Use
    Simple if if (condition) { ... } Single condition, optional action
    If-else if (c) { ... } else { ... } Two mutually exclusive paths
    If-else-if if (c1) ... else if (c2) ... Multiple exclusive conditions

    Golden Rules: 1. Always use braces {} for clarity 2. Condition must be boolean 3. Use .equals() for String comparison 4. Handle the "else" case (even if just logging) 5. Keep nesting shallow (3 levels max)
