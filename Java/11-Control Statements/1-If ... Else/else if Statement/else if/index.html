    Else-If Ladder

    1. Else-If Structure

    Basic Syntax

    if (condition1) {
    // Block 1: condition1 is true
} else if (condition2) {
    // Block 2: condition1 false, condition2 true
} else if (condition3) {
    // Block 3: conditions 1-2 false, condition3 true
} else {
    // Block 4: all above false (default case)
}

    Execution Flow

    Check condition1? ──Yes──► Execute Block 1 ──► Exit
    │
    No
    ▼
Check condition2? ──Yes──► Execute Block 2 ──► Exit
    │
    No
    ▼
Check condition3? ──Yes──► Execute Block 3 ──► Exit
    │
    No
    ▼
Execute Else Block ──► Exit

    Key Rules

    Rule Explanation
    Top to bottom Checks conditions in order, stops at first true
    Mutually exclusive Only ONE block executes
    Final else optional Catches all remaining cases
    Conditions can overlap Put specific before general

    2. Ordering Conditions

    Specific → General (Correct)

    // CORRECT: Specific first
if (score >= 90) {
    grade = 'A';      // 90-100
} else if (score >= 80) {
    grade = 'B';      // 80-89 (already know <90)
} else if (score >= 70) {
    grade = 'C';      // 70-79 (already know <80)
} else if (score >= 60) {
    grade = 'D';      // 60-69 (already know <70)
} else {
    grade = 'F';      // <60 (everything else)
}

    General → Specific (Wrong!)

    // WRONG: General first catches everything!
if (score >= 60) {
    grade = 'D';      // 60-100 (catches too much!)
} else if (score >= 70) {
    grade = 'C';      // NEVER REACHED (70+ already caught)
} else if (score >= 80) {
    grade = 'B';      // NEVER REACHED
} else if (score >= 90) {
    grade = 'A';      // NEVER REACHED
} else {
    grade = 'F';
}

    Example 1: BMI Calculator

    import java.util.Scanner;

public class BMICalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter weight (kg): ");
        double weight = scanner.nextDouble();

        System.out.print("Enter height (m): ");
        double height = scanner.nextDouble();

        double bmi = weight / (height * height);
        String category;
        String advice;

        // Else-if ladder for BMI categories
        if (bmi < 18.5) {
            category = "Underweight";
            advice = "Eat more nutritious food";
        } else if (bmi >= 18.5 && bmi < 25) {
            category = "Normal weight";
            advice = "Keep up the good work!";
        } else if (bmi >= 25 && bmi < 30) {
            category = "Overweight";
            advice = "Consider regular exercise";
        } else if (bmi >= 30 && bmi < 35) {
            category = "Obese Class I";
            advice = "Consult a nutritionist";
        } else if (bmi >= 35 && bmi < 40) {
            category = "Obese Class II";
            advice = "Medical consultation recommended";
        } else {
            category = "Obese Class III";
            advice = "Immediate medical attention";
        }

        System.out.println("\nBMI: " + String.format("%.1f", bmi));
        System.out.println("Category: " + category);
        System.out.println("Advice: " + advice);

        scanner.close();
    }
}

    Example 2: Shipping Rate Calculator

    import java.util.Scanner;

public class ShippingCalculator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Package weight (kg): ");
        double weight = scanner.nextDouble();

        System.out.print("Destination (local/national/international): ");
        String destination = scanner.next().toLowerCase();

        double rate;
        String zone;

        // Nested else-if: weight first, then destination
        if (weight <= 0) {
            System.out.println("Error: Weight must be positive");
            scanner.close();
            return;
        } else if (weight <= 1) {
            zone = "Zone A (Light)";
            if (destination.equals("local")) {
                rate = 5.00;
            } else if (destination.equals("national")) {
                rate = 8.00;
            } else if (destination.equals("international")) {
                rate = 15.00;
            } else {
                System.out.println("Error: Invalid destination");
                scanner.close();
                return;
            }
        } else if (weight <= 5) {
            zone = "Zone B (Medium)";
            if (destination.equals("local")) {
                rate = 10.00;
            } else if (destination.equals("national")) {
                rate = 15.00;
            } else if (destination.equals("international")) {
                rate = 30.00;
            } else {
                System.out.println("Error: Invalid destination");
                scanner.close();
                return;
            }
        } else if (weight <= 10) {
            zone = "Zone C (Heavy)";
            if (destination.equals("local")) {
                rate = 18.00;
            } else if (destination.equals("national")) {
                rate = 25.00;
            } else if (destination.equals("international")) {
                rate = 50.00;
            } else {
                System.out.println("Error: Invalid destination");
                scanner.close();
                return;
            }
        } else {
            zone = "Zone D (Freight)";
            if (destination.equals("local")) {
                rate = 30.00 + (weight - 10) * 2;
            } else if (destination.equals("national")) {
                rate = 40.00 + (weight - 10) * 3;
            } else if (destination.equals("international")) {
                rate = 80.00 + (weight - 10) * 5;
            } else {
                System.out.println("Error: Invalid destination");
                scanner.close();
                return;
            }
        }

        System.out.println("\n=== Shipping Quote ===");
        System.out.println("Weight: " + weight + " kg");
        System.out.println("Zone: " + zone);
        System.out.println("Destination: " + destination);
        System.out.println("Rate: $" + rate);

        scanner.close();
    }
}

    Program 2: Temperature Converter with Scale Detection

    import java.util.Scanner;

public class SmartTemperatureConverter {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter temperature value: ");
        double temp = scanner.nextDouble();

        System.out.print("Enter scale (C/F/K): ");
        char scale = scanner.next().toUpperCase().charAt(0);

        double celsius, fahrenheit, kelvin;
        String weatherDesc;

        // Convert to all scales first
        if (scale == 'C') {
            celsius = temp;
            fahrenheit = (temp * 9/5) + 32;
            kelvin = temp + 273.15;
        } else if (scale == 'F') {
            celsius = (temp - 32) * 5/9;
            fahrenheit = temp;
            kelvin = celsius + 273.15;
        } else if (scale == 'K') {
            celsius = temp - 273.15;
            fahrenheit = (celsius * 9/5) + 32;
            kelvin = temp;
        } else {
            System.out.println("Error: Invalid scale. Use C, F, or K.");
            scanner.close();
            return;
        }

        // Determine weather description based on Celsius
        if (celsius <= -40) {
            weatherDesc = "Extreme Cold (Dangerous)";
        } else if (celsius <= -20) {
            weatherDesc = "Severe Cold";
        } else if (celsius <= 0) {
            weatherDesc = "Freezing";
        } else if (celsius <= 10) {
            weatherDesc = "Very Cold";
        } else if (celsius <= 15) {
            weatherDesc = "Chilly";
        } else if (celsius <= 20) {
            weatherDesc = "Cool";
        } else if (celsius <= 25) {
            weatherDesc = "Mild";
        } else if (celsius <= 30) {
            weatherDesc = "Warm";
        } else if (celsius <= 35) {
            weatherDesc = "Hot";
        } else if (celsius <= 40) {
            weatherDesc = "Very Hot";
        } else {
            weatherDesc = "Extreme Heat (Dangerous)";
        }

        System.out.println("\n=== Temperature Conversion ===");
        System.out.println("Input: " + temp + "°" + scale);
        System.out.println("Celsius: " + String.format("%.2f", celsius) + "°C");
        System.out.println("Fahrenheit: " + String.format("%.2f", fahrenheit) + "°F");
        System.out.println("Kelvin: " + String.format("%.2f", kelvin) + "K");

        System.out.println("\n=== Weather Description ===");
        System.out.println(weatherDesc);

        // Clothing advice
        String clothing;
        if (celsius <= 0) {
            clothing = "Heavy winter coat, gloves, hat";
        } else if (celsius <= 10) {
            clothing = "Jacket or coat required";
        } else if (celsius <= 20) {
            clothing = "Light jacket or sweater";
        } else if (celsius <= 30) {
            clothing = "T-shirt and light clothing";
        } else {
            clothing = "Minimal clothing, stay hydrated";
        }

        System.out.println("Recommended: " + clothing);

        scanner.close();
    }
}

    Program 4: File Extension Handler

    import java.util.Scanner;

public class FileExtensionHandler {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter filename: ");
        String filename = scanner.nextLine();

        // Extract extension
        String extension = "";
        int dotIndex = filename.lastIndexOf('.');

        if (dotIndex > 0 && dotIndex < filename.length() - 1) {
            extension = filename.substring(dotIndex + 1).toLowerCase();
        }

        String fileType;
        String defaultProgram;
        boolean canEdit;
        boolean canExecute;

        // Else-if ladder for file types
        if (extension.equals("txt") || extension.equals("md") || extension.equals("rtf")) {
            fileType = "Text Document";
            defaultProgram = "Notepad / TextEdit";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("doc") || extension.equals("docx")) {
            fileType = "Microsoft Word Document";
            defaultProgram = "Microsoft Word";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("xls") || extension.equals("xlsx")) {
            fileType = "Microsoft Excel Spreadsheet";
            defaultProgram = "Microsoft Excel";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("pdf")) {
            fileType = "PDF Document";
            defaultProgram = "Adobe Reader / Browser";
            canEdit = false;
            canExecute = false;
        } else if (extension.equals("jpg") || extension.equals("jpeg") || 
                   extension.equals("png") || extension.equals("gif")) {
            fileType = "Image File";
            defaultProgram = "Image Viewer / Browser";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("mp3") || extension.equals("wav") || 
                   extension.equals("ogg")) {
            fileType = "Audio File";
            defaultProgram = "Media Player";
            canEdit = false;
            canExecute = false;
        } else if (extension.equals("mp4") || extension.equals("avi") || 
                   extension.equals("mkv")) {
            fileType = "Video File";
            defaultProgram = "Video Player";
            canEdit = false;
            canExecute = false;
        } else if (extension.equals("zip") || extension.equals("rar") || 
                   extension.equals("7z")) {
            fileType = "Compressed Archive";
            defaultProgram = "Archive Manager";
            canEdit = false;
            canExecute = false;
        } else if (extension.equals("exe") || extension.equals("bat") || 
                   extension.equals("sh")) {
            fileType = "Executable Program";
            defaultProgram = "Operating System";
            canEdit = false;
            canExecute = true;
        } else if (extension.equals("java")) {
            fileType = "Java Source Code";
            defaultProgram = "IDE / Text Editor";
            canEdit = true;
            canExecute = false;  // Needs compilation
        } else if (extension.equals("class")) {
            fileType = "Java Compiled Bytecode";
            defaultProgram = "JVM";
            canEdit = false;
            canExecute = true;
        } else if (extension.equals("html") || extension.equals("htm")) {
            fileType = "HTML Web Page";
            defaultProgram = "Web Browser";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("css")) {
            fileType = "CSS Stylesheet";
            defaultProgram = "Text Editor / Browser";
            canEdit = true;
            canExecute = false;
        } else if (extension.equals("js")) {
            fileType = "JavaScript Code";
            defaultProgram = "Web Browser / Node.js";
            canEdit = true;
            canExecute = true;
        } else if (extension.isEmpty()) {
            fileType = "No Extension";
            defaultProgram = "Unknown";
            canEdit = true;
            canExecute = false;
        } else {
            fileType = "Unknown Type (." + extension + ")";
            defaultProgram = "Generic Viewer";
            canEdit = true;
            canExecute = false;
        }

        System.out.println("\n=== File Analysis ===");
        System.out.println("Filename: " + filename);
        System.out.println("Extension: " + (extension.isEmpty() ? "None" : extension));
        System.out.println("Type: " + fileType);
        System.out.println("Open with: " + defaultProgram);
        System.out.println("Editable: " + (canEdit ? "Yes" : "No"));
        System.out.println("Executable: " + (canExecute ? "Yes" : "No"));

        // Security warning
        if (canExecute && (extension.equals("exe") || extension.equals("bat") || extension.equals("sh"))) {
            System.out.println("\n⚠️  SECURITY WARNING: Executable files may contain malware!");
            System.out.println("Only run from trusted sources.");
        }

        scanner.close();
    }
}

    Program 5: Selenium Test Priority Assigner (Automation Prep)

    import java.util.Scanner;

public class TestPriorityAssigner {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Selenium Test Priority Assigner ===");

        System.out.print("Test type (smoke/regression/e2e/performance/security): ");
        String testType = scanner.next().toLowerCase();

        System.out.print("Business impact (critical/high/medium/low): ");
        String impact = scanner.next().toLowerCase();

        System.out.print("Failure history (frequent/occasional/rare/none): ");
        String failureHistory = scanner.next().toLowerCase();

        System.out.print("Execution time in seconds: ");
        int executionTime = scanner.nextInt();

        int priorityScore = 0;
        String priorityLevel;
        String executionOrder;
        String retryPolicy;

        // Calculate base score from test type
        if (testType.equals("smoke")) {
            priorityScore += 100;
        } else if (testType.equals("regression")) {
            priorityScore += 75;
        } else if (testType.equals("e2e")) {
            priorityScore += 60;
        } else if (testType.equals("performance")) {
            priorityScore += 50;
        } else if (testType.equals("security")) {
            priorityScore += 90;
        } else {
            priorityScore += 25;
        }

        // Adjust for business impact
        if (impact.equals("critical")) {
            priorityScore += 50;
        } else if (impact.equals("high")) {
            priorityScore += 30;
        } else if (impact.equals("medium")) {
            priorityScore += 15;
        } else if (impact.equals("low")) {
            priorityScore += 5;
        }

        // Adjust for failure history
        if (failureHistory.equals("frequent")) {
            priorityScore += 40;
        } else if (failureHistory.equals("occasional")) {
            priorityScore += 20;
        } else if (failureHistory.equals("rare")) {
            priorityScore += 5;
        }

        // Adjust for execution time (faster tests get slight boost)
        if (executionTime < 10) {
            priorityScore += 10;
        } else if (executionTime < 30) {
            priorityScore += 5;
        } else if (executionTime > 120) {
            priorityScore -= 10;  // Long tests slightly deprioritized
        }

        // Determine priority level
        if (priorityScore >= 150) {
            priorityLevel = "P0 - Critical";
            executionOrder = "First in suite";
            retryPolicy = "Retry 3 times, fail fast";
        } else if (priorityScore >= 120) {
            priorityLevel = "P1 - High";
            executionOrder = "After P0 tests";
            retryPolicy = "Retry 2 times";
        } else if (priorityScore >= 90) {
            priorityLevel = "P2 - Medium";
            executionOrder = "Parallel execution allowed";
            retryPolicy = "Retry 1 time";
        } else if (priorityScore >= 60) {
            priorityLevel = "P3 - Low";
            executionOrder = "End of suite";
            retryPolicy = "No retry, log only";
        } else {
            priorityLevel = "P4 - Minimal";
            executionOrder = "Optional/On-demand";
            retryPolicy = "Manual investigation only";
        }

        System.out.println("\n=== Priority Assessment ===");
        System.out.println("Priority Score: " + priorityScore);
        System.out.println("Priority Level: " + priorityLevel);
        System.out.println("Execution Order: " + executionOrder);
        System.out.println("Retry Policy: " + retryPolicy);

        // Recommendations
        System.out.println("\n=== Recommendations ===");

        if (priorityScore >= 150) {
            System.out.println("✓ Run on every build");
            System.out.println("✓ Block deployment on failure");
            System.out.println("✓ Alert team immediately");
            System.out.println("✓ Execute in isolated environment");
        } else if (priorityScore >= 120) {
            System.out.println("✓ Run on every build");
            System.out.println("✓ Notify on failure");
            System.out.println("✓ Include in smoke suite");
        } else if (priorityScore >= 90) {
            System.out.println("✓ Run nightly");
            System.out.println("✓ Parallel execution recommended");
            System.out.println("✓ Report weekly summary");
        } else if (priorityScore >= 60) {
            System.out.println("⚠ Run weekly or on-demand");
            System.out.println("⚠ Consider deprecation if flaky");
        } else {
            System.out.println("✗ Review necessity");
            System.out.println("✗ Consider removal or merging");
        }

        // Specific advice based on inputs
        System.out.println("\n=== Specific Notes ===");

        if (executionTime > 300) {
            System.out.println("⚠ Test is very slow (>5 min). Consider optimization or breaking into smaller tests.");
        } else if (executionTime > 60) {
            System.out.println("ℹ Test is moderately slow. Monitor execution time trends.");
        }

        if (failureHistory.equals("frequent")) {
            System.out.println("⚠ High failure rate. Investigate for flakiness or environment issues.");
        }

        if (testType.equals("security") && priorityScore < 120) {
            System.out.println("⚠ Security test with low priority - verify impact assessment.");
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Wrong order if (score > 60) before if (score > 90) 90+ never reached Put most specific first
    Overlapping without else Separate if statements Multiple blocks may execute Use else-if for mutual exclusion
    Missing final else Ends with else if Unhandled cases silent Add final else as catch-all
    Assignment in condition else if (grade = 'A') Always true, wrong variable else if (grade == 'A')
    Semicolon after condition else if (x > 0); { ... } Empty statement, braces always run Remove semicolon
    Incompatible types else if (score == "90") String vs int comparison else if (score == 90)

    7. Quick Rules Checklist

    Else-If Rules

    • [ ] Order matters: Specific → General, Rare → Common
    • [ ] Mutually exclusive: Only one block executes
    • [ ] Final else: Always include for unhandled cases
    • [ ] Boolean conditions: Each must evaluate to true/false
    • [ ] Break long ladders: Consider switch or polymorphism if >6-7 branches

    Best Practices

    • [ ] Comment the "why" for complex condition logic
    • [ ] Extract complex conditions to descriptive boolean variables
    • [ ] Keep it flat: Avoid nesting else-if inside else-if
    • [ ] Test boundary values: Every condition edge case
    • [ ] Default action: Final else should handle or error

    Summary

    Aspect Key Point
    Structure if → else if → else if → else
    Execution Top to bottom, stops at first true
    Mutual exclusion Only ONE block runs
    Ordering Most specific condition FIRST
    Final else Catches all remaining cases (optional but recommended)

    Golden Rules: 1. Order conditions from most specific to most general 2. Ensure conditions are mutually exclusive (or intentionally not) 3. Always include a final else for error handling 4. Keep ladder under 6-7 branches for readability 5. Test boundary values between each range
