    While Loop

    1. While Loop Structure

    Syntax

    while (condition) {
    // loop body
}

    How It Works

    Check Condition ──No──► Exit Loop
    │
   Yes
    ▼
Execute Body
    │
    ▼
Check Condition (repeat)

    Key Characteristics

    Feature Description
    Pre-test Condition checked BEFORE each iteration
    May run zero times If condition initially false
    Indefinite iteration Used when iteration count unknown
    Requires manual update Variable in condition must change inside loop

    2. While Loop Variations

    Basic While

    int i = 0;
while (i < 10) {
    System.out.println(i);
    i++;  // Critical: update condition variable
}

    Infinite Loop (with break)

    while (true) {
    // Do something
    if (exitCondition) {
        break;  // Exit loop
    }
}

    Complex Condition

    while (hasData && !error && attempts < maxAttempts) {
    // Process data
}

    3. Complete Working Examples

    Example 1: Basic While Patterns

    public class WhilePatterns {
    public static void main(String[] args) {
        // Forward counting
        System.out.print("Forward: ");
        int i = 1;
        while (i <= 5) {
            System.out.print(i + " ");
            i++;
        }

        // Backward counting
        System.out.print("\nBackward: ");
        int j = 5;
        while (j >= 1) {
            System.out.print(j + " ");
            j--;
        }

        // Skip with continue
        System.out.print("\nSkip multiples of 3: ");
        int k = 1;
        while (k <= 10) {
            if (k % 3 == 0) {
                k++;
                continue;
            }
            System.out.print(k + " ");
            k++;
        }

        // Early exit with break
        System.out.print("\nStop at 5: ");
        int m = 1;
        while (m <= 10) {
            if (m > 5) break;
            System.out.print(m + " ");
            m++;
        }
    }
}

    Example 2: User Input Validation

    import java.util.Scanner;

public class InputValidation {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int number = 0;
        boolean valid = false;

        while (!valid) {
            System.out.print("Enter a positive even number: ");
            number = scanner.nextInt();

            if (number <= 0) {
                System.out.println("Error: Must be positive");
            } else if (number % 2 != 0) {
                System.out.println("Error: Must be even");
            } else {
                valid = true;
                System.out.println("Valid input: " + number);
            }
        }

        scanner.close();
    }
}

    Program 1: Number Guessing Game

    import java.util.Scanner;
import java.util.Random;

public class GuessingGameWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();

        int secret = random.nextInt(100) + 1;
        int guess = 0;
        int attempts = 0;

        System.out.println("Guess a number between 1 and 100");

        while (guess != secret) {
            System.out.print("Your guess: ");
            guess = scanner.nextInt();
            attempts++;

            if (guess < secret) {
                System.out.println("Too low!");
            } else if (guess > secret) {
                System.out.println("Too high!");
            } else {
                System.out.println("Correct! You took " + attempts + " attempts");
            }

            if (attempts >= 10 && guess != secret) {
                System.out.println("Hint: You're getting close to limit!");
            }
        }

        scanner.close();
    }
}

    Program 2: ATM Menu System

    import java.util.Scanner;

public class ATMMenu {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        double balance = 1000.00;
        boolean running = true;

        while (running) {
            System.out.println("\n=== ATM Menu ===");
            System.out.println("1. Check Balance");
            System.out.println("2. Deposit");
            System.out.println("3. Withdraw");
            System.out.println("4. Exit");
            System.out.print("Choice: ");

            int choice = scanner.nextInt();

            switch (choice) {
                case 1:
                    System.out.println("Balance: $" + balance);
                    break;

                case 2:
                    System.out.print("Enter amount: $");
                    double deposit = scanner.nextDouble();
                    if (deposit > 0) {
                        balance += deposit;
                        System.out.println("Deposited: $" + deposit);
                    } else {
                        System.out.println("Invalid amount");
                    }
                    break;

                case 3:
                    System.out.print("Enter amount: $");
                    double withdraw = scanner.nextDouble();
                    if (withdraw > 0 && withdraw <= balance) {
                        balance -= withdraw;
                        System.out.println("Withdrew: $" + withdraw);
                    } else {
                        System.out.println("Invalid or insufficient funds");
                    }
                    break;

                case 4:
                    System.out.println("Thank you! Goodbye.");
                    running = false;
                    break;

                default:
                    System.out.println("Invalid choice");
            }
        }

        scanner.close();
    }
}

    Program 3: Password Login with Retry Limit

    import java.util.Scanner;

public class PasswordLogin {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        String correctPassword = "secret123";
        String password = "";
        int attempts = 0;
        int maxAttempts = 3;
        boolean loggedIn = false;

        while (attempts < maxAttempts && !loggedIn) {
            System.out.print("Enter password (attempt " + (attempts + 1) + "/" + maxAttempts + "): ");
            password = scanner.nextLine();

            if (password.equals(correctPassword)) {
                loggedIn = true;
                System.out.println("Login successful!");
            } else {
                attempts++;
                if (attempts < maxAttempts) {
                    System.out.println("Incorrect. Try again.");
                }
            }
        }

        if (!loggedIn) {
            System.out.println("Account locked. Too many failed attempts.");
        } else {
            System.out.println("Welcome to your account.");
        }

        scanner.close();
    }
}

    Program 4: Data Entry Until Sentinel

    import java.util.Scanner;

public class SentinelDataEntry {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        final int SENTINEL = -1;
        int number;
        int count = 0;
        int sum = 0;
        int max = Integer.MIN_VALUE;
        int min = Integer.MAX_VALUE;

        System.out.println("Enter numbers (" + SENTINEL + " to stop):");

        number = scanner.nextInt();

        while (number != SENTINEL) {
            sum += number;
            count++;

            if (number > max) max = number;
            if (number < min) min = number;

            number = scanner.nextInt();
        }

        System.out.println("\n=== Results ===");
        System.out.println("Numbers entered: " + count);
        if (count > 0) {
            System.out.println("Sum: " + sum);
            System.out.println("Average: " + (double)sum / count);
            System.out.println("Maximum: " + max);
            System.out.println("Minimum: " + min);
        } else {
            System.out.println("No data entered.");
        }

        scanner.close();
    }
}

    Program 5: Palindrome Checker

    import java.util.Scanner;

public class PalindromeChecker {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a number: ");
        int original = scanner.nextInt();

        int number = original;
        int reversed = 0;

        while (number > 0) {
            int digit = number % 10;
            reversed = reversed * 10 + digit;
            number = number / 10;
        }

        System.out.println("Original: " + original);
        System.out.println("Reversed: " + reversed);

        if (original == reversed) {
            System.out.println(original + " is a palindrome");
        } else {
            System.out.println(original + " is not a palindrome");
        }

        // String version
        scanner.nextLine(); // Clear buffer
        System.out.print("\nEnter a word: ");
        String word = scanner.nextLine();

        String clean = word.toLowerCase().replaceAll("[^a-z]", "");
        int left = 0;
        int right = clean.length() - 1;
        boolean isPalindrome = true;

        while (left < right) {
            if (clean.charAt(left) != clean.charAt(right)) {
                isPalindrome = false;
                break;
            }
            left++;
            right--;
        }

        System.out.println(word + " is " + (isPalindrome ? "" : "not ") + "a palindrome");

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Infinite loop while (i < 10) with no i++ Condition never false Add update inside loop
    Never executes while (false) Condition initially false Check initial condition
    Off-by-one while (i <= 10) with 10 items One extra iteration Use < instead of <=
    Wrong update i-- when need forward Wrong direction Use i++ for forward
    Missing braces while (x) doSomething(); Only one statement Add braces for clarity
    Semicolon while (x); { ... } Empty loop body Remove semicolon

    7. Quick Rules Checklist

    ✅ While Loop Rules

    • [ ] Pre-test: Condition checked before first iteration
    • [ ] May run zero times: If condition initially false
    • [ ] Manual update required: Change condition variable inside
    • [ ] Use when: Indefinite iteration, unknown count

    ✅ Best Practices

    Do Don't
    Ensure condition eventually becomes false Create infinite loops accidentally
    Update condition variable every iteration Forget to update (infinite loop)
    Use break for early exit Use return unless exiting method
    Keep condition simple and clear Combine too many conditions

    ✅ While vs For

    Use While Use For
    Unknown iteration count Known iteration count
    User input validation Array processing
    Waiting for condition Counting/ranging
    Game loops Fixed repetitions

    Summary

    Aspect Description
    Syntax while (condition) { body }
    Check Before each iteration
    Minimum runs Zero times
    Update Manual inside loop
    Best for Indefinite iteration

    Golden Rules: 1. While loop = indefinite iteration (unknown count) 2. Condition checked BEFORE each iteration 3. Must manually update condition variable 4. Ensure loop can terminate (avoid infinite loops) 5. Use break for early exit, continue to skip
