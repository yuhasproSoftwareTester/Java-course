    Section 21: For Loop

    1. For Loop Structure

    Standard Syntax

    for (initialization; condition; update) {
    // loop body
}

    Three Parts Explained

    Part Purpose Example Executes
    Initialization Run once before loop starts int i = 0 One time
    Condition Checked before each iteration i < 10 Before every iteration
    Update Run after each iteration i++ After each iteration

    Execution Flow

    Initialization ──► Check Condition ──No──► Exit Loop
                      │
                     Yes
                      ▼
               Execute Body
                      │
                      ▼
                  Update ──► Check Condition (repeat)

    2. For Loop Variations

    Basic Counting (0 to 9)

    for (int i = 0; i < 10; i++) {
    System.out.println(i);  // 0, 1, 2, ..., 9
}

    Reverse Counting (10 to 1)

    for (int i = 10; i > 0; i--) {
    System.out.println(i);  // 10, 9, 8, ..., 1
}

    Step Size (Even numbers)

    for (int i = 0; i <= 20; i += 2) {
    System.out.println(i);  // 0, 2, 4, ..., 20
}

    Multiple Variables

    for (int i = 0, j = 10; i < j; i++, j--) {
    System.out.println("i=" + i + ", j=" + j);
}

    No Body (Semicolon)

    for (int i = 0; i < 1000000; i++);  // Empty loop, just counting

// Or with braces
for (int i = 0; i < n; i++) {
    // minimal work
}

    3. Scope and Variable Lifetime

    Loop Variable Scope

    for (int i = 0; i < 10; i++) {
    System.out.println(i);  // i visible here
}

// Declare outside to use after loop

for (j = 0; j < 10; j++) {
    // use j
}
System.out.println(j);  // j is 10 here

    4. Complete Working Examples

    Example 1: Basic Counting Patterns

    public class ForPatterns {
    public static void main(String[] args) {
        // Forward 1 to 5
        System.out.print("Forward: ");
        for (int i = 1; i <= 5; i++) {
            System.out.print(i + " ");
        }

        // Backward 5 to 1
        System.out.print("\nBackward: ");
        for (int i = 5; i >= 1; i--) {
            System.out.print(i + " ");
        }

        // Step by 2
        System.out.print("\nStep 2: ");
        for (int i = 0; i <= 10; i += 2) {
            System.out.print(i + " ");
        }

        // Skip some with continue
        System.out.print("\nSkip 3,6,9: ");
        for (int i = 1; i <= 10; i++) {
            if (i % 3 == 0) continue;
            System.out.print(i + " ");
        }

        // Early exit with break
        System.out.print("\nStop at 5: ");
        for (int i = 1; i <= 10; i++) {
            if (i > 5) break;
            System.out.print(i + " ");
        }
    }
}

    Example 2: Array Processing

    import java.util.Scanner;

public class ArrayForLoop {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int[] numbers = new int[5];

        // Input with for loop
        System.out.println("Enter 5 numbers:");
        for (int i = 0; i < numbers.length; i++) {
            System.out.print("Number " + (i + 1) + ": ");
            numbers[i] = scanner.nextInt();
        }

        // Process with for loop
        int sum = 0;
        int max = numbers[0];
        int min = numbers[0];

        for (int i = 0; i < numbers.length; i++) {
            sum += numbers[i];
            if (numbers[i] > max) max = numbers[i];
            if (numbers[i] < min) min = numbers[i];
        }

        double average = (double) sum / numbers.length;

        System.out.println("\nSum: " + sum);
        System.out.println("Average: " + average);
        System.out.println("Max: " + max);
        System.out.println("Min: " + min);

        // Reverse print
        System.out.print("Reverse order: ");
        for (int i = numbers.length - 1; i >= 0; i--) {
            System.out.print(numbers[i] + " ");
        }

        scanner.close();
    }
}

    Program 1: Multiplication Table

    import java.util.Scanner;

public class MultiplicationTable {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter number for table: ");
        int num = scanner.nextInt();

        System.out.print("Enter range (1 to ?): ");
        int range = scanner.nextInt();

        System.out.println("\n=== Multiplication Table of " + num + " ===");

        for (int i = 1; i <= range; i++) {
            System.out.printf("%d x %d = %d%n", num, i, num * i);
        }

        // Bonus: Full matrix
        System.out.println("\n=== Full " + range + "x" + range + " Table ===");
        System.out.print("   |");
        for (int i = 1; i <= range; i++) {
            System.out.printf("%4d", i);
        }
        System.out.println("\n---+" + "-".repeat(range * 4));

        for (int row = 1; row <= range; row++) {
            System.out.printf("%2d |", row);
            for (int col = 1; col <= range; col++) {
                System.out.printf("%4d", row * col);
            }
            System.out.println();
        }

        scanner.close();
    }
}

    Program 2: Factorial and Series

    import java.util.Scanner;

public class FactorialSeries {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter number for factorial: ");
        int n = scanner.nextInt();

        // Calculate factorial
        long factorial = 1;
        for (int i = 1; i <= n; i++) {
            factorial *= i;
        }
        System.out.println(n + "! = " + factorial);

        // Sum of first n natural numbers
        int sum = 0;
        for (int i = 1; i <= n; i++) {
            sum += i;
        }
        System.out.println("Sum 1 to " + n + " = " + sum);

        // Sum of squares
        int sumSquares = 0;
        for (int i = 1; i <= n; i++) {
            sumSquares += i * i;
        }
        System.out.println("Sum of squares = " + sumSquares);

        // Fibonacci series
        System.out.print("Fibonacci series (first " + n + " terms): ");
        int first = 0, second = 1;
        for (int i = 0; i < n; i++) {
            System.out.print(first + " ");
            int next = first + second;
            first = second;
            second = next;
        }

        // Prime check
        boolean isPrime = true;
        if (n <= 1) {
            isPrime = false;
        } else {
            for (int i = 2; i <= Math.sqrt(n); i++) {
                if (n % i == 0) {
                    isPrime = false;
                    break;
                }
            }
        }
        System.out.println("\n" + n + " is " + (isPrime ? "prime" : "not prime"));

        scanner.close();
    }
}

    Program 3: Pattern Printing

    import java.util.Scanner;

public class PatternPrinting {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter pattern size: ");
        int size = scanner.nextInt();

        // Pattern 1: Right triangle
        System.out.println("\n=== Right Triangle ===");
        for (int row = 1; row <= size; row++) {
            for (int col = 1; col <= row; col++) {
                System.out.print("* ");
            }
            System.out.println();
        }

        // Pattern 2: Inverted triangle
        System.out.println("\n=== Inverted Triangle ===");
        for (int row = size; row >= 1; row--) {
            for (int col = 1; col <= row; col++) {
                System.out.print("* ");
            }
            System.out.println();
        }

        // Pattern 3: Pyramid
        System.out.println("\n=== Pyramid ===");
        for (int row = 1; row <= size; row++) {
            // Print spaces
            for (int space = 1; space <= size - row; space++) {
                System.out.print("  ");
            }
            // Print stars
            for (int star = 1; star <= 2 * row - 1; star++) {
                System.out.print("* ");
            }
            System.out.println();
        }

        // Pattern 4: Number triangle
        System.out.println("\n=== Number Triangle ===");
        for (int row = 1; row <= size; row++) {
            int num = row;
            for (int col = 1; col <= row; col++) {
                System.out.print(num + " ");
                num++;
            }
            System.out.println();
        }

        // Pattern 5: Diamond
        System.out.println("\n=== Diamond ===");
        // Upper half
        for (int row = 1; row <= size; row++) {
            for (int space = 1; space <= size - row; space++) {
                System.out.print(" ");
            }
            for (int star = 1; star <= 2 * row - 1; star++) {
                System.out.print("*");
            }
            System.out.println();
        }
        // Lower half
        for (int row = size - 1; row >= 1; row--) {
            for (int space = 1; space <= size - row; space++) {
                System.out.print(" ");
            }
            for (int star = 1; star <= 2 * row - 1; star++) {
                System.out.print("*");
            }
            System.out.println();
        }

        scanner.close();
    }
}

    Program 4: Student Grade Processing

    import java.util.Scanner;

public class StudentGrades {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter number of students: ");
        int count = scanner.nextInt();

        String[] names = new String[count];
        int[] scores = new int[count];

        // Input loop
        for (int i = 0; i < count; i++) {
            scanner.nextLine(); // Clear buffer
            System.out.println("\nStudent " + (i + 1) + ":");
            System.out.print("Name: ");
            names[i] = scanner.nextLine();
            System.out.print("Score: ");
            scores[i] = scanner.nextInt();
        }

        // Calculate statistics
        int total = 0;
        int highest = scores[0];
        int lowest = scores[0];
        int highestIndex = 0;
        int lowestIndex = 0;

        for (int i = 0; i < count; i++) {
            total += scores[i];

            if (scores[i] > highest) {
                highest = scores[i];
                highestIndex = i;
            }
            if (scores[i] < lowest) {
                lowest = scores[i];
                lowestIndex = i;
            }
        }

        double average = (double) total / count;

        // Grade distribution
        int aCount = 0, bCount = 0, cCount = 0, dCount = 0, fCount = 0;

        for (int i = 0; i < count; i++) {
            char grade;
            if (scores[i] >= 90) {
                grade = 'A';
                aCount++;
            } else if (scores[i] >= 80) {
                grade = 'B';
                bCount++;
            } else if (scores[i] >= 70) {
                grade = 'C';
                cCount++;
            } else if (scores[i] >= 60) {
                grade = 'D';
                dCount++;
            } else {
                grade = 'F';
                fCount++;
            }
        }

        // Output results
        System.out.println("\n=== Class Report ===");
        System.out.println("Total students: " + count);
        System.out.println("Average score: " + String.format("%.2f", average));
        System.out.println("Highest: " + highest + " (" + names[highestIndex] + ")");
        System.out.println("Lowest: " + lowest + " (" + names[lowestIndex] + ")");

        System.out.println("\n=== Grade Distribution ===");
        System.out.println("A: " + aCount);
        System.out.println("B: " + bCount);
        System.out.println("C: " + cCount);
        System.out.println("D: " + dCount);
        System.out.println("F: " + fCount);

        // Pass rate
        int passed = aCount + bCount + cCount + dCount;
        double passRate = (double) passed / count * 100;
        System.out.println("\nPass rate: " + String.format("%.1f", passRate) + "%");

        scanner.close();
    }
}

    Program 5: Number Guessing Game with Limited Attempts

    import java.util.Scanner;
import java.util.Random;

public class GuessingGame {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();

        int secretNumber = random.nextInt(100) + 1;  // 1-100
        int maxAttempts = 7;
        boolean won = false;

        System.out.println("=== Number Guessing Game ===");
        System.out.println("Guess a number between 1 and 100");
        System.out.println("You have " + maxAttempts + " attempts");

        // Main game loop
        for (int attempt = 1; attempt <= maxAttempts; attempt++) {
            System.out.print("\nAttempt " + attempt + "/" + maxAttempts + ": ");
            int guess = scanner.nextInt();

            // Validate guess
            if (guess < 1 || guess > 100) {
                System.out.println("Please enter a number between 1 and 100");
                attempt--; // Don't count invalid attempts
                continue;
            }

            // Check guess
            if (guess == secretNumber) {
                System.out.println("🎉 Correct! You won!");
                won = true;

                // Score based on attempts used
                int score = (maxAttempts - attempt + 1) * 10;
                System.out.println("Score: " + score + " points");
                break;  // Exit loop early
            } else if (guess < secretNumber) {
                System.out.println("Too low! Try higher.");
            } else {
                System.out.println("Too high! Try lower.");
            }

            // Hint on last few attempts
            if (attempt == maxAttempts - 2) {
                int diff = Math.abs(guess - secretNumber);
                if (diff <= 10) {
                    System.out.println("Hint: You're very close!");
                } else {
                    System.out.println("Hint: You're far off.");
                }
            }
        }

        if (!won) {
            System.out.println("\n😢 Game Over! The number was: " + secretNumber);
        }

        // Play again option
        System.out.print("\nPlay again? (y/n): ");
        scanner.nextLine(); // Clear buffer
        String again = scanner.nextLine();

        if (again.equalsIgnoreCase("y")) {
            main(args);  // Restart (simplified)
        } else {
            System.out.println("Thanks for playing!");
        }

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Off-by-one i <= 10 when need 0-9 Includes 10, array index error i < 10 or i < array.length
    Wrong update i++ when need reverse Infinite or wrong direction i-- for reverse, i += 2 for steps
    Scope error Use i after loop i only visible inside loop Declare i outside or copy value
    Modify counter i += 2 inside body Double increment, skips values Only modify in update expression
    Empty condition for (;;) Infinite loop Add proper condition i < n
    Wrong semicolon for (i=0; i<10; i++); Loop body is empty Remove semicolon before {

    7. Quick Rules Checklist

    ✅ For Loop Rules

    • [ ] Initialization: Run once before loop
    • [ ] Condition: Checked before each iteration (exit when false)
    • [ ] Update: Run after each iteration
    • [ ] Scope: Loop variable only visible inside loop
    • [ ] Use when: Known number of iterations, counting, array indexing

    ✅ Best Practices

    Do Don't
    Use i < array.length for arrays Hardcode array size in condition
    Use i++ for single step Modify counter inside body
    Use int for counter with small ranges Use long unless necessary
    Keep body focused on one task Put complex logic in loop body
    Use break for early exit Use return when exiting method

    Summary

    Component Purpose Example
    initialization Setup counter int i = 0
    condition Continue while true i < 10
    update Modify counter i++
    body Repeated code { ... }

    Golden Rules: 1. For loop = definite iteration (known start, end, step) 2. Condition checked before each iteration (may run zero times) 3. Update runs after body, before next condition check 4. Loop variable scope is limited to the loop 5. Use break for early exit, continue to skip iteration
