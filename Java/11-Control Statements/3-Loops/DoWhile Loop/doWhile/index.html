    Section 23: Do-While Loop

    1. Do-While Loop Structure

    Syntax

    do {
    // loop body
} while (condition);

    How It Works

    Execute Body (always once)
    │
    ▼
Check Condition ──Yes──► Execute Body (repeat)
    │
    No
    ▼
   Exit

    Key Characteristics

    Feature Description
    Post-test Condition checked AFTER each iteration
    Executes at least once Body runs before first condition check
    Semicolon required while (condition); at end
    Use when First iteration must happen unconditionally

    2. Do-While vs While Comparison

    Aspect Do-While While
    When condition checked After iteration Before iteration
    Minimum executions 1 time 0 times
    Syntax ending } while (condition); while (condition) {
    Best for Menu systems, input validation General indefinite loops

    Visual Comparison

    Do-While (Post-test):

    Execute Body
    │
    ▼
Check? ──Yes──► Execute Body (repeat)
    │
    No ──► Exit

    While (Pre-test):

    Check? ──No──► Exit (never execute)
    │
   Yes
    ▼
Execute Body ──► Check? (repeat)

    3. Complete Working Examples

    Example 1: Basic Do-While Patterns

    import java.util.Scanner;

public class DoWhilePatterns {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // Forward counting (guaranteed at least one)
        System.out.print("Forward: ");
        int i = 1;
        do {
            System.out.print(i + " ");
            i++;
        } while (i <= 5);

        // Backward counting
        System.out.print("\nBackward: ");
        int j = 5;
        do {
            System.out.print(j + " ");
            j--;
        } while (j >= 1);

        // With continue (rare but valid)
        System.out.print("\nSkip 3: ");
        int k = 0;
        do {
            k++;
            if (k == 3) continue;
            System.out.print(k + " ");
        } while (k < 5);

        // With break
        System.out.print("\nStop at 4: ");
        int m = 0;
        do {
            m++;
            if (m > 4) break;
            System.out.print(m + " ");
        } while (m < 10);

        scanner.close();
    }
}

    Example 2: Guaranteed Execution Demo

    public class GuaranteedExecution {
    public static void main(String[] args) {
        // Condition false immediately, but body runs once
        int x = 10;

        System.out.println("Do-While:");
        do {
            System.out.println("x = " + x);  // Prints once
            x++;
        } while (x < 5);  // False immediately, but we already executed

        // Reset
        x = 10;

        System.out.println("\nWhile:");
        while (x < 5) {
            System.out.println("x = " + x);  // Never prints
            x++;
        }
        System.out.println("(Never executed)");
    }
}

    Output:

    Do-While:
x = 10

While:
(Never executed)

    4. Five Practical Programs (Copy-Paste Ready)

    Program 1: Menu System (Classic Use Case)

    import java.util.Scanner;

public class MenuDoWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int choice;

        do {
            System.out.println("\n=== Main Menu ===");
            System.out.println("1. View Profile");
            System.out.println("2. Edit Settings");
            System.out.println("3. View Reports");
            System.out.println("4. Logout");
            System.out.print("Enter choice: ");

            choice = scanner.nextInt();

            switch (choice) {
                case 1:
                    System.out.println("Displaying profile...");
                    break;
                case 2:
                    System.out.println("Opening settings...");
                    break;
                case 3:
                    System.out.println("Loading reports...");
                    break;
                case 4:
                    System.out.println("Logging out...");
                    break;
                default:
                    System.out.println("Invalid choice. Try again.");
            }

        } while (choice != 4);  // Continue until logout

        System.out.println("Goodbye!");
        scanner.close();
    }
}

    Program 2: Input Validation (Guaranteed Prompt)

    import java.util.Scanner;

public class InputValidationDoWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        int age;

        // Keep asking until valid input
        do {
            System.out.print("Enter your age (1-120): ");
            age = scanner.nextInt();

            if (age < 1 || age > 120) {
                System.out.println("Invalid age. Please try again.");
            }

        } while (age < 1 || age > 120);

        System.out.println("Valid age entered: " + age);

        // Another example: Yes/No confirmation
        scanner.nextLine(); // Clear buffer
        String response;

        do {
            System.out.print("\nConfirm deletion (yes/no): ");
            response = scanner.nextLine().toLowerCase();

            if (!response.equals("yes") && !response.equals("no")) {
                System.out.println("Please enter 'yes' or 'no'");
            }

        } while (!response.equals("yes") && !response.equals("no"));

        System.out.println("You chose: " + response);

        scanner.close();
    }
}

    Program 3: Calculator with Repeat Option

    import java.util.Scanner;

public class CalculatorDoWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        char continueCalc;

        do {
            System.out.print("\nEnter first number: ");
            double num1 = scanner.nextDouble();

            System.out.print("Enter operator (+, -, *, /): ");
            char operator = scanner.next().charAt(0);

            System.out.print("Enter second number: ");
            double num2 = scanner.nextDouble();

            double result = 0;
            boolean valid = true;

            switch (operator) {
                case '+':
                    result = num1 + num2;
                    break;
                case '-':
                    result = num1 - num2;
                    break;
                case '*':
                    result = num1 * num2;
                    break;
                case '/':
                    if (num2 != 0) {
                        result = num1 / num2;
                    } else {
                        System.out.println("Error: Cannot divide by zero");
                        valid = false;
                    }
                    break;
                default:
                    System.out.println("Error: Invalid operator");
                    valid = false;
            }

            if (valid) {
                System.out.println("Result: " + result);
            }

            System.out.print("\nPerform another calculation? (y/n): ");
            continueCalc = scanner.next().toLowerCase().charAt(0);

        } while (continueCalc == 'y');

        System.out.println("Calculator closed.");
        scanner.close();
    }
}

    Program 4: Number Reversal

    import java.util.Scanner;

public class NumberReversal {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter a positive integer: ");
        int number = scanner.nextInt();

        int original = number;
        int reversed = 0;

        // Do-while ensures we process at least one digit (handles 0 correctly)
        do {
            int digit = number % 10;           // Get last digit
            reversed = reversed * 10 + digit;  // Add to reversed number
            number = number / 10;              // Remove last digit
        } while (number > 0);

        System.out.println("Original: " + original);
        System.out.println("Reversed: " + reversed);

        // Check palindrome
        if (original == reversed) {
            System.out.println(original + " is a palindrome");
        } else {
            System.out.println(original + " is not a palindrome");
        }

        // Digit sum using do-while
        number = original;
        int sum = 0;

        do {
            sum += number % 10;
            number /= 10;
        } while (number > 0);

        System.out.println("Sum of digits: " + sum);

        scanner.close();
    }
}

    Program 5: Dice Game with Betting

    import java.util.Scanner;
import java.util.Random;

public class DiceGameDoWhile {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        Random random = new Random();

        int balance = 100;
        char playAgain;

        System.out.println("=== Dice Betting Game ===");
        System.out.println("Starting balance: $" + balance);

        do {
            // Get valid bet
            int bet;
            do {
                System.out.print("\nEnter bet amount (1-" + balance + "): $");
                bet = scanner.nextInt();

                if (bet < 1 || bet > balance) {
                    System.out.println("Invalid bet. Try again.");
                }
            } while (bet < 1 || bet > balance);

            // Roll dice
            int dice1 = random.nextInt(6) + 1;
            int dice2 = random.nextInt(6) + 1;
            int total = dice1 + dice2;

            System.out.println("Rolled: " + dice1 + " + " + dice2 + " = " + total);

            // Determine outcome
            if (total == 7 || total == 11) {
                System.out.println("You win! Double your bet!");
                balance += bet;
            } else if (total == 2 || total == 3 || total == 12) {
                System.out.println("Craps! You lose your bet.");
                balance -= bet;
            } else {
                System.out.println("Point is " + total + ". Roll again...");

                // Continue rolling until win or lose
                boolean pointResolved = false;
                do {
                    System.out.print("Press enter to roll...");
                    scanner.nextLine(); // Wait for enter
                    scanner.nextLine();

                    dice1 = random.nextInt(6) + 1;
                    dice2 = random.nextInt(6) + 1;
                    int newTotal = dice1 + dice2;

                    System.out.println("Rolled: " + dice1 + " + " + dice2 + " = " + newTotal);

                    if (newTotal == total) {
                        System.out.println("You hit the point! You win!");
                        balance += bet;
                        pointResolved = true;
                    } else if (newTotal == 7) {
                        System.out.println("Seven out! You lose.");
                        balance -= bet;
                        pointResolved = true;
                    } else {
                        System.out.println("Rolling again...");
                    }

                } while (!pointResolved);
            }

            System.out.println("Current balance: $" + balance);

            if (balance > 0) {
                System.out.print("\nPlay again? (y/n): ");
                playAgain = scanner.next().toLowerCase().charAt(0);
            } else {
                System.out.println("You're out of money!");
                playAgain = 'n';
            }

        } while (playAgain == 'y' && balance > 0);

        System.out.println("\nFinal balance: $" + balance);
        System.out.println("Thanks for playing!");

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Missing semicolon } while (x < 5) Syntax error Add semicolon: } while (x < 5);
    Wrong braces do x++; while (x < 5); Only one statement Use braces: do { x++; } while (x < 5);
    Infinite loop do { ... } while (true); Never exits Add break condition inside
    Wrong condition do { i++; } while (i > 10) when i starts at 0 Only runs once Check logic: should be i < 10
    Variable scope Declare inside do, use in while Variable not visible Declare before do block

    7. Quick Rules Checklist

    ✅ Do-While Rules

    • [ ] Post-test: Condition checked after each iteration
    • [ ] Executes at least once: Guaranteed first iteration
    • [ ] Semicolon required: After while (condition);
    • [ ] Braces recommended: Even for single statement

    ✅ Best Practices

    Do Don't
    Use for menu systems (show menu, then check exit) Use when zero iterations might be needed
    Use for input validation (prompt at least once) Use for simple counting (use for loop)
    Keep condition clear and simple Create infinite loops accidentally
    Ensure termination condition possible Forget the semicolon at end

    ✅ Do-While vs While vs For

    Use Do-When Use While Use For
    Menu must display at least once Unknown iterations, might be zero Known iteration count
    Input validation (prompt guaranteed) Waiting for external condition Array/list iteration
    Roll until condition met Polling/checking status Counting/ranging

    Summary

    Aspect Do-While
    Syntax do { body } while (condition);
    Check After each iteration
    Minimum runs One time
    Semicolon Required after while
    Best for Guaranteed first execution

    Golden Rules: 1. Do-while = post-test loop (check after) 2. Body always executes at least once 3. Don't forget the semicolon at the end! 4. Use for menus, validation, guaranteed first prompt 5. Ensure condition can become false to avoid infinite loops
