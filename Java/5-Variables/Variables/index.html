    6. Variables (Complete Guide)

    What is a Variable?

    Variable = Named memory location to store data

    Syntax: datatype variableName = value;
Example: int age = 25;

    Variable Declaration Rules

    // 1. Declare + Initialize
int age = 25;
String name = "John";

// 2. Declare first, initialize later
int marks;
marks = 85;

// 3. Multiple variables
int a = 1, b = 2, c = 3;

// 4. Same type together
int x, y, z;  // All ints

    Variable Naming Rules (MUST Follow)

    ✅ Valid ❌ Invalid Reason
    age 2age No number start
    firstName first-name No hyphen
    student_id student id No space
    $money @money Only $ and _ allowed
    _private public No Java keywords

    Variable Scope (Important!)

    public class ScopeDemo {
    int global = 100;  // Global (class level)

    public static void main(String[] args) {
        int local = 50;    // Local (method level)

        System.out.println("Local: " + local);
        // System.out.println(global);  // ERROR! Can't access non-static Variable
    }
}

    5 Practical Programs

    Practice 1: Student Profile

    public class Practice1 {
    public static void main(String[] args) {
        String firstName = "John";
        String lastName = "Doe";
        int age = 22;
        char grade = 'A';
        double fees = 25000.50;

        System.out.println("Name: " + firstName + " " + lastName);
        System.out.println("Age: " + age);
        System.out.println("Grade: " + grade);
        System.out.println("Fees: Rs." + fees);
    }
}

    Practice 2: Shopping Cart

    public class Practice2 {
    public static void main(String[] args) {
        String item1 = "Laptop";
        String item2 = "Mouse";
        int qty1 = 1, qty2 = 2;
        double price1 = 45000, price2 = 500;
        double total = (qty1 * price1) + (qty2 * price2);

        System.out.println("Shopping Cart:");
        System.out.println(item1 + " x" + qty1 + " = Rs." + (qty1*price1));
        System.out.println(item2 + " x" + qty2 + " = Rs." + (qty2*price2));
        System.out.println("Total: Rs." + total);
    }
}

    Practice 3: Swap Variables

    public class Practice3 {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        System.out.println("Before swap: a=" + a + ", b=" + b);

        // Swap using temp
        int temp = a;
        a = b;
        b = temp;

        System.out.println("After swap: a=" + a + ", b=" + b);
    }
}

    Practice 4: Employee Salary Calculator

    public class Practice4 {
    public static void main(String[] args) {
        String empName = "Alice";
        double basicSalary = 30000;
        double hra = basicSalary * 0.20;  // 20%
        double da = basicSalary * 0.15;   // 15%
        double grossSalary = basicSalary + hra + da;

        System.out.println("Employee: " + empName);
        System.out.println("Basic: Rs." + basicSalary);
        System.out.println("HRA: Rs." + hra);
        System.out.println("DA: Rs." + da);
        System.out.println("Gross: Rs." + grossSalary);
    }
}

    Common Variable Errors

    // ❌ Not initialized
int x;
System.out.println(x);  // Error!

// ❌ Wrong data type
int age = "25";         // Error!

// ❌ Duplicate in same scope
int a = 10;
int a = 20;             // Error!

// ✅ Correct
int x = 0;              // Initialize
String age = "25";      // String is OK

    Variable Golden Rules

    1. Declare before use
2. Initialize before print
3. Match datatype with value
4. Meaningful names (camelCase)
5. No Java keywords
6. Scope matters!
