    Strings and Methods

    1. String Fundamentals

    What is a String?

    • Object, not primitive (stored in heap memory)
    • Immutable: Cannot be changed after creation
    • Sequence of characters (Unicode support)
    • Stored in String Pool for memory efficiency

    String Immutability Explained

    String name = "Java";
name = name + " Course";  // Creates NEW object, doesn't modify original

// Memory view:
// Step 1: "Java" created in pool
// Step 2: " Course" created
// Step 3: "Java Course" created (NEW object)
// Step 4: name reference moved to new object
// Step 1 object "Java" remains unchanged (garbage collected later)

    Why Immutable?

    Benefit Explanation
    Security Can't modify sensitive data (passwords, URLs)
    Thread-safe Multiple threads can share safely
    HashCode caching Faster HashMap/HashSet operations
    String Pool Reuse saves memory

    Method Example Use Case
    String literal String s = "Hello" Preferred, uses String Pool
    new keyword new String("Hello") Creates separate heap object
    From char array new String(char[]) Convert char array
    From byte array new String(byte[]) Convert bytes to text
    valueOf() String.valueOf(123) Convert any type to String

String a = "Test";

// Creates duplicate object (avoid)
String b = new String("Test");

// a == b is FALSE (different objects)
// a.equals(b) is TRUE (same content)

    3. Essential String Methods (20+)

    3.1 Length and Inspection

    Method Returns Description Example
    length() int Number of characters "Hello".length() → 5
    isEmpty() boolean True if length 0 "".isEmpty() → true
    isBlank() boolean True if empty or whitespace only " ".isBlank() → true (Java 11+)
    charAt(int) char Character at index "Java".charAt(0) → 'J'

    3.2 Comparison

    Method Returns Description Example
    equals(String) boolean Case-sensitive content match "A".equals("a") → false
    equalsIgnoreCase(String) boolean Case-insensitive match "A".equalsIgnoreCase("a") → true
    compareTo(String) int Lexicographic comparison "a".compareTo("b") → -1
    startsWith(String) boolean Prefix check "Test".startsWith("Te") → true
    endsWith(String) boolean Suffix check "Test.java".endsWith(".java") → true
    contains(CharSequence) boolean Substring check "Hello".contains("ell") → true

    3.3 Search and Index

    Method Returns Description Example
    indexOf(String) int First occurrence index "banana".indexOf("a") → 1
    indexOf(String, int) int Search from index "banana".indexOf("a", 2) → 3
    lastIndexOf(String) int Last occurrence index "banana".lastIndexOf("a") → 5
    indexOf(char) int Find character "Java".indexOf('v') → 2

    3.4 Extraction

    Method Returns Description Example
    substring(int) String From index to end "Hello".substring(2) → "llo"
    substring(int, int) String From start to end-1 "Hello".substring(1, 4) → "ell"
    trim() String Remove leading/trailing spaces " hi ".trim() → "hi"
    strip() String Unicode-aware trim (Java 11) Same but better
    stripLeading() String Remove leading spaces only " hi".stripLeading() → "hi"
    stripTrailing() String Remove trailing spaces only "hi ".stripTrailing() → "hi"

    3.5 Modification (Returns NEW String)

    Method Returns Description Example
    toLowerCase() String All lowercase "JAVA".toLowerCase() → "java"
    toUpperCase() String All uppercase "java".toUpperCase() → "JAVA"
    replace(char, char) String Replace all chars "aabb".replace('a', 'x') → "xxbb"
    replace(String, String) String Replace all substrings "aa".replace("a", "xx") → "xxxx"
    replaceAll(String, String) String Regex replace "a1b2".replaceAll("\\d", "X") → "aXbX"
    replaceFirst(String, String) String First regex match only "a1b2".replaceFirst("\\d", "X") → "aXb2"

    3.6 Splitting and Joining

    Method Returns Description Example
    split(String) String[] Split by regex "a,b,c".split(",") → ["a", "b", "c"]
    split(String, int) String[] Split with limit "a,b,c".split(",", 2) → ["a", "b,c"]
    join(CharSequence, ...) String Join with delimiter String.join("-", "a", "b") → "a-b"
    repeat(int) String Repeat string (Java 11) "ab".repeat(3) → "ababab"

    3.7 Formatting and Conversion

    Method Returns Description Example
    format(String, ...) String Static format method String.format("Hi %s", "Joe")
    toCharArray() char[] Convert to char array "Hi".toCharArray() → ['H', 'i']
    getBytes() byte[] Convert to bytes "Hi".getBytes()
    valueOf(any) String Static conversion String.valueOf(123) → "123"

    Program 1: Email Validator

    import java.util.Scanner;

public class EmailValidator {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter email: ");
        String email = scanner.nextLine().trim();

        // Validation checks
        boolean hasAt = email.contains("@");
        boolean hasDot = email.contains(".");
        boolean noSpaces = !email.contains(" ");
        boolean properLength = email.length() >= 5;

        // Extract parts if valid format
        boolean isValidFormat = hasAt && hasDot && noSpaces && properLength;

        String username = "";
        String domain = "";

        if (isValidFormat) {
            int atIndex = email.indexOf('@');
            username = email.substring(0, atIndex);
            domain = email.substring(atIndex + 1);

            // Additional domain checks
            boolean validDomain = domain.contains(".") && 
                                 !domain.startsWith(".") && 
                                 !domain.endsWith(".");
            isValidFormat = isValidFormat && validDomain;
        }

        System.out.println("\n=== Validation Results ===");
        System.out.println("Contains @: " + hasAt);
        System.out.println("Contains dot: " + hasDot);
        System.out.println("No spaces: " + noSpaces);
        System.out.println("Proper length: " + properLength);
        System.out.println("✅ VALID: " + isValidFormat);

        if (isValidFormat) {
            System.out.println("Username: " + username);
            System.out.println("Domain: " + domain);

            // Normalize
            String normalized = email.toLowerCase();
            System.out.println("Normalized: " + normalized);
        }

        scanner.close();
    }
}

    Program 2: URL Parser (Selenium Prep)

    import java.util.Scanner;

public class URLParser {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.print("Enter URL: ");
        String url = scanner.nextLine().trim();

        // Protocol extraction
        String protocol = "";
        if (url.contains("://")) {
            protocol = url.substring(0, url.indexOf("://"));
        }

        // Remove protocol for further parsing
        String withoutProtocol = url.replaceFirst(".*://", "");

        // Domain extraction (before / or :)
        String domain = withoutProtocol;
        int pathIndex = withoutProtocol.indexOf('/');
        int portIndex = withoutProtocol.indexOf(':');

        int endIndex = withoutProtocol.length();
        if (pathIndex != -1) endIndex = Math.min(endIndex, pathIndex);
        if (portIndex != -1) endIndex = Math.min(endIndex, portIndex);

        domain = withoutProtocol.substring(0, endIndex);

        // Path extraction
        String path = "";
        if (pathIndex != -1) {
            int queryIndex = withoutProtocol.indexOf('?');
            if (queryIndex == -1) {
                path = withoutProtocol.substring(pathIndex);
            } else {
                path = withoutProtocol.substring(pathIndex, queryIndex);
            }
        }

        // Query parameters
        String query = "";
        int queryIndex = withoutProtocol.indexOf('?');
        if (queryIndex != -1) {
            int hashIndex = withoutProtocol.indexOf('#');
            if (hashIndex == -1) {
                query = withoutProtocol.substring(queryIndex + 1);
            } else {
                query = withoutProtocol.substring(queryIndex + 1, hashIndex);
            }
        }

        System.out.println("\n=== URL Components ===");
        System.out.println("Full URL: " + url);
        System.out.println("Protocol: " + protocol);
        System.out.println("Domain: " + domain);
        System.out.println("Path: " + (path.isEmpty() ? "/" : path));
        System.out.println("Query: " + (query.isEmpty() ? "none" : query));

        // Validation for Selenium
        boolean isSecure = protocol.equalsIgnoreCase("https");
        boolean isValidDomain = domain.contains(".") && !domain.startsWith(".");

        System.out.println("\n=== Selenium Checks ===");
        System.out.println("Is secure (HTTPS): " + isSecure);
        System.out.println("Valid domain format: " + isValidDomain);

        scanner.close();
    }
}

    Program 3: CSV Data Parser

    import java.util.Scanner;

public class CSVParser {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Enter CSV data (comma-separated):");
        String csv = scanner.nextLine();

        // Split by comma
        String[] fields = csv.split(",");

        System.out.println("\n=== Parsed Fields ===");
        for (int i = 0; i < fields.length; i++) {
            // Clean each field
            String field = fields[i].trim();

            // Remove quotes if present
            if (field.startsWith("\"") && field.endsWith("\"")) {
                field = field.substring(1, field.length() - 1);
            }

            System.out.println("Field " + (i + 1) + ": [" + field + "]");
        }

        // Reconstruct with different delimiter
        String pipeDelimited = String.join("|", fields);
        System.out.println("\nPipe-delimited: " + pipeDelimited);

        // Data transformation example
        if (fields.length >= 3) {
            String name = fields[0].trim();
            String email = fields[1].trim().toLowerCase();
            String phone = fields[2].trim().replaceAll("-", "");

            System.out.println("\n=== Cleaned Data ===");
            System.out.println("Name: " + name.toUpperCase());
            System.out.println("Email: " + email);
            System.out.println("Phone (digits only): " + phone);
        }

        scanner.close();
    }
}

    Program 4: Text Analyzer

    import java.util.Scanner;

public class TextAnalyzer {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("Enter text to analyze:");
        String text = scanner.nextLine();

        // Basic stats
        int length = text.length();
        int wordCount = text.trim().isEmpty() ? 0 : text.trim().split("\\s+").length;
        int lineCount = text.split("\n").length;

        // Character analysis
        int uppercaseCount = 0;
        int lowercaseCount = 0;
        int digitCount = 0;
        int spaceCount = 0;

        for (char c : text.toCharArray()) {
            if (Character.isUpperCase(c)) uppercaseCount++;
            else if (Character.isLowerCase(c)) lowercaseCount++;
            else if (Character.isDigit(c)) digitCount++;
            else if (Character.isWhitespace(c)) spaceCount++;
        }

        // Search functionality
        System.out.print("\nEnter search term: ");
        String search = scanner.nextLine();

        int searchIndex = text.indexOf(search);
        int occurrenceCount = 0;
        int lastIndex = 0;

        while ((lastIndex = text.indexOf(search, lastIndex)) != -1) {
            occurrenceCount++;
            lastIndex += search.length();
        }

        // Case variations
        String[] variations = {
            text.toLowerCase(),
            text.toUpperCase(),
            capitalizeWords(text),
            text.strip()
        };

        System.out.println("\n=== Text Statistics ===");
        System.out.println("Total characters: " + length);
        System.out.println("Words: " + wordCount);
        System.out.println("Lines: " + lineCount);
        System.out.println("Uppercase letters: " + uppercaseCount);
        System.out.println("Lowercase letters: " + lowercaseCount);
        System.out.println("Digits: " + digitCount);
        System.out.println("Spaces: " + spaceCount);

        System.out.println("\n=== Search Results ===");
        System.out.println("Searching for: '" + search + "'");
        System.out.println("Occurrences: " + occurrenceCount);
        System.out.println("First found at index: " + (searchIndex == -1 ? "N/A" : searchIndex));

        System.out.println("\n=== Variations ===");
        System.out.println("Lowercase: " + variations[0].substring(0, Math.min(50, variations[0].length())) + "...");
        System.out.println("Uppercase: " + variations[1].substring(0, Math.min(50, variations[1].length())) + "...");
        System.out.println("Title Case: " + variations[2].substring(0, Math.min(50, variations[2].length())) + "...");

        scanner.close();
    }

    // Helper method
    static String capitalizeWords(String text) {
        String[] words = text.toLowerCase().split(" ");
        StringBuilder result = new StringBuilder();
        for (String word : words) {
            if (!word.isEmpty()) {
                result.append(Character.toUpperCase(word.charAt(0)))
                      .append(word.substring(1))
                      .append(" ");
            }
        }
        return result.toString().trim();
    }
}

    Program 5: Selenium Locator Builder (Automation Prep)

    import java.util.Scanner;

public class LocatorBuilder {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        System.out.println("=== Selenium Locator Builder ===");

        System.out.print("Enter element attribute value (id, name, class, etc.): ");
        String rawValue = scanner.nextLine();

        System.out.print("Attribute type (id/name/class/tag/text): ");
        String attrType = scanner.nextLine().toLowerCase().trim();

        // Clean the value
        String cleanValue = rawValue.trim()
                                   .replace("\"", "\\\"")
                                   .replace("'", "\\'");

        // Generate locators
        System.out.println("\n=== Generated Locators ===");

        switch (attrType) {
            case "id":
                System.out.println("By.id(\"" + cleanValue + "\")");
                System.out.println("By.cssSelector(\"#" + cleanValue + "\")");
                System.out.println("By.xpath(\"//*[@id='" + cleanValue + "']\")");
                break;

            case "name":
                System.out.println("By.name(\"" + cleanValue + "\")");
                System.out.println("By.cssSelector(\"[name='" + cleanValue + "']\")");
                System.out.println("By.xpath(\"//*[@name='" + cleanValue + "']\")");
                break;

            case "class":
                // Handle multiple classes
                if (cleanValue.contains(" ")) {
                    String cssClass = cleanValue.replace(" ", ".");
                    System.out.println("By.cssSelector(\"." + cssClass + "\")");
                    // XPath with contains for partial class
                    String[] classes = cleanValue.split("\\s+");
                    System.out.println("By.xpath(\"//*[contains(@class, '" + classes[0] + "')]\")");
                } else {
                    System.out.println("By.className(\"" + cleanValue + "\")");
                    System.out.println("By.cssSelector(\"." + cleanValue + "\")");
                }
                break;

            case "tag":
                System.out.println("By.tagName(\"" + cleanValue + "\")");
                System.out.println("By.cssSelector(\"" + cleanValue + "\")");
                break;

            case "text":
                // Exact match
                System.out.println("By.xpath(\"//*[text()='" + cleanValue + "']\")");
                // Partial match
                System.out.println("By.xpath(\"//*[contains(text(), '" + cleanValue + "')]\")");
                // Case insensitive
                System.out.println("By.xpath(\"//*[contains(translate(text(), 'ABCDEFGHIJKLMNOPQRSTUVWXYZ', 'abcdefghijklmnopqrstuvwxyz'), '" 
                    + cleanValue.toLowerCase() + "')]\")");
                break;

            default:
                System.out.println("Generic CSS: By.cssSelector(\"[" + attrType + "='" + cleanValue + "']\")");
                System.out.println("Generic XPath: By.xpath(\"//*[@" + attrType + "='" + cleanValue + "']\")");
        }

        // Dynamic locator with variable
        System.out.println("\n=== Dynamic Locator Template ===");
        System.out.println("String dynamicValue = \"" + cleanValue + "\";");
        System.out.println("By dynamicLocator = By.xpath(\"//*[@" + attrType + "='\" + dynamicValue + \"']\");");

        // Validation helpers
        System.out.println("\n=== Validation Methods ===");
        System.out.println("// Check if value is valid identifier");
        System.out.println("boolean isValid = !\"" + cleanValue + "\".isBlank() && !\"" + cleanValue + "\".contains(\" \");");

        // Text normalization for comparison
        System.out.println("\n=== Text Normalization for Assertions ===");
        String normalized = cleanValue.toLowerCase().trim().replaceAll("\\s+", " ");
        System.out.println("String expectedText = \"" + normalized + "\";");
        System.out.println("String actualText = element.getText().toLowerCase().trim().replaceAll(\"\\\\s+\", \" \");");
        System.out.println("boolean match = actualText.contains(expectedText);");

        scanner.close();
    }
}

    6. Common Errors & Fixes

    Error Wrong Code Problem Fix
    Using == for strings if (s1 == s2) Compares references, not content if (s1.equals(s2))
    Modifying "in place" s.toUpperCase() Returns new string, original unchanged s = s.toUpperCase()
    Index out of bounds s.charAt(s.length()) Valid indices: 0 to length-1 s.charAt(s.length() - 1)
    Substring end index s.substring(0, 5) End index is exclusive s.substring(0, 4) gets chars 0-3
    Split regex special chars "a.b".split(".") . is regex for "any char" "a.b".split("\\.")
    Null pointer s.length() if s is null Throws NPE if (s != null && !s.isEmpty())
    StringBuilder not used Loop with s += "x" Creates many objects, slow Use StringBuilder

    7. Quick Rules Checklist

    ✅ String Rules

    • [ ] Immutable: Every "modification" creates a new object
    • [ ] Use .equals() for content comparison (not ==)
    • [ ] Use .equalsIgnoreCase() for case-insensitive comparison
    • [ ] Check null first before calling methods: if (str != null && str.length() > 0)
    • [ ] Index bounds: charAt(0) to charAt(length-1)
    • [ ] Substring: End index is exclusive (not included)

    ✅ Performance Rules

    • [ ] String literals for constants: String s = "constant"
    • [ ] StringBuilder for loops/modifications
    • [ ] StringBuffer only if thread safety needed (rare)
    • [ ] Avoid + in loops (creates many temporary objects)

    Another Example: Dynamic XPath Builder

    public By buildXPath(String tag, String attribute, String value) {
    // Sanitize value for XPath
    String safeValue = value.replace("'", "\\'");

    // Build XPath: //tag[@attribute='value']
    String xpath = String.format("//%s[@%s='%s']", tag, attribute, safeValue);
    return By.xpath(xpath);
}

// Usage
By userNameField = buildXPath("input", "id", "userName");
By dynamicButton = buildXPath("button", "text()", "Submit");

// For partial match
public By buildContainsXPath(String tag, String attribute, String partialValue) {
    String safeValue = partialValue.replace("'", "\\'");
    String xpath = String.format("//%s[contains(@%s, '%s')]", tag, attribute, safeValue);
    return By.xpath(xpath);
}

    9. StringBuilder vs String

    Feature String StringBuilder
    Mutable No Yes
    Thread-safe Yes (immutable) No
    Speed Slow for modifications Fast for modifications
    Use case Constants, single values Loops, building text

    StringBuilder Example

    // BAD: Creates 1000 String objects
String result = "";
for (int i = 0; i < 1000; i++) {
    result += i;  // Creates new object each time!
}

// GOOD: Single mutable object
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String result = sb.toString();
