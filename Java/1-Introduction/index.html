    Introduction to Java

    What is Java?

    Java is a high-level, object-oriented, platform-independent programming language developed by Sun Microsystems (now owned by Oracle).

    It is designed to be: - Simple - Secure - Robust - Portable

    Java follows the principle: "Write Once, Run Anywhere (WORA)"

    Why Learn Java?

    Java is one of the most in-demand programming languages.

    It is widely used in: - Web applications - Android mobile apps - Enterprise systems - Automation testing (Selenium, TestNG)

    ✔ Beginner-friendly
    ✔ Huge community support
    ✔ Used in real-world projects

    Key Features of Java

    Platform Independent

    Java code can run on any system that has JVM installed.

    Object-Oriented

    Everything in Java is based on objects and classes.

    Secure

    Java does not use pointers and has built-in security features.

    Robust

    Strong memory management and exception handling.

    Multithreaded

    Java supports running multiple tasks at the same time.

    Java Architecture (VERY IMPORTANT)

    Java works using three main components:

    JDK + JRE + JVM

    1. JVM (Java Virtual Machine)

    JVM is the engine that runs Java programs.

    Responsibilities: - Executes bytecode - Converts bytecode into machine code - Manages memory - Handles garbage collection

    ✔ Platform dependent
    ✔ Core of Java runtime

    2. JRE (Java Runtime Environment)

    JRE provides the environment to run Java programs.

    It includes: - JVM - Libraries - Runtime files

    ✔ Used only for running Java programs

    3. JDK (Java Development Kit)

    JDK is used for developing Java applications.

    It includes: - JRE - Compiler (javac) - Tools (debugger, etc.)

    ✔ Used for writing + compiling + running

    Relationship

    JDK = JRE + Development Tools
JRE = JVM + Libraries
