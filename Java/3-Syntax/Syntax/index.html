    3. Java Syntax & First Program

    Java Syntax Keywords (Must Memorize)

    Keyword Purpose Example
    public Access modifier (visible everywhere) public class
    class Defines a class class MyClass
    static Belongs to class (not object) static void main
    void No return value void main()
    int Integer data type int age = 25;
    String Text data type String name = "John";
    main Entry point method main(String[] args)
    System Built-in class System.out
    out Output stream out.println()
    println Print with newline println("Hello")

    Common Errors & Fixes

    Error Cause Fix
    ';' expected Missing semicolon Add ; at line end
    class not found Wrong file name File = Class name
    javac not recognized PATH not set Add JDK to PATH
    cannot find symbol Typo in keyword Check spelling

    Syntax Rules (Detailed)

    // 1. EVERY statement ends with ;
int x = 10;        //  Correct
int y = 20         //  Error!

// 2. Braces ALWAYS match
public class Test {
    public static void main(String[] args) {
        System.out.println("Hello");  //  Braces match
    }  // ← Closing brace required
}    // ← Class closing brace

// 3. main() method REQUIRED (exact signature)
public static void main(String[] args)  //  Correct
public static void Main(String args)    //  Wrong case
static void main(String[] args)         //  Missing public

    Syntax Checklist

    File name = Class name (.java)
public class ClassName
public static void main(String[] args)
Every statement ends with ;
Braces match {} for class & main
Semicolons after variables
No spaces in keywords

    Quick Test

    Does this compile?

    public class Test {
    public static void main(String[] args)
    {
        System.out.println("Test");
    }
}

    Answer: NO (missing { after main())
